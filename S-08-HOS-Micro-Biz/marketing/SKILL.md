## Xianyu (Idle Fish) Listing Copy

### Title Formula
```
[Service Type] + [Tech Stack] + [Selling Point] + [Target Audience]

Examples:
  "Python coursework thesis data analysis web scraping automation CS tutoring"
  "Java SpringBoot graduation project mini-program website development"
  "AI LLM deployment ChatGPT privatization RAG knowledge base consulting"
```

### Description Template
```
- CS Master / Security specialization, X years experience
- Expertise: Python / Java / AI / Security / Web
- Helped XX+ students complete coursework/thesis
- Code explanation + after-sales Q&A + revisions until satisfied

Process:
1. DM with requirements (the more detailed the better)
2. Free evaluation and quote
3. Start work after confirmation
4. Delivery + explanation + after-sales

Note: No exam cheating or paper ghostwriting
Free to chat first, no pressure
```
