# 服务目录模块总览

> 本模块是 HOS 微商技术服务运营体系的服务产品基石，定义了可售服务的分层架构、定价逻辑与具体服务菜单，是接单报价与获客文案的核心依据。

## 文档清单

| 编号 | 文档 | 说明 |
|------|------|------|
| CAT-0001 | 01-四层服务模型.md | 引流品/标品/利润品/形象品分层架构 |
| CAT-0002 | 02-定价策略引擎.md | 工时×时薪×难度×紧急四维定价公式 |
| CAT-0003 | 03-服务菜单-程序设计.md | 代码调试/课设/毕设/脚本/网站/小程序六项服务 |
| CAT-0004 | 04-服务菜单-AI方向.md | 模型部署/Prompt工程/RAG/数据分析/AI应用五项服务 |
| CAT-0005 | 05-服务菜单-信息安全.md | CTF/渗透测试/安全加固/等保咨询四项服务 |
| CAT-0006 | 06-服务菜单-计算机基础.md | 算法辅导/实验辅导/考研辅导三项服务 |

## 使用建议

1. 新接单前优先查阅四层服务模型（CAT-0001），明确订单对应的产品层级与定位
2. 定价时使用定价策略引擎公式（CAT-0002），确保报价一致性与合理性
3. 根据客户技术方向匹配对应服务菜单：程序设计/AI/信息安全/计算机基础
4. 服务菜单中的工时估算与难度系数应结合实际项目动态调整，避免静态套用
5. 定期复盘各层级服务的转化率与利润率，优化产品结构与菜单更新
