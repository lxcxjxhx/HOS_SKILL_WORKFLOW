# 订单与财务模块总览

> 本模块是 HOS 微商技术服务运营体系的运营管理后端，覆盖订单跟踪、财务核算、客户复购与转介绍四大运营闭环，支撑业务可持续增长。

## 文档清单

| 编号 | 文档 | 说明 |
|------|------|------|
| ORD-0001 | 01-订单跟踪表.md | 订单全生命周期跟踪与状态管理 |
| ORD-0002 | 02-财务管理模板.md | 收入/支出/月度/季度/年度财务体系 |
| ORD-0003 | 03-客户复购运营模板.md | 客户分层/复购触发/沉睡唤醒/流失挽回 |
| ORD-0004 | 04-转介绍机制模板.md | 老带新激励/话术/流程/跟踪/复盘 |

## 使用建议

1. 每笔订单创建后立即录入订单跟踪表（ORD-0001），实时更新状态直至闭环
2. 财务模板按月/季/年度定期填报，确保收支数据完整可追溯
3. 客户复购运营需结合客户分层制定差异化触达策略，避免无差别推送
4. 转介绍机制需设置明确激励规则与跟踪流程，量化老带新转化效果
5. 定期复盘订单转化率、复购率与转介绍率三项核心指标，优化运营策略
