> **模块**: orders
> **文档编号**: ORD-0003
> **版本**: 1.0.0 | **最后更新**: 2026-07-26
> **适用阶段**: 冷启动 / 稳定期 / 扩张期

---

## 文档说明

本模板用于构建 HOS 微商技术服务业务的客户复购运营体系。微商技术服务(课设、毕设、项目辅导等)具有典型的周期性、季节性、技术栈迁移特征,复购运营是稳定期与扩张期的核心增长引擎。本文档提供框架、模型、话术、模板,可直接复制使用。

## 一、复购运营框架

### 1.1 复购价值公式

复购运营的底层价值可通过以下公式量化:

```
复购收入 = 客户基数 × 复购率 × 客单价 × 复购频次

客户LTV = 首单金额 + Σ(复购金额 × 折现因子)

复购净利润 = 复购收入 - 触达成本 - 让利成本 - 服务交付成本
```

**关键结论**:
- 复购客户的获客成本仅为新客户的 1/5 至 1/8
- 复购客户客单价通常比首单高 20%-40%(信任溢价)
- 复购率每提升 5%,长期利润可提升 25%-95%(经典零售法则,微商技术服务场景同样适用)

### 1.2 复购率基准

| 业务阶段 | 整体复购率基准 | 高价值客户复购率 | 备注 |
|---------|--------------|----------------|------|
| 冷启动期(0-6个月) | 15%-25% | 40%+ | 客户基数小,依赖口碑 |
| 稳定期(6-18个月) | 30%-45% | 60%+ | 标签体系成熟,触发精准 |
| 扩张期(18个月+) | 40%-55% | 70%+ | 自动化触达 + 人工精选 |

### 1.3 复购生命周期

```
[首单成交] → [交付满意期(0-7天)] → [静默期(7-30天)] → [触发窗口期(30-60天)]
                                                                    ↓
                                                            [复购成交] 或
                                                                    ↓
                                                       [沉睡期(60-90天)] → [流失期(90天+)]
                                                                    ↓
                                                            [唤醒/挽回]
```

**生命周期关键节点**:
- 第 7 天:满意度回访,埋下复购钩子
- 第 30 天:首次复购触发(技术栈迁移/新需求)
- 第 60 天:沉睡预警,主动触达
- 第 90 天:流失边缘,唤醒话术升级
- 第 180 天:正式流失,进入挽回池

## 二、客户分层模型

### 2.1 分层维度

按**消费金额**与**消费频次**两个维度,将客户分为四层:

| 分层 | 消费金额 | 消费频次 | 客户特征 | 运营策略 |
|------|---------|---------|---------|---------|
| S 级 - 高价值客户 | 累计 ≥ 2000 元 | ≥ 3 次 | 忠诚度高,客单价高,口碑传播者 | VIP 专属服务,优先内测,转介绍核心 |
| A 级 - 潜力客户 | 累计 500-2000 元 | 2 次 | 有复购意愿,客单价中等 | 需求挖掘,套餐升级,频次提升 |
| B 级 - 沉睡客户 | 累计 200-500 元 | 1 次,30-90 天未复购 | 单次成交后静默 | 场景触发唤醒,优惠刺激 |
| C 级 - 流失客户 | 累计 < 200 元 或 90 天+未复购 | 1 次 | 流失或仅咨询未成交 | 低成本挽回,内容种草 |

### 2.2 分层运营动作矩阵

```
┌─────────────┬──────────────────┬──────────────────┬──────────────────┐
│  分层        │  月度动作         │  季度动作         │  年度动作         │
├─────────────┼──────────────────┼──────────────────┼──────────────────┤
│  S 高价值    │ 1对1回访+需求预判 │ 专属套餐+内测邀请 │ 年度复盘+礼品+转介│
│  A 潜力      │ 场景触发+优惠推送 │ 套餐升级方案      │ 价值总结+续费引导 │
│  B 沉睡      │ 唤醒话术+内容触达 │ 优惠刺激+需求调研 │ 重新激活或归档    │
│  C 流失      │ 低频内容触达      │ 挽话话术+让利     │ 清理或挽回尝试    │
└─────────────┴──────────────────┴──────────────────┴──────────────────┘
```

## 四、复购触发场景与话术

### 4.1 课设季回访(5-6月、11-12月)

**触发条件**: 客户历史成交含课设服务,且当前为课设季前 2 周

**话术模板 A - 直接型**:
```
[客户昵称] 同学你好,我是之前帮你做 [上次项目名] 的 [你的称呼]。
最近课设季又要到了,这学期有没有新的课设任务需要支持?
上次合作你满意度不错的话,这次老客户可以享 9 折 + 优先排期。
```

**话术模板 B - 价值驱动型**:
```
[客户昵称],最近课程压力大不大?
上次 [项目名] 的代码你后续用得还顺手吗?
这学期如果遇到新的课设,我可以基于你上次的技术栈直接复用部分框架,
能帮你节省 30% 的时间。有需要随时找我。
```

**话术模板 C - 福利型**:
```
[客户昵称],老客户回馈周开始啦!
你是我们的复购客户,这学期课设可以享:
1. 老客 9 折
2. 免费需求评审 1 次
3. 交付后 7 天免费答疑
需要的话回复"1",我给你优先排期。
```

### 4.2 毕设季回访(3-5月)

**触发条件**: 客户历史成交含毕设服务,或大四/研三在读

**话术模板 A - 关怀型**:
```
[客户昵称],毕设进度怎么样了?
上次合作到现在有一段时间了,最近答辩准备得顺利吗?
如果中期检查、论文润色、答辩 PPT 有需要,老客户有专属优惠。
```

**话术模板 B - 升级型**:
```
[客户昵称],记得你上次做的是 [项目类型],
这次毕设如果是进阶版(比如加了算法/系统优化/可视化),
我可以基于上次的成果做迭代,比从零开始省时省钱。
方便的话发一下你的毕设题目,我帮你看看方案。
```

### 4.3 技术栈升级

**触发条件**: 客户历史技术栈出现重大版本更新或主流迁移

**话术模板**:
```
[客户昵称],提醒你一下,[技术栈名] 最近出了新版本/新框架,
你上次用的 [旧版本] 后续可能不再维护。
如果你后续课程或项目要用,我可以帮你:
1. 评估迁移成本
2. 提供新版本的 demo
3. 老客户享迁移服务 8 折
```

### 4.4 新服务上线

**触发条件**: 上线新服务类型,定向推送给相关标签客户

**话术模板**:
```
[客户昵称],跟你说个好消息,我们新上线了 [新服务名] 服务,
主要是解决 [具体痛点] 的。
你是老客户,所以第一时间通知你,前 10 名预约享早鸟价。
如果你或者同学有需要,可以直接锁名额。
```

### 4.5 老客专属优惠

**触发条件**: 客户分层为 S 级或 A 级,季度运营动作

**话术模板**:
```
[客户昵称],感谢你一直以来的信任。
作为我们的 [S/A] 级老客户,本季度你享有以下专属权益:
1. 全场服务 8.5 折
2. 优先排期权(旺季保证 48 小时内响应)
3. 免费技术咨询 1 次(30 分钟)
4. 转介绍奖励翻倍
权益有效期到 [日期],需要使用随时找我。
```

## 五、沉睡客户唤醒策略

### 5.1 唤醒分级

| 沉睡时长 | 唤醒级别 | 触达方式 | 让利力度 | 目标 |
|---------|---------|---------|---------|------|
| 30-60 天 | 一级唤醒 | 微信文字 + 内容触达 | 无让利,价值唤醒 | 重新激活需求 |
| 60-90 天 | 二级唤醒 | 微信文字 + 优惠券 | 中等让利(9 折) | 刺激成交 |
| 90-180 天 | 三级唤醒 | 语音/电话 + 大额优惠 | 较大让利(8 折+赠品) | 强力挽回 |
| 180 天+ | 流失挽回 | 挽话话术 + 最低价 | 最大让利(7 折+免费咨询) | 最后尝试 |

### 5.2 30 天唤醒话术(一级)

```
[客户昵称],好久没联系啦,最近学业怎么样?
上次 [项目名] 交付后用得还顺手吗?
如果有任何技术问题,随时可以问我,老客户答疑免费的。
另外最近整理了一份 [技术栈/方向] 的学习资料包,需要的话发你。
```

### 5.3 60 天唤醒话术(二级)

```
[客户昵称],有一阵子没合作了,最近忙吗?
跟你说一下,本月在做老客户回馈,你有一张 9 折券到 [日期] 到期,
另外还有免费需求评审 1 次。
如果近期有课设/项目/毕设相关需求,这是比较划算的窗口。
```

### 5.4 90 天唤醒话术(三级)

```
[客户昵称],最近好吗?距离上次合作有一段时间了。
说实话,你是我比较在意的客户,所以这次直接给你最大优惠:
1. 全场服务 8 折
2. 免费赠送 1 次技术答疑(1 小时)
3. 交付周期优先安排
不知道是最近没需求,还是上次体验有不到位的地方?
方便的话可以说说,我改进一下。
```

## 六、流失客户挽回策略

### 6.1 流失原因分类

| 流失原因 | 占比预估 | 挽回难度 | 挽话策略 |
|---------|---------|---------|---------|
| 无需求(毕业/转方向) | 40% | 高 | 保持关系,长期种草 |
| 价格原因 | 25% | 中 | 让利 + 套餐优化 |
| 体验不佳 | 20% | 中 | 道歉 + 补偿 + 改进承诺 |
| 找到替代 | 10% | 高 | 差异化价值 + 优惠 |
| 失联(换号/删好友) | 5% | 极高 | 多渠道触达 |

### 6.2 挽回话术模板

**场景 A - 无需求型**:
```
[客户昵称],好久不见。毕业之后转 [新方向] 了吗?
完全理解,职业路径变化很正常。
不过我们最近也在拓展 [新方向] 相关的服务,
如果你工作中遇到技术问题,或者有同事需要,
随时可以找我,老朋友价格肯定给力。
```

**场景 B - 价格原因型**:
```
[客户昵称],上次合作后就没再联系了,是不是价格方面有压力?
如果是的话,这次我直接给你老友价:[具体报价],
比上次低 [X]%,主要是我这边也想维持长期合作。
你看这个价格能接受吗?
```

**场景 C - 体验不佳型**:
```
[客户昵称],上次合作如果有什么不到位的地方,我先道歉。
后来我复盘了你的项目,确实在 [具体环节] 可以做得更好。
这次如果再合作,我承诺:
1. [具体改进点 1]
2. [具体改进点 2]
3. 交付不满意免费返工
希望给我一次证明的机会。
```

### 6.3 挽回优惠方案

| 挽回场景 | 优惠方案 | 使用条件 |
|---------|---------|---------|
| 首次挽回 | 8 折 + 免费咨询 1 次 | 30 天内成交 |
| 二次挽回 | 7 折 + 免费答疑 + 赠品 | 15 天内成交 |
| 体验补偿挽回 | 免费重做 1 项 + 后续 7 折 | 需确认体验问题属实 |

### 6.4 挽回失败收尾话术

```
[客户昵称],理解你目前没有需求,没关系。
加个好友不容易,咱们保持联系。
后续如果有任何技术问题,或者同学朋友需要,
随时找我,老朋友肯定给最优价。
祝学业顺利,保持联系。
```

## 八、复购运营节奏

### 8.1 月度运营动作清单

```markdown
## 月度复购运营 Checklist

### 第一周:数据复盘
- [ ] 导出上月复购数据,填写《月度复购数据追踪表》
- [ ] 更新客户分层,标记升降级客户
- [ ] 识别本月进入触发窗口期的客户(成交满 30 天)
- [ ] 识别本月进入沉睡期的客户(成交满 60 天)

### 第二周:触达执行
- [ ] 对触发窗口期客户执行复购话术触达
- [ ] 对一级沉睡客户(30-60 天)执行唤醒话术
- [ ] 对 S 级客户执行 1 对 1 关怀回访
- [ ] 朋友圈发布 1-2 条老客专属内容

### 第三周:跟进转化
- [ ] 跟进触达客户的回复,推进成交
- [ ] 对未回复客户执行二次触达(换话术/换渠道)
```
