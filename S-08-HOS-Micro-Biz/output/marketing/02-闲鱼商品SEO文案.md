## 一、闲鱼平台规则简述

闲鱼作为二手交易平台，对技术服务类商品有明确的合规边界。技术服务微商运营者必须理解并遵守平台规则，才能实现长效稳定经营，避免账号降权或商品下架。

### 1.1 技术服务合规边界

- **允许范围**：原创代码交付、技术咨询服务、编程辅导、项目代做（需明确为技术服务而非代写论文）、数据分析与可视化、部署运维支持
- **禁止范围**：代写学术论文、代考、破解他人系统、提供黑灰产工具、侵犯第三方知识产权的代码转售
- **灰色地带（高风险）**：毕业设计代做（需规避"代写"字眼，改为"技术指导""代码实现""项目开发"）、刷量服务、外挂脚本
- **资质要求**：涉及等保测评、安全审计等服务，建议在描述中注明"合法授权范围内"并提供服务协议模板

### 1.2 不被降权/下架的注意事项

| 风险点 | 规避策略 |
|--------|----------|
| 标题堆砌关键词 | 标题不超过30字，关键词自然融入，不重复超过2次 |
| 描述含联系方式 | 严禁在商品描述、图片中出现微信/QQ/手机号，私域引流通过"咨询"引导 |
| 商品类目错放 | 技术服务统一放在"虚拟商品 > 技术服务"或"教育培训 > 技能培训" |
| 重复铺货 | 同一服务不同价格上架不超过3个链接，差异化标题与描述 |
| 价格异常 | 9.9引流品需有真实交付内容，避免"0.01元咨询"等极端低价 |
| 交易纠纷 | 交付前签订需求确认书，保留聊天记录与交付凭证 |
| 违禁词 | 规避"包过""保过""100%""最专业""第一"等绝对化用语 |

### 1.3 账号权重维护

- 保持账号活跃度：每周上架2-3个新品，每日签到、回复咨询
- 提升芝麻信用分：绑定芝麻信用，分值650以上可获得"极好"标签
- 积累好评：引导满意客户确认收货并五星好评，好评率维持在95%以上
- 响应速度：咨询消息5分钟内回复，转化率提升30%以上

## 二、标题公式

闲鱼标题是搜索流量的核心入口，需兼顾平台搜索算法与用户点击意愿。

### 2.1 标准公式

```
[服务类型] + [技术栈] + [卖点] + [适用人群]
```

### 2.2 公式拆解

| 要素 | 说明 | 示例 |
|------|------|------|
| 服务类型 | 明确交付物形式 | 代做/辅导/部署/调试/开发 |
| 技术栈 | 具体技术关键词 | Python/Java/SpringBoot/ChatGPT |
| 卖点 | 差异化优势 | 一对一/包修改/源码交付/24小时 |
| 适用人群 | 精准定位受众 | 大学生/课设/毕设/考研/在职 |

### 2.3 标题示例

```
✓ Python数据分析代做 大学生课设毕设 一对一辅导包修改源码交付
✓ SpringBoot项目开发 Java毕业设计代做 小程序后端24小时出稿
✓ ChatGPT大模型部署 RAG知识库搭建 企业AI应用定制开发
✓ 计算机考研408辅导 数据结构算法 一对一批改作业真题精讲
✓ 网络安全渗透测试 CTF比赛指导 漏洞扫描报告合规审计
```

### 2.4 标题禁忌

- 单纯关键词堆砌：`Python Java C++ 代做 课设 毕设 数据结构`
- 无服务类型：`计算机专业大学生看过来专业团队`
- 夸大承诺：`包过毕设100%通过率最专业团队`
- 含联系方式：`Python代做加V咨询xxx`

## 六、闲鱼定价策略

定价策略采用三层漏斗结构，引流品获客、标品成交、利润品提升客单价。

| 策略 | 价格区间 | 目的 | 典型商品 |
|------|----------|------|----------|
| 低价引流品 | 9.9-29.9 | 吸引咨询，建立私域入口 | 代码调试咨询/作业答疑/单题讲解 |
| 正价标品 | 100-500 | 主要成交，覆盖课设/小型项目 | 课设代做/数据分析/小型毕设模块 |
| 高端利润品 | 500-2000 | 提升客单价，高净值客户 | 完整毕设/大模型部署/企业级项目 |

### 6.1 定价执行细节

**低价引流品（9.9-29.9）**
- 标价9.9元，实际为"咨询定金"，沟通后按需求补差价
- 商品描述明确"标价为咨询费，实际价格私信评估"
- 目标：日均咨询量10-20人，私域转化率30%

**正价标品（100-500）**
- 课设类：100-200元，按题目难度浮动
- 数据分析类：200-400元，按数据量与可视化要求
- 小型毕设模块：300-500元，如单独的爬虫/后端模块
- 目标：成交转化率40%，复购率20%

**高端利润品（500-2000）**
- 完整毕设：800-1500元，含代码+文档+答辩指导
- 大模型部署：1000-2000元，含私有化部署+调优
- 企业级项目：1500-3000元，按工时与人天核算
- 目标：月均3-5单，贡献60%利润

### 6.2 价格锚定技巧

- 商品页展示"市场价 ~~1500~~ 限时888"，制造稀缺感
- 引流品描述中植入"同类服务市场价300+，新品限时9.9咨询"
- 高端品设置"分期付款"选项，降低决策门槛

## 八、私域引流话术

闲鱼严禁在商品页直接留联系方式，私域引流需通过咨询话术自然过渡，引导客户主动添加。

```
【咨询开场话术】
你好，看到你对[服务类型]感兴趣，请问具体是什么需求呢？
方便的话发一下[学校/专业/题目要求]，我帮你评估一下工作量。

【需求确认话术】
好的，需求我了解了。这个项目大概需要[X]天完成，
费用在[价格区间]左右。为了保证沟通效率，
我加你微信发一些案例参考，你看方便吗？

【私域引导话术（3种变体）】
变体1（案例引导）：
我这边有一些类似项目的案例和源码演示，
微信上发你看看，更有参考价值。
闲鱼上图片压缩严重，微信看更清晰。

变体2（效率引导）：
这个需求比较复杂，细节沟通比较多，
```
