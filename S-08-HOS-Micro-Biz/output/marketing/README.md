# 获客文案模块总览

> 本模块是 HOS 微商技术服务运营体系的获客引擎，提供多平台内容营销模板与推广脚本，驱动流量获取与线索转化。

## 文档清单

| 编号 | 文档 | 说明 |
|------|------|------|
| MKT-0001 | 01-朋友圈文案模板集.md | 案例/知识/促销/故事四类朋友圈文案 |
| MKT-0002 | 02-闲鱼商品SEO文案.md | 标题公式+商品描述+SEO关键词优化 |
| MKT-0003 | 03-小红书种草笔记模板.md | 学习笔记/接单故事/避坑指南三类内容 |
| MKT-0004 | 04-社群推广脚本.md | 技术分享+限时优惠的社群推广SOP |

## 使用建议

1. 根据目标客群选择平台：技术圈层优先社群推广，学生群体优先小红书与闲鱼
2. 朋友圈文案四类轮换发布，保持内容多样性与稳定曝光频次
3. 闲鱼商品文案需嵌入SEO关键词，提升搜索可见度与自然流量
4. 社群推广脚本配合限时优惠使用，制造转化紧迫感与行动指令
5. 文案内容需与服务目录中的服务项保持一致，避免承诺超出能力范围
