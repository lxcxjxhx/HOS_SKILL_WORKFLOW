## 一、考试代考类红线

### 1.1 定义

考试代考指以任何形式替代考生本人参加考试的行为,包括但不限于:

- 在线考试期间远程操作考生设备作答
- 期末考试、期中考试、随堂测试的代答
- 职业资格认证考试代考(如 PMP、CFA、软考)
- 语言能力考试代考(如四六级、雅思、托福)
- 驾驶证理论考试、行业准入考试代考
- 开发用于绕过在线监考系统的工具(虚拟摄像头、AI 代答、屏幕共享作弊)

### 1.2 典型话术识别

```
【高风险话术信号】
- "考试的时候你帮我远程操作一下"
- "我开个共享屏幕,你来答题"
- "这个认证考试很简单,你帮我过了给你 X 千"
- "能不能做个自动答题的脚本,考试时挂着"
- "监考不严,你替我考一下,没人发现"
- "帮我做个虚拟摄像头,考试时放录播"
- "在线考试系统有没有漏洞可以绕过"
- "我出双倍价格,你帮我搞定这场考试"
```

### 1.3 法律风险说明

```
【法律风险】
1. 《刑法》第二百八十四条之一:组织考试作弊罪、非法出售提供试题答案罪、
   代替考试罪。代考行为情节严重的,处三年以下有期徒刑或拘役,并处罚金。
2. 《教育法》第七十九条:在国家教育考试中作弊的,由教育行政部门宣布考试
   无效,责令停止相关考试,没收违法所得。
3. 《学位条例》及高校学籍管理规定:代考行为可导致开除学籍、撤销学位。
4. 职业资格认证代考:可能触犯《刑法》第二百八十条伪造身份证件罪
   (使用假身份证代考),并终身取消认证资格。
5. 远程代考涉及跨地域,可能构成"组织作弊罪"共犯。

【对服务方的风险】
- 刑事责任:作为代考实施者或工具提供者,可能被追究刑事责任
- 民事责任:考生可主张服务无效要求退款,甚至反向举报
- 声誉风险:一旦曝光,品牌信誉彻底崩塌
- 平台风险:所在平台可能永久封禁账号
```

### 1.4 拒绝话术模板

```
【标准拒绝话术】
您好,感谢您的信任。关于考试代考的需求,很抱歉我们无法提供此类服务。

原因说明:
考试代考属于《刑法》明确禁止的行为,涉及代替考试罪与组织考试作弊罪。
我们作为技术服务方,不能参与任何形式的考试舞弊,这也事关您本人的学籍
与前途。

如果您在备考过程中遇到技术性问题,我们很乐意提供合规的辅导服务,例如:
- 考试涉及的知识点讲解
- 编程题解题思路辅导
- 模拟环境搭建指导

希望您理解,祝您考试顺利。
```

### 1.5 替代服务建议

```
【可提供的合规替代】
1. 考试知识点辅导:按小时计费,讲解考试范围内的技术难点
2. 模拟题练习环境搭建:帮助客户在本地搭建练习环境(不含真题)
3. 编程类考试解题思路指导:讲解算法思路、代码结构(不代答真题)
4. 认证考试备考资料整理:协助整理官方考纲范围内的学习笔记
5. 在线学习平台开发:为客户开发合规的在线学习/练习系统(不涉及真题库)
```

## 二、论文代写类红线

### 2.1 定义

论文代写指以任何形式为他人代笔撰写学术论文正文的行为,包括但不限于:

- 本科毕业论文代写
- 硕士、博士学位论文代写
- 学术期刊论文代写
- 课程作业论文代写(如计科课程的设计报告)
- 开题报告、文献综述代写
- 代写后降重、洗稿以通过查重

### 2.2 典型话术识别

```
【高风险话术信号】
- "帮我写毕业论文,题目是 XXX"
- "直接给我一篇完整的,我自己也看不懂内容"
- "开题报告、正文、答辩 PPT 一套包了"
- "查重率要低于 10%,你负责降重"
- "不要加注释,看起来像我自己写的"
- "我提供思路,你帮我写出来,字数 X 万"
- "期刊论文帮我代写一篇,核心期刊"
- "文献综述帮我凑字数就行"
```

### 2.3 法律风险说明

```
【法律风险】
1. 《学位条例》第十七条:学位授予单位对舞弊作伪者,可撤销学位。
2. 《高等学校预防与处理学术不端行为办法》(教育部令第 40 号):
   代写论文属于严重学术不端,买卖论文者将被开除学籍或撤销学位。
3. 《科研诚信案件调查处理规则》:代写论文纳入科研失信记录,影响终身。
4. 2015 年国务院学位委员会《关于印发<学位证书和学位授予信息管理办法>
   的通知》:明确将代写纳入撤销学位情形。
5. 民事风险:代写合同因违反公序良俗可能被认定无效,服务方难以主张尾款。

【对服务方的风险】
- 行政处罚:被教育部门通报,纳入失信名单
- 民事纠纷:客户举报后难以维权,已收款可能被追回
- 刑事风险:大规模代写可能被认定为非法经营
- 声誉风险:学术圈曝光后无法继续承接教育类业务
```

### 2.4 拒绝话术模板

```
【标准拒绝话术】
您好,关于论文代写的需求,很抱歉我们无法承接。

原因说明:
论文代写属于教育部明确认定的严重学术不端行为,一旦查实会导致撤销学位、
开除学籍,并纳入科研失信记录。我们作为技术服务方,不提供任何形式的
论文代笔服务,这也是对您学术前途的保护。

如果您在论文写作过程中需要技术性辅助,我们可以提供以下合规服务:
- 论文涉及的技术实现指导(代码部分)
- 研究方法与思路梳理
- 论文格式排版
- 查重后的语言润色(不改变核心观点)
- 答辩 PPT 制作与技术演示辅导

希望您理解,如需以上服务可随时沟通。
```

### 2.5 替代服务建议

```
【可提供的合规替代】
1. 论文技术实现辅导:指导客户完成论文中涉及的代码开发(客户亲自写)
2. 研究思路咨询:协助梳理研究框架、技术路线(不代写正文)
3. 论文排版服务:按学校模板进行格式调整(Word / LaTeX)
4. 语言润色:对客户已写好的初稿进行语言优化(不代写)
5. 答辩辅导:模拟答辩、讲解技术细节、PPT 优化
6. 文献检索指导:教客户使用知网、Web of Science 等数据库(不代写综述)
7. 查重降重建议:提供合规的语言改写建议(不提供洗稿服务)
```

## 三、恶意攻击类红线

### 3.1 定义

恶意攻击指未经授权对他人信息系统实施入侵、破坏、窃取的行为,包括但不限于:

- 未经授权的渗透测试与漏洞利用
- 破解他人账号密码、绕过身份认证
- DDoS 攻击、CC 攻击
- 开发木马、后门、键盘记录器、远控工具
- 开发钓鱼页面、伪造网站
- 破解软件授权、绕过 DRM
- 窃取个人隐私数据、拖库脱裤
- 攻击基础设施(电网、金融、政务系统)

### 3.2 典型话术识别

```
【高风险话术信号】
- "帮我黑入 XXX 的账号"
- "破解一下这个 WiFi 密码"
- "能不能 DDoS 这个网站,我给你钱"
- "帮我做个木马,能控制别人电脑"
- "写个键盘记录器给我"
- "帮我做个钓鱼页面,套别人的密码"
- "这个系统有漏洞,帮我利用一下"
- "破解这个软件的授权,去掉验证"
- "帮我拖一下这个网站的数据库"
- "做个远控,能绕过杀软的"
```

### 3.3 法律风险说明

```
【法律风险】
1. 《刑法》第二百八十五条:非法侵入计算机信息系统罪、非法获取计算机信息
   系统数据罪、非法控制计算机信息系统罪。情节严重的,处三年以下有期徒刑;
   情节特别严重的,处三年以上七年以下有期徒刑。
2. 《刑法》第二百八十六条:破坏计算机信息系统罪。造成严重后果的,处五年
   以下有期徒刑;后果特别严重的,处五年以上有期徒刑。
3. 《刑法》第二百八十六条之一:拒不履行信息网络安全管理义务罪。
4. 《刑法》第二百八十七条:利用计算机实施金融诈骗、盗窃、贪污、挪用公款
   等犯罪的,从重处罚。
5. 《网络安全法》第二十七条:任何个人和组织不得从事非法侵入他人网络、
   干扰他人网络正常功能、窃取网络数据等危害网络安全的活动。
6. 《数据安全法》《个人信息保护法》:窃取、非法提供个人信息可追究刑责。

【对服务方的风险】
- 刑事责任:直接实施者或工具提供者均可被追究刑责
- 共犯认定:明知用于违法仍提供工具,构成共同犯罪
- 民事赔偿:需赔偿受害方全部损失
- 没收违法所得:全部收入将被追缴
```

### 3.4 拒绝话术模板

```
【标准拒绝话术】
您好,关于您提到的需求,我们需要先确认一下背景。

如果是未经授权的对他人系统的访问、破解、攻击行为,很抱歉我们无法提供
任何支持。这类行为违反《刑法》第二百八十五条、二百八十六条,属于非法
侵入计算机信息系统罪、破坏计算机信息系统罪,无论是否牟利均构成犯罪。

如果您是企业安全负责人或系统所有者,需要对自己拥有的系统进行安全评估,
请提供以下材料后我们可以继续沟通:
- 系统所有权证明(域名备案、企业归属)
- 书面授权测试书(加盖公章)
- 测试范围与边界说明

我们提供合规的安全评估服务,包括漏洞扫描、渗透测试、代码审计,均需在
书面授权范围内进行。期待您的理解与配合。
```

### 3.5 替代服务建议

```
【可提供的合规替代】
1. 授权渗透测试:客户提供书面授权书,对指定系统进行安全评估
2. 代码审计:对客户自有代码进行安全漏洞审查
3. 安全培训:企业内网安全意识培训、开发安全培训
4. 漏洞复现环境搭建:搭建隔离环境复现公开漏洞(仅供研究学习)
5. CTF 训练平台开发:为高校或企业开发合规的 CTF 竞赛平台
6. 安全工具开发:开发合规的扫描器、WAF、IDS 等防御类工具
7. 应急响应服务:对已发生的安全事件提供取证与修复支持
```

## 四、作弊工具类红线

### 4.1 定义

作弊工具指开发用于破坏公平性、绕过规则限制的自动化工具,包括但不限于:

- 刷课脚本(自动播放、自动答题)
- 抢课脚本、秒杀外挂
- 自动刷题、题库爬取后自动答题
- 多开工具、改分工具
- 绕过验证码、绕过风控
- 游戏外挂(自动打怪、透视、自瞄)
- 票务系统抢票外挂
- 平台薅羊毛自动化(批量注册、虚假交易)

### 4.2 典型话术识别

```
【高风险话术信号】
- "帮我写个刷课脚本,自动播放自动答题"
- "能不能做个抢课外挂,秒选的"
- "这个学习平台太烦了,帮我自动刷完"
- "做个刷题脚本,题库爬下来自动答"
- "游戏外挂会做吗,透视自瞄"
- "帮我抢演唱会票,做个抢票脚本"
- "做个多开,能同时登几十个号"
- "这个考试系统能不能改分"
- "帮我绕过这个网站的风控"
- "做个薅羊毛脚本,批量薅"
```

### 4.3 法律风险说明

```
【法律风险】
1. 《刑法》第二百八十五条:提供侵入、非法控制计算机信息系统程序、工具罪。
   向他人提供专门用于侵入、非法控制计算机信息系统的程序、工具,情节严重的,
   处三年以下有期徒刑。
2. 《刑法》第二百八十六条:破坏计算机信息系统罪。外挂、脚本若造成系统
   异常,可追究刑责。
3. 《反不正当竞争法》第十二条:利用技术手段妨碍、破坏其他经营者合法提供
   的网络产品正常运行,构成不正当竞争。
4. 《网络游戏管理暂行办法》:开发、销售游戏外挂属于违法行为。
5. 平台规则:刷课、刷量、薅羊毛违反各平台服务协议,可能导致账号封禁、
   民事索赔。
6. 《刑法》第二百八十七条之一:非法利用信息网络罪,为实施诈骗等违法
   活动发布信息或提供工具可入罪。

【对服务方的风险】
- 刑事责任:工具提供者与使用者可能构成共同犯罪
- 民事赔偿:被侵权平台可主张经济赔偿
- 平台追责:账号封禁、资金冻结
- 道德风险:破坏教育公平、市场公平
```

### 4.4 拒绝话术模板

```

无法承接。

原因说明:

- 自动化办公脚本(处理您自己的文档与数据)
- 正规的题库练习系统开发(不含真题爬取)

希望您理解我们的立场,期待在合规范围内为您提供帮助。
```

### 4.5 替代服务建议

## 五、违法违规项目类红线

### 5.1 定义

违法违规项目指直接违反法律法规、危害社会公共利益的项目,包括但不限于:

- 赌博网站、博彩系统、彩票外挂
- 色情直播、成人平台、擦边内容平台
- 诈骗系统(杀猪盘、虚假投资、庞氏骗局)
- 资金盘、传销系统
- 钓鱼网站、虚假身份生成
- 洗钱、跑分平台
- 群控系统、养号系统、虚假流量
- 虚假宣传、刷单炒信系统
- 违禁品交易平台(毒品、枪支、烟草)
- 未成年保护红线相关(诱导未成年、儿童色情)

### 5.2 典型话术识别

```
【高风险话术信号】
- "帮我做个博彩网站,赔率可控的那种"
- "色情直播平台会做吗"
- "做个资金盘,返利模式"
- "帮我搭个杀猪盘,话术系统也要"
- "洗钱相关的,跑分平台"
- "群控系统,能管几千个号"
- "帮我做个虚假投资平台"
- "做个传销系统,三级分销"
- "未成年向的内容平台"(需高度警惕)
```

## 六、灰色地带识别与决策

### 6.1 辅导 vs 代写边界

```
【边界判定原则】
合规辅导(允许):
- 讲解思路、原理、方法
- 指导客户调试代码
- 审查客户已写的代码并提建议
- 提供片段示例代码供参考
- 协助搭建开发环境
- 答疑解惑

违规代写(禁止):
- 直接产出完整可交付的论文正文
- 代写核心代码且客户无法理解
- 客户未参与开发,仅提供成品
- "你写好了发我,我看着改改"实为代写
- 客户拒绝任何沟通,只要成品

【判定标准】
1. 客户是否实质参与创作过程?
   - 是 → 合规辅导
   - 否 → 代写,拒单
2. 交付物是否为客户独立完成的成果?
   - 是 → 合规
   - 否 → 代写,拒单
3. 服务方是否产出"成品级"内容?
   - 仅提供指导/片段 → 合规
   - 产出完整正文/完整代码 → 代写,拒单
```

### 6.2 授权测试 vs 恶意攻击边界

```
【边界判定原则】
合规授权测试(允许):
- 客户提供书面授权书(加盖公章)
- 客户是系统所有者或被所有者书面授权
- 测试范围明确,边界清晰
- 测试不涉及生产数据破坏
- 出具正式渗透测试报告

违规恶意攻击(禁止):
- 无书面授权
- 客户非系统所有者
- "朋友让我测测他的系统"但无书面授权
- "自己公司系统"但无权属证明
- 测试范围模糊或越界
- 要求提供攻击工具用于"其他用途"

【判定标准】
1. 是否有书面授权文件?
   - 是 → 进入下一步
   - 否 → 拒单
2. 客户是否为系统所有者或获授权方?
   - 是,有证明 → 进入下一步
   - 否或无证明 → 拒单
3. 测试范围是否清晰可控?
   - 是 → 可承接
   - 否 → 要求明确范围,否则拒单
```

### 6.3 数据采集 vs 爬虫滥用边界

```
【边界判定原则】
合规数据采集(允许):
- 目标站点 robots.txt 允许
- 采集频率合理,不影响目标站点运行
- 采集公开数据,不涉及个人信息
- 有明确合法用途
- 遵守目标站点服务协议

违规爬虫滥用(禁止):
- 违反 robots.txt
- 高频请求导致目标站点拒绝服务
- 采集个人信息(手机号、身份证、地址)
- 绕过反爬机制(验证码、登录)
- 采集后用于违法用途
- 采集受版权保护的内容并商用

【判定标准】
1. 目标数据是否为公开非个人数据?
   - 是 → 进入下一步
   - 否(个人信息)→ 拒单
2. 采集行为是否遵守 robots.txt 与服务协议?
   - 是 → 进入下一步
   - 否 → 拒单
3. 采集频率是否合理?
   - 是 → 可承接
   - 否 → 要求降低频率,否则拒单
```

### 6.4 安全研究 vs 武器化边界

```
【边界判定原则】
合规安全研究(允许):
- 在隔离环境复现已公开漏洞(CVE)
- 编写漏洞分析报告
- 开发防御性工具(检测、修复)
- 向厂商负责任披露漏洞
- 学术性 PoC(不发布完整利用代码)

违规武器化(禁止):
- 开发可直接用于攻击的利用工具
- 打包出售漏洞利用代码
- 开发绕过安全软件的免杀工具
- 开发针对特定目标的攻击框架
- 未授权披露 0day 漏洞

【判定标准】
1. 产出物是否为防御性或学术性?
   - 是 → 可承接
   - 否(攻击性工具)→ 拒单
2. 漏洞信息是否通过合规渠道披露?
   - 是 → 可承接
   - 否(公开发布或出售)→ 拒单
3. 是否在隔离环境进行?
   - 是 → 可承接
   - 否(影响真实系统)→ 拒单
```

### 6.5 灰色地带处理流程

```
【灰色地带处理流程】
1. 识别为灰色地带后,暂停报价与开工
2. 要求客户补充以下材料:
   - 项目用途说明(书面)
   - 授权文件(如涉及第三方系统)
   - 资质证明(如涉及特许行业)
   - 学校或企业政策(如涉及学术)
3. 将需求与补充材料提交合规复核:
   - 复核人:合规主管或指定复审人
   - 复核时限:24-48 小时
   - 复核结论:通过 / 附条件通过 / 拒单
4. 复核通过后方可继续流程
5. 复核记录归档,保留至少 2 年
6. 执行过程中如发现实际用途偏离,立即终止
```

```
4. 同步报备公司法务或外部顾问
```

```
1. 立即暂停开发
2. 与客户沟通确认实际用途
3. 如涉及红线,终止合作并留存证据
4. 如涉及灰色地带,提交合规复核
5. 已收取的定金按合同约定处理(红线终止不退款)
6. 向合规主管报备
```

---

## 十、红线清单维护

### 10.1 更新机制

```
【清单更新机制】
1. 每季度由合规主管组织一次红线清单评审
2. 评审依据:
   - 新颁布或修订的法律法规
   - 行业新出现的违规模式
   - 内部遇到的典型案例
   - 监管部门的风险提示
3. 更新内容经法务(或外部顾问)审核
4. 更新后全员培训,签字确认
5. 历史版本归档保留
```

### 10.2 典型案例库

```
【案例库维护】
1. 每次红线拒单后,脱敏形成典型案例
2. 案例包含:
   - 需求摘要
   - 红线类型
   - 识别过程
   - 拒绝话术
   - 客户反应
   - 经验总结
3. 案例库按月更新,作为新人培训教材
4. 案例库严格保密,仅内部可见
```
