# 沟通模板与SOP模块总览

> 本模块是 HOS 微商技术服务运营体系的沟通标准化层，提供从需求确认到交付售后的全流程话术与SOP，保障沟通质量与服务一致性。

## 文档清单

| 编号 | 文档 | 说明 |
|------|------|------|
| TPL-0001 | 01-需求确认checklist.md | 接单前六维需求核对清单与话术 |
| TPL-0002 | 02-沟通话术库.md | 客户生命周期八大阶段全场景话术 |
| TPL-0003 | 03-报价话术模板.md | 报价呈现/议价应对/加价跟进话术矩阵 |
| TPL-0004 | 04-交付与售后SOP.md | 交付前/执行中/验收/售后/异常处理全流程SOP |

## 使用建议

1. 接单第一步使用需求确认checklist（TPL-0001），避免需求理解偏差导致返工
2. 按客户生命周期阶段匹配沟通话术库（TPL-0002）对应章节，保持沟通节奏
3. 报价时同时参考服务目录定价与报价话术模板（TPL-0003），确保口径统一
4. 交付与售后SOP（TPL-0004）为强制执行流程，不可跳过验收环节
5. 异常处理SOP用于应对延期、纠纷、退款等突发场景，遇异常立即启用
