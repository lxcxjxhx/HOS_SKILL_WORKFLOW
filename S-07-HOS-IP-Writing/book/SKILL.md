# 技术书籍写作系统

> 从大纲到出版的全流程支持，覆盖技术书籍、教程、博客合集三种类型。

---

## 触发条件

| 触发场景 | 示例表达 |
|---------|---------|
| 写书 | "写一本技术书"、"帮我写书" |
| 写教程 | "写一本入门教程" |
| 博客转书 | "把系列博客整理成书" |
| 生成目录 | "生成书籍目录" |
| 写章节 | "写第 X 章" |
| 出版指导 | "这本书应该怎么出版" |

**不触发**：单篇文章（→ `blog`），学术论文（→ `paper`）。

---

## 书籍类型速查

| 类型 | 结构 | 每章篇幅 | 全书篇幅 | 代码量 |
|------|------|---------|---------|--------|
| 技术书籍 | Part → Chapter → Section | 8000-15000 字 | 8-15 万字 | 每章 5-10 个示例 |
| 教程书籍 | Lesson → Step → Exercise | 5000-10000 字 | 5-10 万字 | 每章 10-15 个步骤 |
| 博客合集 | Part → Chapter（原文章） | 3000-8000 字 | 5-12 万字 | 保留原有代码 |

## 执行流程

### Phase 1: 需求分析

**操作步骤**：
1. 确认书籍类型（技术书/教程/博客合集）
2. 确认目标读者和技术水平
3. 确认核心主题和覆盖范围
4. 确认预计章节数量
5. 确认出版方式（传统出版/自出版）

**质量门禁**：书籍类型确定；目标读者明确；核心主题列表完成。

### Phase 2: 目录生成

**操作步骤**：
1. 生成完整目录结构（Part → Chapter → Section）
2. 每章标注：学习目标、主要内容、预计篇幅
3. 生成章节依赖关系（确保逻辑递进）
4. 等待用户确认或调整

**质量门禁**：目录覆盖所有核心主题；章节间有逻辑递进关系。

### Phase 3: 章节撰写

**操作步骤**：
1. 每章结构：
   - 章节引言（问题引入、学习目标）
   - 理论讲解（概念、原理、最佳实践）
   - 代码示例（可运行代码、详细注释）
   - 实战案例（完整项目案例）
   - 常见问题（FAQ、陷阱提示）
   - 本章小结（要点回顾）
   - 练习题（选择题、编程题，分难度）
2. 确保代码风格统一、注释完整
3. 确保全书术语一致

**质量门禁**：每章包含理论+代码示例+练习题；代码可运行。

### Phase 4: 审校优化

**操作步骤**：
1. 技术准确性审查
2. 语言风格统一
3. 交叉引用检查
4. 术语一致性检查
5. 生成前言、附录（参考文献、术语表、索引）

**质量门禁**：全书术语一致；交叉引用正确；风格统一。

## 博客转书籍流程

当用户提供博客合集时：
1. 读取所有博客文章
2. 分析主题，重新组织为书籍目录
3. 补充章节过渡和引言
4. 统一术语和风格
5. 生成前言和附录

---

## 出版指导

| 出版方式 | 适合场景 | 推荐平台/出版社 |
|---------|---------|---------------|
| 传统出版 | 追求权威性和广泛传播 | 电子工业、机械工业、人民邮电 |
| 自出版 | 快速迭代和直接面对读者 | GitBook、Leanpub |
| 混合模式 | 先验证再传统出版 | 先 Leanpub → 再联系出版社 |

## 输出规范

遵循 `shared/output-conventions.md` 中的 book 部分：
- 输出目录：`book/output/{book-name}/`
- 目录结构：

```
{book-name}/
  README.md          # 书籍概览
  toc.md             # 目录
  chapters/
    ch01-{title}.md
    ch02-{title}.md
  appendix/
    references.md
    glossary.md
```

---

## 约束

1. **代码可运行**：所有代码示例必须可运行
2. **引用规范**：正确引用他人工作
3. **循序渐进**：由浅入深，避免跳跃
4. **读者优先**：始终从读者角度思考

## 上下文接口

**读取**（从 `shared/context-schema.md`）：
- `project.*`：项目名称、描述、技术栈
- `output.*`：语言偏好、风格偏好
- `blog.articles`：来自 blog 子技能的系列文章

**写入**（供下游技能使用）：
- `book.toc`：书籍目录
- `book.chapters`：书籍章节内容
