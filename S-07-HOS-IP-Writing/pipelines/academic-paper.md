# 管线：学术全流程

> paper → review → 投稿

---

## 触发条件

用户表达以下意图时激活此管线：
- "我要写一篇关于 XX 的论文"
- "准备投稿 XX 会议/期刊"
- "paper writing"

## 链路

```
paper (Stage 1-5) → review (学术润色) → 投稿
```

## 执行步骤

### Step 1: 激活 paper 子技能

1. 进入 paper 的五阶段写作流程
2. 完成 Stage 1-5，产出论文终稿
3. 输出 IP-Context 摘要：
   ```
   - 研究问题: {一句话}
   - 核心贡献: {列表}
   - 目标投稿: {会议/期刊名}
   - 论文草稿路径: paper/output/{name}-final.md
   ```

### Step 2: 激活 review 子技能

1. 读取 paper 产出的终稿
2. 执行学术润色流程：
   - 学术表达优化（口语化 → 学术用语）
   - AI 填充词清除
   - 引用格式规范化（APA/IEEE/GB/T 7714）
   - 段落结构改进
3. 输出润色报告：修改清单 + 质量评分

### Step 3: 投稿准备

1. 根据目标投稿类型检查格式：
   - 篇幅限制
   - 模板格式
   - 引用风格
2. 生成投稿检查清单

## 质量门禁

| 节点 | 标准 |
|------|------|
| paper Stage 5 完成 | 篇幅在目标范围 ±10%；逻辑链完整 |
| review 完成 | AI 填充词清零；主动语态 > 80%；术语一致 |
| 投稿准备完成 | 格式 100% 符合目标要求 |

## 上下文传递

```
paper → review:
  传递: 论文终稿 + 研究问题 + 核心贡献 + 目标投稿
  格式: Markdown 文件 + IP-Context 摘要

review → 投稿:
  传递: 润色后终稿 + 修改报告 + 格式检查报告
  格式: Markdown 文件
```
