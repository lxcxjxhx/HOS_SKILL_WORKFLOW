# 管线：技术影响力建设

> blog → book → review

---

## 触发条件

用户表达以下意图时激活此管线：
- "我要建立技术影响力"
- "把系列文章整理成书"
- "写一个系列教程"

## 链路

```
blog (系列文章) → book (整理成书) → review (全书润色)
```

## 执行步骤

### Step 1: 激活 blog 子技能（系列文章）

1. 确定系列主题和文章数量（建议 5-15 篇）
2. 生成系列大纲：
   - 每篇文章的标题和核心论点
   - 文章间的逻辑递进关系
   - 发布节奏建议
3. 逐篇撰写，每篇遵循 blog 执行流程
4. 输出系列文章集 + IP-Context 摘要

### Step 2: 激活 book 子技能（整理成书）

1. 读取 blog 产出的系列文章集
2. 执行博客转书籍流程：
   - 分析已有文章主题和结构
   - 重新组织为书籍目录（Part → Chapter）
   - 补充章节过渡和引言
   - 统一术语和风格
   - 生成前言和附录
3. 输出书稿 + IP-Context 摘要

### Step 3: 激活 review 子技能（全书润色）

1. 读取 book 产出的书稿
2. 执行全书润色：
   - 风格统一检查
   - 术语一致性检查
   - 代码示例验证
   - 交叉引用检查
3. 输出润色后终稿 + 修改报告

## 质量门禁

| 节点 | 标准 |
|------|------|
| blog 每篇完成 | 代码示例可运行；SEO 检查通过；独立可读 |
| book 目录完成 | 覆盖所有核心主题；章节间逻辑递进 |
| book 书稿完成 | 章节过渡自然；术语统一 |
| review 完成 | 全书风格统一；无 AI 套路残留 |

## 上下文传递

```
blog → book:
  传递: 系列文章集 + 主题列表 + 术语表
  格式: Markdown 文件目录 + IP-Context 摘要

book → review:
  传递: 完整书稿 + 目录 + 术语表
  格式: Markdown 文件目录
```
