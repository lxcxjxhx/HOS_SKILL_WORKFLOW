# 三种专利类型指南

## 概述

中国专利法规定了三种专利类型：发明专利、实用新型专利和外观设计专利。本指南帮助根据技术方案特征选择合适的专利类型。

---

## 一、发明专利

### 1.1 定义

发明专利是指对产品、方法或者其改进所提出的新的技术方案。

### 1.2 保护对象

- **产品发明**：新的物质、材料、器件、设备等
- **方法发明**：新的制造方法、使用方法、检测方法等
- **改进发明**：对现有产品或方法的改进

### 1.3 授权条件

| 条件 | 要求 |
|------|------|
| 新颖性 | 不属于现有技术，且在申请日前没有同样的发明被公开 |
| 创造性 | 与现有技术相比，具有突出的实质性特点和显著的进步 |
| 实用性 | 能够在产业中制造或使用，并产生积极效果 |

### 1.4 保护期限

自申请日起 20 年。

### 1.5 审查制度

- **初步审查**：审查形式要件
- **实质审查**：审查新颖性、创造性、实用性
- 申请人需在申请日起 3 年内提出实质审查请求

### 1.6 审查周期

通常 2-3 年（可申请优先审查或预审加速）。

### 1.7 适用场景

- 技术创新程度高
- 涉及方法/工艺/算法
- 需要长期保护的核心技术
- 具有重大商业价值的技术

### 1.8 示例

- 一种新型化合物的合成方法
- 一种基于深度学习的图像识别算法
- 一种新型药物的制备方法
- 一种新型材料的组成及制备工艺

---

## 二、实用新型专利

### 2.1 定义

实用新型是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案。

### 2.2 保护对象

- **形状改进**：产品外形的新设计
- **构造改进**：产品内部结构的新设计
- **形状+构造结合**：产品外形和内部结构的综合改进

### 2.3 授权条件

| 条件 | 要求 |
|------|------|
| 新颖性 | 不属于现有技术 |
| 创造性 | 与现有技术相比，具有实质性特点和进步（要求低于发明） |
| 实用性 | 能够在产业中制造或使用 |

### 2.4 保护期限

自申请日起 10 年。

### 2.5 审查制度

- **初步审查**：仅审查形式要件和明显实质性缺陷
- **不实质审查**：不审查新颖性、创造性（但在无效程序中会审查）

### 2.6 审查周期

通常 6-12 个月。

### 2.7 适用场景

- 产品结构的改进
- 创新程度一般的小发明
- 需要快速获得授权
- 预算有限

### 2.8 限制

- **只能保护产品**，不能保护方法
- 产品必须具有固定的形状或构造
- 不能保护无固定形状的物质（如液体、气体、粉末）

### 2.9 示例

- 一种新型手机支架
- 一种改进的螺丝刀结构
- 一种新型水杯
- 一种改进的电路板布局

---

## 三、外观设计专利

### 3.1 定义

外观设计是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。

### 3.2 保护对象

- **形状设计**：产品外形的新设计
- **图案设计**：产品表面图案的新设计
- **色彩+形状/图案**：色彩与形状、图案结合的新设计
- **局部设计**：产品局部的新设计（2021 年新增）

### 3.3 授权条件

| 条件 | 要求 |
|------|------|
| 新颖性 | 不属于现有设计 |
| 创造性 | 与现有设计或现有设计特征的组合相比，具有明显区别 |
| 美感 | 富有美感 |
| 工业适用性 | 适于工业应用 |

### 3.4 保护期限

自申请日起 15 年（2021 年修改后）。

### 3.5 审查制度

- **初步审查**：仅审查形式要件和明显实质性缺陷

### 3.6 审查周期

通常 4-8 个月。

### 3.7 适用场景

- 产品外观设计的创新保护
- 产品包装设计的保护
- GUI（图形用户界面）的保护
- 快速获得外观设计保护

### 3.8 限制

- 不保护技术方案
- 不保护功能特征
- 必须依附于具体产品

### 3.9 示例

- 一种新型手机外观
- 一种新型家具的外观设计
- 一种新型包装盒
- 一种图形用户界面（GUI）

## 四、三种专利类型对比

| 对比项 | 发明专利 | 实用新型专利 | 外观设计专利 |
|--------|---------|------------|------------|
| **保护对象** | 产品/方法/改进 | 产品形状/构造 | 产品外观 |
| **创新要求** | 高（突出的实质性特点+显著进步） | 中（实质性特点+进步） | 明显区别 |
| **保护期限** | 20 年 | 10 年 | 15 年 |
| **审查制度** | 初审+实审 | 初审 | 初审 |
| **审查周期** | 2-3 年 | 6-12 月 | 4-8 月 |
| **费用** | 高 | 低 | 低 |
| **稳定性** | 高（经过实审） | 中（未经实审） | 中（未经实审） |
| **维权难度** | 低 | 中（需出具专利权评价报告） | 中 |

## 五、专利类型选择决策树

```
开始
│
├─ 技术方案是否涉及方法/工艺/算法？
│  ├─ 是 → 发明专利
│  └─ 否 ↓
│
├─ 技术方案是否涉及产品形状/构造的改进？
│  ├─ 是 ↓
│  │  ├─ 创新程度高，需要长期保护？
│  │  │  ├─ 是 → 发明专利
│  │  │  └─ 否 → 实用新型专利
│  │  └─ 需要快速获得授权？
│  │     ├─ 是 → 实用新型专利
│  │     └─ 否 → 发明专利（更稳定）
│  └─ 否 ↓
│
├─ 技术方案是否涉及产品外观的设计？
│  ├─ 是 → 外观设计专利
│  └─ 否 ↓
│
└─ 综合评估，建议咨询专利代理师
```

## 六、组合申请策略

### 6.1 发明 + 实用新型同时申请

**策略：** 对同一技术方案同时申请发明专利和实用新型专利

**优势：**
- 实用新型先授权，快速获得保护
- 发明专利后授权，获得更长期限的保护
- 发明专利授权时，放弃实用新型专利

**注意：**
- 需要在申请时声明
- 两件申请的权利要求不能完全相同

### 6.2 产品 + 方法同时申请

**策略：** 对产品申请产品专利，对制造方法申请方法专利

**优势：**
- 产品保护和方法保护相互补充
- 维权时可以选择最有利的权利要求

### 6.3 外观 + 实用新型同时申请

**策略：** 对产品外观申请外观设计专利，对产品结构申请实用新型专利

**优势：**
- 外观保护和结构保护相互补充
- 全面保护产品的创新点

## 七、常见问题

### Q1：同一技术方案可以同时申请多种专利吗？

**A：** 可以。例如：
- 对同一技术方案同时申请发明和实用新型（需声明）
- 对产品结构和外观分别申请实用新型和外观设计

### Q2：实用新型和发明的选择依据是什么？

**A：** 主要考虑以下因素：
- 创新程度：高 → 发明，中 → 实用新型
- 保护期限需求：长 → 发明，短 → 实用新型
- 授权速度需求：快 → 实用新型，不急 → 发明
- 预算：充足 → 发明，有限 → 实用新型

### Q3：外观设计专利能保护技术功能吗？

**A：** 不能。外观设计只保护产品的外观设计，不保护技术功能。如果外观设计中包含技术功能特征，该特征不受外观设计专利保护。

### Q4：实用新型专利的稳定性如何？

**A：** 实用新型专利未经实质审查，稳定性相对较低。在无效程序中，可能被宣告无效。建议在维权前出具专利权评价报告。

### Q5：发明专利的审查周期可以缩短吗？

**A：** 可以。以下方式可以缩短审查周期：
- 优先审查：符合条件可申请优先审查
- 预审：通过知识产权保护中心进行预审
- PPH（专利审查高速路）：基于国外审查结果加速审查
