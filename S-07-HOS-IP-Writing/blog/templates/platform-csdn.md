# CSDN 格式指南

> CSDN 使用 Markdown 编辑器，支持标准 Markdown 语法 + LaTeX 数学公式。

---

## 一、文章结构规范

### 1.1 标题层级
- **H1**（`#`）：文章标题，每篇仅一个
- **H2**（`##`）：主要章节
- **H3**（`###`）：子章节
- **H4-H6**：细分内容，按需使用
- CSDN 会根据标题自动生成目录

### 1.2 文章长度建议
- 技术博客：2000-5000 字
- 深度教程：3000-8000 字
- 最佳阅读体验：配合 3-5 张图

---

## 二、代码块

### 2.1 标准代码块
````markdown
```python
def hello():
    print("Hello, CSDN!")
```
````

### 2.2 支持的常用语言
`python`, `java`, `javascript`, `cpp`, `c`, `go`, `rust`, `sql`, `bash`, `json`, `yaml`, `html`, `css`, `typescript`

### 2.3 行号显示
CSDN 代码块默认显示行号，无需额外配置。

---

## 三、数学公式（LaTeX）

### 3.1 行内公式
```markdown
行内公式示例：$E = mc^2$
```

### 3.2 块级公式
```markdown
$$
\sum_{i=1}^{n} x_i = x_1 + x_2 + \cdots + x_n
$$
```

### 3.3 注意事项
- 行内公式使用单个 `$`，块级公式使用双 `$$`
- 公式与 `$` 符号之间不要有空格
- 复杂公式建议单独成段

---

## 四、图片

### 4.1 插入方式
```markdown
![图片描述](图片URL)
```

### 4.2 最佳实践
- 优先上传到 CSDN 图床（编辑器自带上传功能）
- 图片宽度建议不超过 900px
- 添加有意义的 alt 描述
- 图片格式推荐 PNG（截图）或 JPG（照片）

---

## 五、标签与分类

### 5.1 标签规则
- 最多 **5 个**标签
- 第一个标签为**主标签**（决定文章分类）
- 选择 CSDN 已有的标签体系
- 常用技术标签：`Python`, `Java`, `前端`, `算法`, `机器学习`, `数据库`

### 5.2 分类建议
- 选择与主标签匹配的专栏分类
- 可将文章加入个人专栏

---

## 六、链接

### 6.1 外部链接
```markdown
[链接文字](https://example.com)
```

### 6.2 注意事项
- 避免过多外部链接（可能影响推荐）
- 优先引用 CSDN 站内文章
- 不要添加引流链接（可能违规）

---

## 七、特殊格式

### 7.1 表格
```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据 | 数据 | 数据 |
```

### 7.2 任务列表
```markdown
- [x] 已完成任务
- [ ] 未完成任务
```

### 7.3 目录标记
CSDN 自动生成目录，无需手动添加。如需强制显示：
```markdown
@[TOC](目录)
```

---

## 八、发布检查清单

- [ ] 标题清晰，包含核心关键词
- [ ] 摘要完整（文章前 100 字很重要）
- [ ] 代码块语法正确，标注了语言
- [ ] 图片已上传到 CSDN 图床
- [ ] 标签已选择（1-5 个）
- [ ] 已选择专栏（如有）
- [ ] 无外部引流链接
- [ ] 原创声明（如适用）
- [ ] 目录层级合理
