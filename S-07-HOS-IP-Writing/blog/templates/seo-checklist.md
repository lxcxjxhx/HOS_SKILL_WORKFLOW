# SEO 检查清单

> 博客文章发布前的 SEO 优化检查清单。逐项检查并优化，提升文章在搜索引擎中的排名。

---

## 一、关键词优化

### 1.1 关键词选择
- [ ] 确定了 **1 个核心关键词**
- [ ] 确定了 **3-5 个次要关键词**
- [ ] 关键词与文章主题高度相关
- [ ] 关键词有合理的搜索量
- [ ] 关键词竞争度可接受

### 1.2 关键词分布
- [ ] 核心关键词出现在**标题**中
- [ ] 核心关键词出现在**第一段**（前 100 字）
- [ ] 核心关键词出现在**H2 标题**中（至少 1 个）
- [ ] 核心关键词自然分布在正文中
- [ ] 关键词密度在 **1%-3%** 之间
- [ ] 次要关键词自然分布在正文中
- [ ] 避免了关键词堆砌

### 1.3 长尾关键词
- [ ] 包含了相关的长尾关键词
- [ ] 长尾关键词覆盖了用户可能的搜索意图
- [ ] 长尾关键词自然融入文章

---

## 二、标题优化

### 2.1 标题结构
- [ ] 标题长度在 **15-25 字**之间
- [ ] 标题包含核心关键词
- [ ] 标题位于文章开头（H1）
- [ ] 每篇文章只有 **1 个 H1**
- [ ] 标题简洁有力，吸引点击

### 2.2 标题类型（选择一种）
- [ ] 数字型：`7 个方法...`、`10 个技巧...`
- [ ] 问题型：`如何...`、`为什么...`
- [ ] 指南型：`完整指南`、`入门教程`
- [ ] 对比型：`A vs B`、`A 和 B 的区别`
- [ ] 清单型：`必备清单`、`最佳实践`

### 2.3 副标题
- [ ] 副标题补充了主标题信息
- [ ] 副标题包含次要关键词

---

## 三、描述优化

### 3.1 Meta Description
- [ ] 描述长度在 **120-160 字**之间
- [ ] 描述包含核心关键词
- [ ] 描述概括了文章核心内容
- [ ] 描述有吸引力，引导点击
- [ ] 描述是完整的句子（非碎片）

### 3.2 文章摘要
- [ ] 摘要长度在 **100-300 字**之间
- [ ] 摘要概括了文章核心要点
- [ ] 摘要引发阅读兴趣
- [ ] 摘要包含核心关键词

---

## 四、内容结构优化

### 4.1 标题层级
- [ ] H1 只有 1 个（文章标题）
- [ ] H2 为主要章节标题（3-8 个）
- [ ] H3 为子章节标题
- [ ] 标题层级不跳级（H1 → H2 → H3）
- [ ] 标题中包含相关关键词

### 4.2 段落结构
- [ ] 每段不超过 **5 行**（移动端友好）
- [ ] 段落之间有逻辑过渡
- [ ] 重要信息放在段首
- [ ] 使用列表展示并列信息

### 4.3 内容质量
- [ ] 内容原创，非抄袭或洗稿
- [ ] 内容有深度，提供了独到见解
- [ ] 信息准确，代码可运行
- [ ] 内容完整，覆盖了主题的主要方面
- [ ] 文章长度适当（2000-5000 字）

---

## 五、图片优化

### 5.1 图片 Alt 文本
- [ ] 每张图片都有 alt 描述
- [ ] alt 描述准确反映图片内容
- [ ] alt 中包含相关关键词（自然融入）

### 5.2 图片质量
- [ ] 图片清晰，分辨率足够
- [ ] 图片尺寸适当（不过大影响加载速度）
- [ ] 图片格式正确（PNG/JPG/WebP）
- [ ] 图片与内容相关

---

## 六、链接优化

### 6.1 内部链接
- [ ] 包含了相关文章的链接
- [ ] 锚文本描述准确
- [ ] 内链自然融入内容

### 6.2 外部链接
- [ ] 引用了权威来源（官方文档、知名博客）
- [ ] 外部链接使用 `nofollow`（如需要）
- [ ] 外部链接在新窗口打开
- [ ] 外部链接数量适当（不过多）

---

## 七、标签与分类

### 7.1 标签
- [ ] 选择了平台允许数量的标签
- [ ] 标签与内容高度相关
- [ ] 标签覆盖了主要技术点
- [ ] 标签是平台已有的标签体系

### 7.2 分类
- [ ] 选择了正确的文章分类
- [ ] 分类与内容匹配

---

## 八、平台特定优化

### 8.1 CSDN
- [ ] 原创标记（如适用）
- [ ] 专栏已选择
- [ ] 目录层级正确

### 8.2 掘金
- [ ] 分类标签准确
- [ ] 封面图已设置
- [ ] 已加入专栏

### 8.3 知乎
- [ ] 话题标签已选择（3-5 个）
- [ ] 已投稿到专栏
- [ ] 结尾引导互动

### 8.4 Medium
- [ ] 英文标题和描述
- [ ] 封面图 1400×788px
- [ ] 标签最多 5 个
- [ ] URL 已自定义

### 8.5 Dev.to
- [ ] Front Matter 完整
- [ ] description 已填写
- [ ] 标签最多 4 个
- [ ] series 已设置（如适用）

---

## 九、技术 SEO

### 9.1 可读性
- [ ] 文章有清晰的引言和总结
- [ ] 使用了过渡词和连接词
- [ ] 句子长度适中（避免过长）
- [ ] 专业术语有解释

### 9.2 社交分享
- [ ] 文章适合社交分享
- [ ] 有吸引分享的标题
- [ ] 封面图适合社交展示

---

## 十、发布前最终检查

- [ ] 通读全文，无错别字和语法错误
- [ ] 代码示例全部可运行
- [ ] 所有链接有效
- [ ] 图片显示正常
- [ ] 格式在各平台预览正常
- [ ] 标签和分类正确
- [ ] SEO 信息完整

## SEO 评分参考

| 评分 | 说明 |
|------|------|
| 90-100 | 优秀，可直接发布 |
| 70-89 | 良好，建议小幅优化 |
| 50-69 | 一般，需要较多优化 |
| < 50 | 较差，建议重写或大幅修改 |
