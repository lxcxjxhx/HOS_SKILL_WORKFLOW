# 博客写作工作流

> 本工作流定义了从需求分析到最终发布的完整博客写作流程，适用于各类技术博客文章。

---

## 工作流概览

```
需求分析 → 大纲生成 → 用户确认 → 正文写作 → 平台适配 → SEO 优化 → 最终输出
```

---

## 阶段一：需求分析

### 1.1 收集需求信息

**必须确认的信息：**

| 项目 | 说明 | 示例 |
|------|------|------|
| 文章主题 | 核心技术内容 | Python 异步编程 |
| 目标平台 | 发布到哪些平台 | CSDN、掘金、知乎 |
| 文章类型 | 博客/教程/案例研究 | 技术博客 |
| 目标读者 | 读者技术水平 | 中级开发者 |
| 核心要点 | 必须覆盖的内容 | asyncio、async/await、性能优化 |

**可选确认的信息：**

| 项目 | 说明 | 示例 |
|------|------|------|
| 文章长度 | 预期字数范围 | 3000-5000 字 |
| 代码示例 | 是否需要代码示例 | 需要，包含完整示例 |
| 图表需求 | 是否需要图表 | 需要架构图和流程图 |
| 参考资料 | 需要引用的资料 | 官方文档、相关论文 |

### 1.2 需求分析输出

**输出文档：**

```markdown
## 需求分析文档

### 基本信息
- 主题：{{主题}}
- 平台：{{平台列表}}
- 类型：{{文章类型}}
- 读者：{{目标读者}}

### 核心要点
1. {{要点1}}
2. {{要点2}}
3. {{要点3}}

### 特殊要求
- {{要求1}}
- {{要求2}}
```

---

## 阶段二：大纲生成

### 2.1 选择模板

根据文章类型选择对应模板：

| 文章类型 | 模板文件 |
|---------|---------|
| 技术博客 | `templates/blog-post-template.md` |
| 技术教程 | `templates/technical-tutorial.md` |
| 案例研究 | `templates/case-study.md` |

### 2.2 生成大纲

**大纲结构：**

```markdown
# {{文章标题}}

## 一、引言
- 背景介绍
- 问题提出
- 文章价值

## 二、核心内容
### 2.1 {{要点1}}
- 概念解释
- 原理说明
- 代码示例

### 2.2 {{要点2}}
- 概念解释
- 原理说明
- 代码示例

### 2.3 {{要点3}}
- 概念解释
- 原理说明
- 代码示例

## 三、实战演示
- 完整示例
- 运行结果
- 代码解析

## 四、总结与展望
- 要点回顾
- 实践建议
- 未来方向
```

### 2.3 生成候选标题

**标题生成规则：**

1. **数字型**：`7 个方法掌握 Python 异步编程`
2. **问题型**：`如何高效使用 Python 异步编程？`
3. **指南型**：`Python 异步编程完整指南`
4. **对比型**：`同步 vs 异步：Python 并发编程实战`
5. **清单型**：`Python 异步编程最佳实践清单`

**输出 3-5 个候选标题，等待用户选择。**

### 2.4 用户确认

**确认内容：**
- [ ] 大纲结构是否合理
- [ ] 标题选择（或调整）
- [ ] 核心要点是否完整
- [ ] 是否需要增删章节

**用户反馈处理：**
- 如用户提出修改意见，调整大纲后再次确认
- 如用户确认通过，进入下一阶段

---

## 阶段三：正文写作

### 3.1 写作顺序

**推荐写作顺序：**

1. **引言**：吸引读者，说明文章价值
2. **背景**：提供必要的上下文
3. **核心内容**：逐节展开，配合代码和图表
4. **实战演示**：给出完整可运行的示例
5. **总结**：回顾要点，给出建议

### 3.2 写作规范

**段落规范：**
- 每段不超过 5 行（移动端友好）
- 重要信息放在段首
- 使用过渡词连接段落

**代码规范：**
- 代码块必须标注语言
- 代码简洁，突出关键部分
- 配合文字说明解释代码
- 确保代码可运行

**图表规范：**
- 图表与内容相关
- 添加图表说明
- 使用 Mermaid 或文字描述

### 3.3 写作检查

**每节写作完成后检查：**
- [ ] 内容是否准确
- [ ] 代码是否可运行
- [ ] 是否覆盖了要点
- [ ] 是否有逻辑错误

---

## 阶段四：平台适配

### 4.1 加载平台指南

根据目标平台加载对应指南：

| 平台 | 指南文件 |
|------|---------|
| CSDN | `templates/platform-csdn.md` |
| 掘金 | `templates/platform-juejin.md` |
| 知乎 | `templates/platform-zhihu.md` |
| Medium | `templates/platform-medium.md` |
| Dev.to | `templates/platform-devto.md` |

### 4.2 格式转换

**转换内容：**

1. **标题层级**：调整 H1-H6 使用
2. **代码块**：确保语法高亮正确
3. **图片**：适配平台图片上传方式
4. **标签**：转换为平台标签格式
5. **特殊语法**：使用平台特有语法（如需要）

### 4.3 生成平台版本

**为每个目标平台生成独立文件：**

```
{slug}-{platform}.md
```

示例：
- `python-async-guide-csdn.md`
- `python-async-guide-juejin.md`
- `python-async-guide-zhihu.md`

## 阶段五：SEO 优化

### 5.1 加载 SEO 检查清单

加载 `templates/seo-checklist.md`

### 5.2 执行 SEO 检查

**检查项目：**

1. **关键词优化**
   - 核心关键词在标题中
   - 核心关键词在第一段
   - 关键词密度 1%-3%
   - 避免关键词堆砌

2. **标题优化**
   - 标题长度 15-25 字
   - 标题包含核心关键词
   - 标题吸引点击

3. **描述优化**
   - Meta description 120-160 字
   - 描述包含核心关键词
   - 描述有吸引力

4. **结构优化**
   - H1 只有 1 个
   - H2 为主要章节
   - 标题层级不跳级

5. **图片优化**
   - 每张图片有 alt 描述
   - alt 包含关键词

### 5.3 生成 SEO 报告

**报告内容：**

```markdown
## SEO 优化报告

### 关键词分析
- 核心关键词：{{关键词}}
- 次要关键词：{{关键词列表}}
- 关键词密度：{{百分比}}

### 标题评估
- 标题长度：{{字数}}
- 标题类型：{{类型}}
- 评分：{{分数}}/100

### 描述评估
- Meta description 长度：{{字数}}
- 评分：{{分数}}/100

### 结构评估
- H1 数量：{{数量}}
- H2 数量：{{数量}}
- 评分：{{分数}}/100

### 综合评分
- 总分：{{分数}}/100
- 等级：{{优秀|良好|一般|较差}}

### 优化建议
1. {{建议1}}
2. {{建议2}}
3. {{建议3}}
```

## 阶段六：最终输出

### 6.1 输出文件清单

**必须输出：**
- [ ] 各平台版本的文章文件
- [ ] SEO 优化报告

**可选输出：**
- [ ] 原始 Markdown 版本
- [ ] 代码清单文件
- [ ] 图表源文件

### 6.2 输出文件命名

**命名规则：**

```
{slug}.md                      # 原始版本
{slug}-{platform}.md           # 平台版本
{slug}-seo-report.md           # SEO 报告
```

示例：
```
python-async-guide.md
python-async-guide-csdn.md
python-async-guide-juejin.md
python-async-guide-zhihu.md
python-async-guide-seo-report.md
```

### 6.3 发布建议

**发布建议内容：**

```markdown
## 发布建议

### 发布时间
- 最佳发布时间：{{建议时间}}
- 原因：{{原因说明}}

### 发布顺序
1. 首先发布到：{{平台1}}
2. 然后发布到：{{平台2}}
3. 最后发布到：{{平台3}}

### 推广建议
- {{建议1}}
- {{建议2}}
- {{建议3}}

### 互动建议
- 及时回复评论
- 关注数据反馈
- 根据反馈调整后续内容
```
