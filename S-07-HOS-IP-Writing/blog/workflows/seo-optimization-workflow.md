# SEO 优化工作流

> 本工作流定义了博客文章 SEO 优化的完整流程，从关键词分析到最终优化建议，帮助文章在搜索引擎中获得更好排名。

---

## 工作流概览

```
输入文章 → 关键词分析 → 标题优化 → 描述优化 → 结构优化 → 内容优化 → 生成 SEO 报告 → 输出优化版本
```

---

## 阶段一：输入分析

### 1.1 接收输入

**输入内容：**
- 文章全文（Markdown 格式）
- 目标平台（可选）
- 目标关键词（可选）

### 1.2 基础分析

**分析内容：**

1. **文章基本信息**
   - 标题
   - 字数
   - 段落数
   - 标题层级结构

2. **现有 SEO 元素**
   - 现有标题
   - 现有描述/摘要
   - 现有标签
   - 图片 alt 文本

3. **内容结构**
   - H1 数量
   - H2 数量
   - H3 数量
   - 代码块数量
   - 图片数量

**分析输出：**

```markdown
## 文章基础分析报告

### 基本信息
- 标题：{{标题}}
- 字数：{{字数}}
- 段落数：{{段落数}}
- 预计阅读时间：{{时间}}

### 结构分析
- H1：{{数量}} 个
- H2：{{数量}} 个
- H3：{{数量}} 个
- 代码块：{{数量}} 个
- 图片：{{数量}} 张

### 现有 SEO 元素
- 标题长度：{{字数}}
- 描述：{{有/无}}
- 标签：{{数量}} 个
- 图片 alt：{{有/无}}
```

## 阶段二：关键词分析

### 2.1 提取候选关键词

**提取方法：**

1. **标题关键词**
   - 从标题中提取核心词汇
   - 识别技术术语

2. **高频词汇**
   - 统计正文高频词汇
   - 过滤常见词（的、了、是等）
   - 识别技术关键词

3. **语义分析**
   - 识别文章主题
   - 提取相关概念
   - 识别长尾关键词

### 2.2 关键词评估

**评估维度：**

| 维度 | 说明 | 权重 |
|------|------|------|
| 相关性 | 与文章主题的相关度 | 高 |
| 搜索量 | 预估搜索量 | 中 |
| 竞争度 | 竞争激烈程度 | 中 |
| 商业价值 | 对目标的价值 | 低 |

### 2.3 确定关键词策略

**输出：**

```markdown
## 关键词策略

### 核心关键词（1 个）
- 关键词：{{关键词}}
- 理由：{{理由}}

### 次要关键词（3-5 个）
1. {{关键词1}}
2. {{关键词2}}
3. {{关键词3}}

### 长尾关键词（5-10 个）
1. {{长尾关键词1}}
2. {{长尾关键词2}}
3. {{长尾关键词3}}

### 关键词分布计划
- 标题：核心关键词
- 第一段：核心关键词 + 次要关键词
- H2 标题：次要关键词
- 正文：自然分布所有关键词
```

## 阶段三：标题优化

### 3.1 标题评估

**评估标准：**

| 标准 | 优秀 | 良好 | 一般 | 较差 |
|------|------|------|------|------|
| 长度 | 15-25 字 | 10-30 字 | 5-40 字 | <5 或 >40 字 |
| 关键词 | 包含核心关键词 | 包含相关词 | 间接相关 | 无关 |
| 吸引力 | 强烈吸引 | 较吸引 | 一般 | 无吸引力 |
| 清晰度 | 非常清晰 | 较清晰 | 一般 | 模糊 |

### 3.2 标题优化建议

**优化方向：**

1. **长度优化**
   - 控制在 15-25 字
   - 简洁有力

2. **关键词优化**
   - 包含核心关键词
   - 关键词靠前

3. **类型优化**
   - 数字型：`7 个方法...`
   - 问题型：`如何...`
   - 指南型：`完整指南`
   - 对比型：`A vs B`
   - 清单型：`最佳实践`

4. **吸引力优化**
   - 使用有力词汇
   - 突出价值
   - 制造好奇心

### 3.3 生成候选标题

**生成规则：**

为每种类型生成 1-2 个候选标题：

```markdown
## 候选标题

### 数字型
1. {{标题1}}
2. {{标题2}}

### 问题型
3. {{标题3}}
4. {{标题4}}

### 指南型
5. {{标题5}}

### 对比型
6. {{标题6}}

### 清单型
7. {{标题7}}

### 推荐标题
- 首选：{{标题X}}
- 理由：{{理由}}
```

## 阶段四：描述优化

### 4.1 Meta Description 优化

**优化标准：**

| 标准 | 要求 |
|------|------|
| 长度 | 120-160 字 |
| 关键词 | 包含核心关键词 |
| 内容 | 概括文章核心 |
| 吸引力 | 引导点击 |
| 完整性 | 完整句子 |

### 4.2 生成 Meta Description

**生成模板：**

```
{{核心关键词}}是{{定义/作用}}。本文详细介绍了{{核心内容}}，包括{{要点1}}、{{要点2}}和{{要点3}}。无论你是{{目标读者1}}还是{{目标读者2}}，都能从本文中获得{{价值}}。
```

**示例：**

```
Python 异步编程是提高程序性能的关键技术。本文详细介绍了 Python 异步编程的核心概念、asyncio 库的使用方法和实际应用场景，包括 async/await 语法、协程管理和性能优化技巧。无论你是中级开发者还是希望提升技能的高级工程师，都能从本文中获得实用的异步编程知识。
```

### 4.3 文章摘要优化

**优化标准：**

| 标准 | 要求 |
|------|------|
| 长度 | 100-300 字 |
| 内容 | 概括核心要点 |
| 吸引力 | 引发阅读兴趣 |
| 关键词 | 包含核心关键词 |

## 阶段五：结构优化

### 5.1 标题层级优化

**优化规则：**

1. **H1 优化**
   - 仅保留 1 个 H1（文章标题）
   - H1 包含核心关键词

2. **H2 优化**
   - 3-8 个 H2 为宜
   - H2 包含次要关键词
   - H2 描述清晰

3. **H3 优化**
   - H3 为子章节
   - 层级不跳级

### 5.2 段落优化

**优化规则：**

1. **段落长度**
   - 每段不超过 5 行
   - 移动端友好

2. **段落结构**
   - 重要信息在段首
   - 使用过渡词
   - 逻辑清晰

3. **列表使用**
   - 并列信息用列表
   - 步骤用有序列表
   - 要点用无序列表

### 5.3 内容结构优化

**优化建议：**

```markdown
## 结构优化建议

### 当前结构
```
H1: 文章标题
  H2: 章节1
    H3: 子章节1.1
    H3: 子章节1.2
  H2: 章节2
  H2: 章节3
```

### 优化后结构
```
H1: 优化后的文章标题（包含核心关键词）
  H2: 引言（包含核心关键词）
  H2: 章节1（包含次要关键词）
    H3: 子章节1.1
    H3: 子章节1.2
  H2: 章节2（包含次要关键词）
  H2: 章节3（包含次要关键词）
  H2: 总结
```

### 优化说明
1. {{说明1}}
2. {{说明2}}
3. {{说明3}}
```

## 阶段六：内容优化

### 6.1 关键词分布优化

**优化规则：**

1. **标题**
   - 包含核心关键词
   - 关键词靠前

2. **第一段**
   - 前 100 字包含核心关键词
   - 自然引入次要关键词

3. **H2 标题**
   - 至少 1 个 H2 包含核心关键词
   - 其他 H2 包含次要关键词

4. **正文**
   - 关键词密度 1%-3%
   - 自然分布，避免堆砌
   - 使用同义词和变体

### 6.2 图片优化

**优化规则：**

1. **Alt 文本**
   - 每张图片都有 alt
   - alt 描述准确
   - 包含相关关键词

2. **图片质量**
   - 清晰度高
   - 尺寸适当
   - 格式正确

3. **图片命名**
   - 使用描述性文件名
   - 包含关键词

### 6.3 链接优化

**优化规则：**

1. **内部链接**
   - 链接到相关文章
   - 锚文本描述准确
   - 自然融入内容

2. **外部链接**
   - 引用权威来源
   - 链接到官方文档
   - 数量适当

## 常见问题

### 问题 1：关键词密度过高

**解决方案：**
- 使用同义词替换
- 删除重复表述
- 自然融入上下文

### 问题 2：标题过长

**解决方案：**
- 删除冗余词汇
- 使用缩写
- 突出核心信息

### 问题 3：缺少关键词

**解决方案：**
- 在标题中添加
- 在第一段添加
- 在 H2 标题添加
- 在正文自然添加

### 问题 4：结构不合理

**解决方案：**
- 调整标题层级
- 合并或拆分章节
- 重新组织内容
