# 标准润色工作流（Review Workflow）

> 完整的文本润色流程，适用于各类文本的去 AI 化和质量提升。

---

## 工作流概述

本工作流分为 5 个阶段，每个阶段包含明确的输入、处理步骤和输出。建议按顺序执行，也可根据实际情况跳过某些阶段。

**适用场景**：
- 技术博客润色
- 商业文档润色
- 一般性文章润色
- AI 生成内容去痕迹

**预计耗时**：
- 短文（< 1000 字）：15-30 分钟
- 中文（1000-3000 字）：30-60 分钟
- 长文（> 3000 字）：60-120 分钟

---

## 阶段一：文本分析（5-10 分钟）

### 1.1 输入准备

**输入**：
- 待润色的原始文本
- 文本类型说明（可选）
- 目标读者说明（可选）

**处理步骤**：

1. **读取文本**
   ```
   读取完整文本内容
   记录文本长度（字数、段落数、句子数）
   ```

2. **识别文本类型**
   ```
   检查是否包含学术标记（引用、术语、公式）
   检查是否包含技术术语
   检查是否包含商业用语
   判断文本类型：学术 / 技术 / 商业 / 一般
   ```

3. **评估当前质量**
   ```
   快速浏览全文
   初步判断 AI 痕迹程度（轻/中/重）
   识别最明显的问题
   ```

**输出**：
- 文本类型判断
- 初步质量评估
- 润色策略选择

---

### 1.2 策略选择

根据文本类型选择润色策略：

| 文本类型 | 润色重点 | 注意事项 |
|----------|----------|----------|
| 学术论文 | 保持严谨性，规范引用 | 避免过度口语化 |
| 技术博客 | 保持专业性，增加可读性 | 可适当口语化 |
| 商业文档 | 保持简洁性，行动导向 | 避免学术化表达 |
| 一般文章 | 自然流畅，去除 AI 痕迹 | 保持作者风格 |

---

## 阶段二：问题诊断（10-15 分钟）

### 2.1 AI 模式扫描

**处理步骤**：

1. **填充短语扫描**
   ```
   搜索以下关键词：
   - "值得注意的是"
   - "需要指出的是"
   - "众所周知"
   - "从本质上来说"
   - "总的来说"
   - "综上所述"
   
   标记所有出现位置
   记录出现次数
   ```

2. **公式化结构扫描**
   ```
   检查以下模式：
   - "首先...其次...最后..."
   - "一方面...另一方面..."
   - "不仅...而且..."
   - "在...的背景下"
   - "随着...的发展"
   
   标记结构位置
   评估是否需要改写
   ```

3. **被动语态扫描**
   ```
   搜索被动标记词：
   - "被"
   - "由"
   - "受"
   - "得到"
   
   检查是否可改为主动语态
   ```

4. **模糊表达扫描**
   ```
   搜索模糊词：
   - "很多"、"一些"、"大量"
   - "很好"、"有效"、"良好"
   - "最近"、"近年来"、"目前"
   
   标记需要具体化的位置
   ```

**输出**：
- AI 模式检测报告
- 问题清单（按优先级排序）
- 修改建议列表

---

### 2.2 问题优先级排序

**优先级规则**：

| 优先级 | 问题类型 | 处理要求 |
|--------|----------|----------|
| P0（必须） | 高信号 AI 标记 | 必须修改 |
| P1（建议） | 中信号 AI 标记 | 建议修改 |
| P2（可选） | 低信号 AI 标记 | 可选修改 |
| P3（风格） | 节奏、句式变化 | 风格调整 |

**输出**：
- 按优先级排序的修改清单
- 预计修改工作量

---

## 阶段三：逐段润色（20-40 分钟）

### 3.1 段落级润色

**处理步骤**（对每个段落执行）：

1. **删除填充短语**
   ```
   删除所有 P0 级填充词
   确保删除后句子完整
   检查上下文连贯性
   ```

2. **转换主动语态**
   ```
   将被动句改为主动句
   明确动作执行者
   必要时添加主语（"我们"、"研究者"）
   ```

3. **打破公式化结构**
   ```
   改写"首先...其次...最后..."结构
   用自然过渡替代机械连接
   多样化段落开头
   ```

4. **具体化表达**
   ```
   将模糊词替换为具体数字
   将笼统描述改为详细说明
   添加具体案例或数据
   ```

**示例**：

原文：
> 值得注意的是，人工智能技术在近年来取得了显著的发展。从本质上来说，深度学习算法的实现使得计算机能够更好地理解复杂的数据模式。

润色后：
> 人工智能技术在近年来取得显著发展。深度学习算法使计算机能够更好地理解复杂数据模式。

---

### 3.2 句式优化

**处理步骤**：

1. **句式多样化**
   ```
   检查连续句子长度
   混合使用长短句（10-30 字交替）
   避免连续三个以上相同句式
   ```

2. **过渡自然化**
   ```
   检查段落间过渡
   使用多样化过渡词
   避免机械式连接词堆砌
   ```

3. **节奏调整**
   ```
   检查段落长度变化
   交替使用短段落和长段落
   创造视觉节奏
   ```

**输出**：
- 逐段润色后的文本
- 每段修改说明

---

## 阶段四：整体优化（10-15 分钟）

### 4.1 连贯性检查

**处理步骤**：

1. **逻辑连贯性**
   ```
   检查全文逻辑链条
   确保论点发展有序
   检查因果关系是否成立
   ```

2. **段落衔接**
   ```
   检查段落间过渡
   确保衔接自然
   无突兀转折
   ```

3. **一致性检查**
   ```
   术语使用一致
   时态使用一致
   人称使用一致
   格式风格一致
   ```

---

### 4.2 风格统一

**处理步骤**：

1. **语体统一**
   ```
   检查全文语体风格
   确保符合目标语境
   无风格跳跃
   ```

2. **专业度统一**
   ```
   检查专业术语使用
   确保符合目标读者水平
   无过度专业化或过度简化
   ```

**输出**：
- 整体优化后的文本
- 连贯性评估报告

---

## 阶段五：质量验证（5-10 分钟）

### 5.1 最终检查

**处理步骤**：

1. **AI 痕迹复查**
   ```
   重新扫描 AI 模式
   确认所有 P0 问题已解决
   检查是否引入新的 AI 模式
   ```

2. **可读性检查**
   ```
   朗读全文
   检查是否流畅自然
   检查是否有生硬表达
   ```

3. **专业性检查**
   ```
   检查是否有常识性错误
   检查是否有过时信息
   检查是否有歧义表达
   ```

---

### 5.2 质量评分

使用以下维度进行评分（1-5 分）：

| 维度 | 评分 | 说明 |
|------|------|------|
| 自然度 | /5 | 是否像人类写作 |
| 具体性 | /5 | 表达是否具体明确 |
| 节奏感 | /5 | 句式是否有变化 |
| 专业性 | /5 | 是否符合语境要求 |
| 连贯性 | /5 | 逻辑是否清晰 |
| **总分** | **/25** | |

**评分标准**：
- 20-25 分：优秀，可直接发布
- 15-19 分：良好，少量微调
- 10-14 分：合格，需要改进
- 5-9 分：较差，需要大幅修改
- < 5 分：很差，需要重写

---

### 5.3 输出交付

**最终输出**：

1. **润色后文本**
   - 完整的润色后文本
   - 保留原文格式

2. **修改说明**
   - 主要修改点列表
   - 每处修改的理由
   - 修改前后对比（关键部分）

3. **质量报告**
   - 质量评分
   - 改进建议
   - 后续优化方向

## 工作流变体

### 变体 A：快速润色（10-15 分钟）

适用于短文或时间紧急的情况：

1. 跳过阶段一的详细分析
2. 阶段二只检查 P0 问题
3. 阶段三只执行步骤 1（删除填充词）和步骤 2（转换语态）
4. 跳过阶段四
5. 阶段五简化为快速浏览

### 变体 B：深度润色（60-90 分钟）

适用于重要文档或高质量要求：

1. 阶段一增加读者分析
2. 阶段二增加语法检查
3. 阶段三增加修辞优化
4. 阶段四增加多轮迭代
5. 阶段五增加同行评审

## 常见问题

### Q1：润色后失去作者风格怎么办？

**A**：润色的目标是去除 AI 痕迹，不是改变作者风格。建议：
- 保留作者的独特表达
- 只修改明显的 AI 套路
- 在修改说明中标注每处修改的理由

### Q2：如何判断润色是否过度？

**A**：检查以下指标：
- 原文核心观点是否改变
- 作者风格是否保留
- 是否引入了新的问题
- 读者是否能接受

### Q3：学术文本润色有哪些特殊要求？

**A**：学术文本润色需要：
- 保持严谨性，避免过度口语化
- 规范引用格式（APA/MLA/Chicago/GB/T 7714）
- 使用学术用语替代口语化表达
- 确保论证逻辑严密

详细流程参见 `academic-review-workflow.md`。
