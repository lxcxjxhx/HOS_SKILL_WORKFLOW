# 润色检查清单（Review Checklist）

> 系统性润色检查模板，用于确保文本质量达到发布标准。

---

## 使用说明

在润色前复制此清单，逐项检查并标记完成情况。建议按优先级顺序执行检查。

---

## 一、AI 写作模式检查（高优先级）

### 1.1 填充短语检查
- [ ] 删除"值得注意的是"、"需要指出的是"等填充词
- [ ] 删除"众所周知"、"不言而喻"等预设共识
- [ ] 删除"从本质上来说"、"从根本上说"等本质化表达
- [ ] 删除"在某种程度上"、"在一定意义上"等模糊限定
- [ ] 删除"总的来说"、"综上所述"等机械总结

### 1.2 公式化结构检查
- [ ] 打破"首先...其次...最后..."的机械结构
- [ ] 避免"一方面...另一方面..."的对称套路
- [ ] 减少"不仅...而且..."的递进模式
- [ ] 多样化段落开头方式
- [ ] 避免每段都以相同句式开头

### 1.3 AI 套路表达检查
- [ ] 识别并改写"本质上"、"根本上"等 AI 偏好词
- [ ] 减少"至关重要"、"不可或缺"等过度强调
- [ ] 避免"在...的背景下"等模板化开头
- [ ] 减少"随着...的发展"等陈词滥调
- [ ] 消除"扮演着重要角色"等空洞表达

---

## 二、语态与主语检查（高优先级）

### 2.1 主动语态检查
- [ ] 将被动语态改为主动语态（除非有明确理由）
- [ ] 确保动作执行者清晰可见
- [ ] 避免连续使用被动语态
- [ ] 检查"被"、"由"、"受"等被动标记词

### 2.2 人类主语注入
- [ ] 用"研究者"、"开发者"替代无灵主语
- [ ] 用"我们"、"本文"替代抽象主语
- [ ] 确保主语具体、可感知
- [ ] 避免"本文研究了..."等机械化表达

---

## 三、具体化表达检查（中优先级）

### 3.1 模糊词替换
- [ ] 将"很多"、"一些"替换为具体数字
- [ ] 将"相关"、"有关"替换为明确描述
- [ ] 将"重要"、"关键"替换为具体影响
- [ ] 将"有效"、"良好"替换为量化指标

### 3.2 量化表达
- [ ] 用数字、百分比替代笼统描述
- [ ] 用具体案例替代抽象观点
- [ ] 用时间、地点、人物替代模糊指代
- [ ] 用对比数据替代主观判断

### 3.3 精确术语
- [ ] 使用领域专业术语替代泛化表达
- [ ] 确保术语使用一致
- [ ] 避免同义词混用造成混淆
- [ ] 检查术语的首次定义

---

## 四、节奏与结构检查（中优先级）

### 4.1 句式多样性
- [ ] 混合使用长短句（避免全短句或全长句）
- [ ] 检查句子长度变化（建议 10-30 字交替）
- [ ] 避免连续三个以上相同句式
- [ ] 适当使用问句、感叹句增加变化

### 4.2 段落结构
- [ ] 段落长度有变化（避免全短段或全长段）
- [ ] 每段有明确主题句
- [ ] 段落间过渡自然
- [ ] 避免段落开头重复

### 4.3 过渡与连接
- [ ] 使用多样化过渡词
- [ ] 避免机械式连接词堆砌
- [ ] 确保逻辑关系清晰
- [ ] 检查因果关系是否成立

---

## 五、学术规范检查（学术文本专用）

### 5.1 引用格式
- [ ] 引用格式统一（APA/MLA/Chicago/GB/T 7714）
- [ ] 文内引用格式正确
- [ ] 参考文献列表完整
- [ ] 引用与正文衔接自然

### 5.2 学术表达
- [ ] 口语化表达改为学术用语
- [ ] 主观判断改为客观描述
- [ ] 情绪化表达改为理性分析
- [ ] 模糊表达改为精确描述

### 5.3 论证结构
- [ ] 论点清晰明确
- [ ] 论据充分可靠
- [ ] 推理逻辑严密
- [ ] 结论有据可依

### 5.4 文献综述
- [ ] 文献覆盖全面
- [ ] 批判性分析到位
- [ ] 综合表述清晰
- [ ] 研究空白明确

---

## 六、最终质量检查（低优先级）

### 6.1 连贯性检查
- [ ] 全文逻辑连贯
- [ ] 段落间衔接自然
- [ ] 论点发展有序
- [ ] 无突兀转折

### 6.2 一致性检查
- [ ] 术语使用一致
- [ ] 时态使用一致
- [ ] 人称使用一致
- [ ] 格式风格一致

### 6.3 可读性检查
- [ ] 语言流畅自然
- [ ] 无生硬表达
- [ ] 无歧义句
- [ ] 无语法错误

### 6.4 专业性检查
- [ ] 符合目标读者水平
- [ ] 专业术语使用恰当
- [ ] 无常识性错误
- [ ] 无过时信息

---

## 七、润色评分表

完成检查后，对以下维度进行评分（1-5 分）：

| 维度 | 评分 | 说明 |
|------|------|------|
| 自然度 | /5 | 是否像人类写作 |
| 具体性 | /5 | 表达是否具体明确 |
| 节奏感 | /5 | 句式是否有变化 |
| 专业性 | /5 | 是否符合语境要求 |
| 连贯性 | /5 | 逻辑是否清晰 |
| **总分** | **/25** | |

**评分标准**：
- 5 分：优秀，无需修改
- 4 分：良好，少量微调
- 3 分：合格，需要改进
- 2 分：较差，需要大幅修改
- 1 分：很差，需要重写
