### 2.2 软件鉴别材料

软件鉴别材料包括**程序鉴别材料**和**文档鉴别材料**两部分。

#### 2.2.1 程序鉴别材料（代码文档）

**基本要求：**
- 提交源程序前、后各连续30页
- 每页不少于50行（除结束页外）
- 整个程序按50行一页的格式排版
- 源程序不足60页的，提交全部源程序

**格式要求：**
- 纸张：A4纸
- 页边距：上2.5cm，下2.5cm，左3cm，右2.5cm
- 字体：宋体小四或仿宋_GB2312小四
- 行距：固定值20磅

**内容要求：**
- 代码应为源程序，非目标代码
- 代码应完整、连续
- 可去除注释和空行
- 应包含软件名称和版本号

**提取方法：**
```
1. 使用代码统计工具提取代码
2. 按50行/页排版
3. 前30页：从第1行开始
4. 后30页：从倒数第1500行开始
5. 不足60页：提交全部代码
```

**检查清单：**
- [ ] 代码格式符合要求
- [ ] 每页不少于50行
- [ ] 前30页和后30页完整
- [ ] 包含软件名称和版本
- [ ] 代码连续、完整

#### 2.2.2 文档鉴别材料（说明书）

**基本要求：**
- 提交软件说明书（用户手册、操作手册等）
- 页数一般10-60页
- 应包含软件的全部主要功能

**文档选择：**
可选以下任一文档：
- 用户手册
- 操作手册
- 设计说明书
- 本技能生成的说明书

**格式要求：**
- 纸张：A4纸
- 页边距：标准页边距
- 字体：宋体小四
- 应包含目录

**内容要求：**
- 包含软件概述
- 包含运行环境
- 包含功能说明
- 包含使用说明
- 包含界面截图（如有）

**检查清单：**
- [ ] 文档页数符合要求
- [ ] 包含必要章节
- [ ] 功能描述详细
- [ ] 界面截图清晰（如有）

## 7. 注意事项

### 7.1 材料一致性
- 所有材料中的软件名称必须一致
- 版本号必须统一
- 著作权人信息必须一致
- 日期逻辑必须正确

### 7.2 常见错误
1. **软件名称不规范**
   - 错误：使用英文缩写作为简称
   - 正确：使用中文名称

2. **日期逻辑错误**
   - 错误：开发完成日期晚于申请日期
   - 正确：开发完成日期 ≤ 首次发表日期 ≤ 申请日期

3. **代码格式不符**
   - 错误：每页代码行数不足
   - 正确：每页不少于50行

4. **说明书内容不全**
   - 错误：缺少必要章节
   - 正确：包含完整的章节结构

### 7.3 审核周期
- **普通办理**：约30-60个工作日
- **加急办理**：约5-10个工作日（需额外费用）
