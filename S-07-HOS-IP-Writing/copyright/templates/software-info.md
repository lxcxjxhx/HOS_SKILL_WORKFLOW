## 注意事项

1. **信息一致性**
   - 所有文档中的软件名称必须一致
   - 版本号必须统一
   - 著作权人信息必须与申请表一致

2. **日期逻辑**
   - 开发完成日期 ≤ 首次发表日期 ≤ 申请日期
   - 日期必须合理，不能是未来日期

3. **运行环境**
   - 必须具体、明确
   - 不能使用"最新版"等模糊表述
   - 要区分最低配置和推荐配置

4. **编程语言**
   - 列出主要语言即可
   - 不需要列出所有使用的语言
   - 框架可以附带说明

5. **源程序量**
   - 如实填写
   - 可以估算
   - 代码文档页数应与源程序量匹配
