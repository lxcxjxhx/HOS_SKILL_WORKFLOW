#### 2.1.2 流程描述
[用文字详细描述流程的每个步骤]

**流程步骤：**

1. **开始**
   - 用户访问系统

2. **输入用户信息**
   - 输入用户名、密码、邮箱等信息
   - 点击注册按钮

3. **前端验证**
   - 判断：输入是否完整？
   - 否 → 提示错误信息 → 返回步骤2
   - 是 → 继续

4. **提交到服务器**
   - 发送注册请求到后端

5. **后端验证**
   - 判断：用户名是否已存在？
   - 是 → 返回错误信息 → 提示用户 → 返回步骤2
   - 否 → 继续

6. **创建账号**
   - 加密密码
   - 保存用户信息到数据库

7. **发送验证邮件**
   - 生成验证链接
   - 发送邮件到用户邮箱

8. **提示注册成功**
   - 显示注册成功信息
   - 提示用户查收验证邮件

9. **结束**
   - 流程结束
