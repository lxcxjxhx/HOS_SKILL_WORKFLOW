## 一、集成项目列表

### 1.1 论文写作（paper）

#### 集成项目 1：SNL-UCSB/paper-writing-skill

| 属性 | 信息 |
|------|------|
| **项目名称** | paper-writing-skill |
| **仓库地址** | https://github.com/SNL-UCSB/paper-writing-skill |
| **许可证** | MIT License |
| **作者** | Arpit Gupta (UC Santa Barbara Systems and Networking Lab) |
| **集成方式** | 二次开发 |

**集成内容**：
- 五阶段写作流程（Brainstorm → Architecture → Draft → Integration → Compression）
- 编辑原则和语音规则
- 压缩模式和修辞动作
- 质量检查清单

**HOS 二次开发 additions**：
- 增加中文学术写作支持
- 增加多投稿类型适配（SCI/EI/CCF/arXiv/IEEE/中文核心）
- 增加中文期刊格式规范
- 优化中文术语处理

**原项目贡献**：
该项目基于对 6 篇论文（8 次投稿）、7600+ Overleaf 编辑、100+ tex 文件版本和 5 次同行评审过程的深入分析，提炼出系统化的论文写作方法论。

## 二、自研部分

以下子技能为 HOS 团队完全自研：

| 子技能 | 说明 | 参考标准 |
|--------|------|----------|
| **专利写作（patent）** | 三种专利类型支持，符合 CNIPA 格式 | 中国国家知识产权局专利撰写规范 |
| **软著写作（copyright）** | 自动从 GitHub 仓库生成软著申请材料 | 中国版权保护中心软件著作权登记指南 |
| **书籍写作（book）** | 多类型书籍支持，全流程出版指导 | 技术写作最佳实践 |
| **博客写作（blog）** | 多平台支持，格式适配 | 技术博客写作方法论 |
