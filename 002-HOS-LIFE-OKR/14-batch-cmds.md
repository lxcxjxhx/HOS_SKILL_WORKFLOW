# 14 — 批量处理与快捷操作 (Batch Processing & Quick Commands)

## 核心原则

> ❗ 用户不应该手动执行超过 3 步。所有高频多步流程，**一条命令完成**。

## 快捷命令表

| 快捷命令 | 自动完成步骤 |
|---------|-------------|
| `📋今日启动` | 加载存档 → 检查复习队列 → 生成今日计划 → 输出仪表盘 |
| `📖学完第X章` | 出章节测验 → 评分留档 → 生成知识清单 → 更新复习队列 → 输出资产摘要 |
| `✅交卷` | 评分 → 对题错题留档 → 生成考后总结 → 更新复习队列 → 快照存档 → 输出报告 |
| `🧠开始复习` | 检查复习队列 → 按优先级输出题目 → 逐题反馈 → 更新间隔 |
| `💾SAVE` | 生成快照 → 输出编码 → 更新文件索引 |
| `📊周复盘` | 汇总周数据 → 趋势分析 → 知识资产报告 → 系统调整 → 周快照 |
| `📚资产总览` | 输出档案统计 → 知识清单索引 → 产出索引 → 掌握度雷达 |
| `🔍查关键词` | 搜索知识清单/错题本/产出索引 → 汇总相关结果 |
| `🔄批量错题` | 调取错题本 → 生成专项卷 → 逐题反馈 → 更新留档 → 输出进步报告 |
| `📁整理文件` | 检查所有产出 → 按规范重命名 → 更新索引 → 输出目录树 |
| `🚀完整日流程` | 今日启动 → 执行任务 → 交卷→ 复习 → SAVE → 复盘 |

## 一键日流程示例

```
你: "🚀完整日流程"
系统:
  ✅ 1/6 加载存档 → 恢复状态
  ✅ 2/6 复习队列: 8题到期 → 2题超期
  ✅ 3/6 生成今日3个任务 (含复习块)
  ✅ 4/6 今日计划已输出 → 等待执行...
  → [用户执行后]
  ✅ 5/6 任务完成留档 + 知识清单更新
  ✅ 6/6 快照已保存 + 复盘完成
  📊 今日产出: 1 commit + 1 笔记 + 1 复盘
```
