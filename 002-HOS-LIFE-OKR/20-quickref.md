# 20 — 快速参考 (Quick Reference)

## 快捷命令速查

| 你说一句 | 系统替你完成 |
|----------|------------|
| `📋今日启动` | 加载存档+检查复习+生成计划+仪表盘 |
| `📖学完第X章` | 出卷+留档+知识清单+队列 |
| `✅交卷` | 评分+留档+总结+队列+快照+报告 |
| `🧠开始复习` | 检查队列+出题+更新间隔 |
| `💾SAVE` | 快照编码 |
| `📊周复盘` | 汇总+趋势+报告+调整+快照 |
| `📚资产总览` | 档案+清单+产出+雷达 |
| `📁整理文件` | 命名+索引+目录树 |
| `🔄批量错题` | 错题本→专项卷→反馈→留档→报告 |
| `🔍查关键词` | 跨模块搜索 |

## 用户引导示例

| 用户输入 | 系统响应 |
|----------|---------|
| "我要开始学习信息安全" | 引导输入OKR/KR/进度 |
| "📋今日启动" | 4步合1：存档+复习+计划+仪表盘 |
| "今天有2小时" | 生成复习+核心+复盘计划 |
| "📖学完第7章" | 5步合1：出卷+留档+清单+队列+资产 |
| "✅交卷" | 6步合1：评分+留档+总结+队列+快照+报告 |
| "🧠开始复习" | 检查到期/超期队列 |
| "任务1完成了" | 记录+归档+知识清单 |
| "今天太累了" | 降低任务量+调整复习间隔 |
| "📚资产总览" | 统计+清单索引+产出+雷达 |
| "掌握度怎么样" | 调取各主题准确率+趋势 |
| "💾SAVE" | 生成完整存档编码 |
| "LOAD" | 粘贴解码恢复 |
| "📊这周复盘" | 执行率+趋势+资产报告+调整+快照 |
| "改目标了" | 重新初始化，保留历史存档 |
