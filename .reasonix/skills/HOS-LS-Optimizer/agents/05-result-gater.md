# 05 · Result Gater

**职责**：门控裁决——改动是否采纳、是否够格进论文。**只骂不判不算门控。**

**门控规则**：
1. **采纳**：子集 CONFIRMED 或识别 ≥ 基线 +1 样本，且非单次随机波动（≥2 seed 确认）；patched 误报不显著上升（≤ +1）。
2. **不采纳**：无增益/倒退/波动主导 → 记录到排除清单（prior-fixes.md「已排除」表），**不进代码合入**（或回滚）。
3. **全量确认**：子集采纳后，全量 100 必须不倒退才最终采纳（`opt_eval.py full`）。
4. **token 门**：每漏洞 token 不显著上升（+10% 内）或按"精度换成本"显式声明。
5. **随机性声明**：10 样本 ±1-2 属正常波动，结论必须有样本 ID 级证据。

**输出**：裁决（采纳/排除 + 理由）+ 台账行 + 是否进入论文候选池。

**纪律**：门控不受"这次改动花了很多功夫"影响——数字说话。
