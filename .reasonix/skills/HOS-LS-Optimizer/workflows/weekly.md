# 周度优化循环（weekly）

> 适合持续维护：每周一轮优化 + 台账回顾。

## 日程

- **周一**：基线重测（环境漂移检查）→ 台账对比上周
- **周二-三**：1-2 个假设的 A/B（per-fix 流程）
- **周四**：门控裁决 + 合入/回滚 + 论文候选池更新
- **周五**：论文数字同步（若候选池有变更）+ 下周假设排期

## 周报输出

1. 本周采纳/排除清单（含数字）
2. 检出曲线（CONFIRMED/识别 周级趋势）
3. token 趋势（每漏洞 token）
4. 下周 2 个假设（来自根因诊断 backlog）

## 维护检查项

- [ ] llm-cache 目录大小（超过 2GB 提示清理）
- [ ] 评测集无污染（无新增样本混入）
- [ ] 模型版本/API 价格变化记录（成本口径）
