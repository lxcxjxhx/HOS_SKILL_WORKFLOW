# 10 — 复习提效引擎 (Spaced Repetition & Review Engine)

## 间隔重复算法

```
初始间隔: 1天   (首次答错/首次学习后)
二次间隔: 3天   (第一次复习后)
三次间隔: 7天   (第二次复习后)
四次间隔: 14天  (第三次正确回答后)
五次间隔: 30天  (第四次正确回答后)
最大间隔: 90天  (已完全掌握，改为月度抽查)

每次正确回答 → 间隔 × 2.0（指数增长）
每次错误回答 → 间隔 ÷ 2.0（紧急召回）+ 重新计入短期队列
```

## 复习优先级公式

```
ReviewScore = 遗忘系数 × 紧急度 × 薄弱权重

遗忘系数 = (当前日 - 上次复习日) / 间隔
  → > 1.0 已超期，越久越紧急
  → < 0.8 还未到最佳复习点

紧急度 = min(距离考试天数 / 30, 1.0)
  → 考前越近，所有复习优先级越高

薄弱权重 = 1 - 该知识点近3次平均正确率
  → 正确率越低，复习优先级越高
```

## 复习块类型

| 类型 | 时长 | 内容 | 能量 |
|-----|------|------|------|
| ⚡ 快速闪回 | 5-10min | 今日到期前5题 | 任何 |
| 📋 错题重做 | 15-20min | 错题本+近7天错误集中区 | 低-中 |
| 🧠 间隔重复 | 10-15min | 全部到期题目 | 低-中 |
| 📊 知识图谱回顾 | 10-15min | 掌握+待加强主题浏览 | 低 |
| 🔄 全真模拟复现 | 30-45min | 模拟考错题变体 | 中-高 |

## 复习流程

```
每日启动 → 检查复习队列
  ├── 到期队列 → 按 ReviewScore 排序
  ├── 插入时间切片的复习块
  ├── 用户完成复习
  ├── 更新 mastery_level + next_review
  └── 如答错 → 缩短间隔 + 标记高优
```
