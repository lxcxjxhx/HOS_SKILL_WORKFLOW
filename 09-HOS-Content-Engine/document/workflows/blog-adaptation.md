# 博客适配工作流

> 从 4D 资产包到多平台博客文章的标准化工作流。

---

## 1. 工作流概览

```
接收 4D 资产包 → 委托博客写作 → 平台适配（CSDN/掘金/知乎） → 与视频脚本一致性检查 → 输出
```

---

## 2. 详细步骤

### Step 1: 接收 4D 资产包

- **输入**: 来自 D1/D2/D3 阶段的资产包
- **动作**:
  1. 验证资产包完整性
  2. 提取核心内容素材
  3. 确认目标平台列表
- **检查项**:
  - [ ] 资产包格式正确
  - [ ] 素材内容充分

### Step 2: 委托博客写作

- **委托目标**: `07-HOS-IP-Writing/blog`
- **动作**:
  1. 将资产包传递给博客写作模块
  2. 指定内容支柱和写作风格
  3. 确定基础博客结构
  4. 等待基础博客文章生成
- **输出**: 基础博客文章（Markdown）

#### 写作风格指南

| 支柱 | 风格 | 字数 |
|------|------|------|
| Pillar 1 | 资讯汇编，简洁客观 | 1500-2500 |
| Pillar 2 | 技术深度，代码为主 | 3000-5000 |
| Pillar 3 | 叙事纪实，过程导向 | 2000-4000 |
| Pillar 4 | 故事叙事，情感共鸣 | 2000-4000 |
| Pillar 5 | 挑战记录，紧张刺激 | 2000-3000 |
| Pillar 6 | 深度分析，逻辑严密 | 3000-5000 |

### Step 3: 平台适配

#### 3.1 CSDN 适配

- **特点**:
  - 支持 Markdown 导入
  - 代码高亮良好
  - SEO 权重高
- **适配要点**:
  - [ ] 添加 CSDN 目录结构（`@[TOC]`）
  - [ ] 代码块标注语言
  - [ ] 添加相关标签（≤ 5 个）
  - [ ] 设置文章类型（原创/转载）
  - [ ] 添加版权声明
- **输出**: CSDN 版本博客

#### 3.2 掘金适配

- **特点**:
  - Markdown 原生支持
  - 社区技术氛围浓
  - 标签系统丰富
- **适配要点**:
  - [ ] 选择合适标签（≤ 5 个）
  - [ ] 添加封面图
  - [ ] 使用掘金推荐的文章结构
  - [ ] 开头添加摘要（`> ` 引用块）
  - [ ] 关联相关专栏
- **输出**: 掘金版本博客

#### 3.3 知乎适配

- **特点**:
  - 富文本编辑器
  - 长文阅读体验好
  - 适合深度内容
- **适配要点**:
  - [ ] 转换为知乎兼容格式
  - [ ] 添加话题标签
  - [ ] 开头设置悬念/问题
  - [ ] 适当增加段落间距
  - [ ] 图片添加说明文字
  - [ ] 考虑知乎 SEO（问题关联）
- **输出**: 知乎版本博客

### Step 4: 与视频脚本一致性检查

- **动作**:
  1. 对比博客内容与视频脚本的核心信息
  2. 确认数据/事实一致
  3. 确认观点/结论一致
  4. 确认术语使用一致
- **检查项**:
  - [ ] 核心事实一致（数字、名称、日期）
  - [ ] 观点立场一致
  - [ ] 术语翻译一致
  - [ ] 链接/引用一致
  - [ ] 无矛盾信息
- **输出**: 一致性检查报告

### Step 5: 输出

- **最终产出**:
  1. CSDN 版本博客（Markdown）
  2. 掘金版本博客（Markdown）
  3. 知乎版本博客（Markdown）
  4. 一致性检查报告

---

## 4. 注意事项

1. **原创声明**: 各平台均标注原创
2. **交叉引用**: 博客中可引用视频链接，反之亦然
3. **发布节奏**: 建议视频发布后 24 小时内发布博客
4. **评论互动**: 各平台评论需及时回复
