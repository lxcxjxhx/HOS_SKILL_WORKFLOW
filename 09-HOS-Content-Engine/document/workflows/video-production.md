# 视频生产工作流

> 从 4D 资产包到最终视频产出物的标准化工作流。

---

## 1. 工作流概览

```
接收 4D 资产包 → 确定内容支柱 → 生成视频脚本 → 生成元数据 → 生成封面简报 → 委托资产生产 → 一致性检查 → 输出
```

---

## 2. 详细步骤

### Step 1: 接收 4D 资产包

- **输入**: 来自 D1/D2/D3 阶段的资产包
- **动作**:
  1. 验证资产包完整性
  2. 确认质量门已通过
  3. 解析资产包内容（素材、分析、开发成果）
- **检查项**:
  - [ ] 资产包格式正确
  - [ ] 必要字段已填充
  - [ ] 质量门标记为 `passed: true`

### Step 2: 确定内容支柱

- **动作**:
  1. 从资产包读取 `pillar` 字段
  2. 根据支柱选择视频风格和时长：

| 支柱 | 风格 | 目标时长 |
|------|------|----------|
| Pillar 1 | 资讯播报 | 5-8 min |
| Pillar 2 | 技术深读 | 10-15 min |
| Pillar 3 | 纪录片 | 10-20 min |
| Pillar 4 | 故事叙事 | 10-15 min |
| Pillar 5 | 挑战实录 | 10-20 min |
| Pillar 6 | 深度解读 | 8-15 min |

### Step 3: 生成视频脚本

- **调用**: `bilibili-video-script.md` 模板
- **动作**:
  1. 根据支柱选择脚本结构
  2. 从资产包提取核心内容
  3. 填充分镜表各段
  4. 编写口播文案（口语化）
  5. 标注字幕文本
  6. 设计转场和 BGM 建议
- **输出**: 完整视频脚本
- **质量门**:
  - [ ] Hook 5 秒内抓注意力
  - [ ] 信息密度足够
  - [ ] 时长在目标范围内

### Step 4: 生成元数据

- **调用**: `bilibili-metadata.md` 模板
- **动作**:
  1. 生成 SEO 优化标题（≤ 80 字）
  2. 撰写简介（≤ 2000 字）含时间线
  3. 选择标签（≤ 12 个，梯度组合）
  4. 确定分区
  5. 生成封面简报摘要
- **输出**: 完整元数据

### Step 5: 生成封面简报

- **调用**: `thumbnail-brief.md` 模板
- **动作**:
  1. 提炼封面文字（≤ 10 字）
  2. 确定配色方案
  3. 设计构图方案
  4. 提供参考风格
- **输出**: 封面设计简报

### Step 6: 委托资产生产

- **动作**:
  1. 将封面简报发送至 `06-Fuck-Demo` 进行视觉资产生产
  2. 等待封面图生成
  3. 确认视觉资产质量
- **输出**: 封面图 + 其他视觉资产

### Step 7: 一致性检查

- **动作**:
  1. 视频脚本 vs 资产包：内容一致性
  2. 元数据 vs 视频脚本：标题/简介与内容匹配
  3. 封面 vs 视频脚本：视觉风格与内容调性一致
  4. 所有产出物交叉检查
- **检查项**:
  - [ ] 标题准确反映视频内容
  - [ ] 标签与内容主题匹配
  - [ ] 封面风格与视频调性一致
  - [ ] 无事实性错误
  - [ ] 无敏感内容

### Step 8: 输出

- **最终产出**:
  1. 视频脚本（Markdown）
  2. B站元数据（Markdown）
  3. 封面简报 + 封面图
  4. 一致性检查报告

---

## 3. 产出物清单

| 产出物 | 格式 | 说明 |
|--------|------|------|
| 视频脚本 | Markdown | 含分镜表 + 口播文案 |
| 元数据 | Markdown | 标题/简介/标签/分区 |
| 封面简报 | Markdown | 设计指导 |
| 封面图 | PNG/JPG | 最终封面 |
| 一致性报告 | Markdown | 交叉检查结果 |
