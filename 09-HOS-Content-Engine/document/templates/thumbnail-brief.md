## 封面文字

- **要求**: ≤ 10 字
- **原则**: 简洁有力，一眼能懂

```
主文字: [填写]
副文字: [可选，填写]
```

### 文字要求

1. 字数不超过 10 个汉字
2. 使用短句或关键词组合
3. 避免完整句子，追求视觉冲击力
4. 与视频标题互补而非重复

### 示例

| 视频类型 | 封面文字示例 |
|----------|-------------|
| 安全漏洞分析 | `这个Bug价值百万` |
| 源码深读 | `拆解 Ollama` |
| PR 贡献 | `我的第一个PR` |
| 周报 | `AI安全周报#42` |
| 挑战赛 | `72小时挑战` |

## 构图方案

```
布局: [描述，如 左文右图 / 居中对称 / 对角线构图]
主体: [描述画面主体元素]
层次: [前景/中景/背景描述]
```

### 构图原则

1. **三分法**: 关键元素放在三分线交点
2. **留白**: 不要填满整个画面
3. **层次**: 前景文字 + 中景主体 + 背景氛围
4. **对比**: 明暗对比、大小对比、色彩对比
