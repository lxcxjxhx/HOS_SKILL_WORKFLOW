## 标准结构

### 1. Hook（0:00-0:30）

> 目标：30 秒内抓住观众注意力

- **画面**: [描述开场画面]
- **口播**:
  ```
  [开场白文案]
  ```
- **要点**:
  - 抛出核心问题或惊人事实
  - 制造悬念或好奇心
  - 避免冗长铺垫

### 2. 背景铺垫（0:30-2:00）

> 目标：建立上下文，让观众理解话题背景

- **画面**: [描述背景画面/图表]
- **口播**:
  ```
  [背景介绍文案]
  ```
- **要点**:
  - 介绍话题背景
  - 说明为什么重要
  - 预告视频内容结构

### 3. 核心内容（2:00-7:00）

> 目标：传递核心信息，展开主要论述

- **画面**: [描述核心内容画面]
- **口播**:
  ```
  [核心内容文案]
  ```
- **要点**:
  - 分点论述，逻辑清晰
  - 配合代码演示 / 图表 / 动画
  - 每 2-3 分钟设置一个小高潮或转折
  - 保持信息密度，避免注水

### 4. 深度分析（7:00-8:30）

> 目标：提供独到见解，展现专业深度

- **画面**: [描述分析画面]
- **口播**:
  ```
  [深度分析文案]
  ```
- **要点**:
  - 超越表面信息的深层分析
  - 个人见解和独到观点
  - 数据支撑或案例佐证

### 5. 总结回顾（8:30-9:30）

> 目标：强化记忆点，总结核心收获

- **画面**: [描述总结画面]
- **口播**:
  ```
  [总结文案]
  ```
- **要点**:
  - 回顾 3-5 个核心要点
  - 给出行动建议
  - 留下思考题

### 6. CTA 引导（9:30-10:00）

> 目标：引导互动和关注

- **画面**: [描述结尾画面]
- **口播**:
  ```
  [CTA 文案]
  ```
- **要点**:
  - 引导三连（点赞、投币、收藏）
  - 引导关注
  - 预告下期内容
  - 引导评论区互动

## 使用说明

1. 复制本模板到具体项目的视频脚本文件
2. 填写基本信息
3. 按分镜表逐段填写内容
4. 口播文案使用自然口语化表达
5. 字幕文本可略简化（观众会同时听到口播）
6. 完成后对照质量检查清单

### 质量检查清单

- [ ] Hook 是否能在 5 秒内抓住注意力
- [ ] 信息密度是否足够（无注水段落）
- [ ] 每 2-3 分钟是否有节奏变化
- [ ] 技术内容是否有可视化辅助
- [ ] 结尾 CTA 是否自然不突兀
- [ ] 总时长是否在目标范围内
