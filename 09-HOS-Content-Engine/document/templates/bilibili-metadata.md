## 元数据

### 标题

- **要求**: ≤ 80 字
- **格式**: `[主标题] | [副标题/补充]`
- **示例**: `我给 Ollama 提了个 PR，被合并的那一刻我哭了`

```
[填写标题]
```

### 简介

- **要求**: ≤ 2000 字
- **结构**:
  1. 一句话概括视频内容
  2. 视频时间线（可选但推荐）
  3. 相关链接
  4. 话题标签

```
[填写简介]

---
时间线：
0:00 开场
0:30 背景介绍
...

相关链接：
- GitHub: [链接]
- 博客: [链接]

#AI安全 #开源 #编程
```

### 标签

- **要求**: ≤ 12 个


## SEO 优化指南

### 标题优化

1. **关键词前置**: 将核心关键词放在标题前 20 字内
2. **数字效应**: 使用具体数字（"5 个方法"、"3 分钟学会"）
3. **情感触发**: 使用能引发好奇/惊讶/共鸣的措辞
4. **避免标题党**: 标题要准确反映内容，避免过度夸张
5. **搜索友好**: 包含用户可能搜索的关键词

### 简介优化

1. **前两行关键**: 折叠前可见的内容最重要
2. **关键词自然嵌入**: 在简介中自然使用目标关键词
3. **时间线提升体验**: 添加时间线有助于用户导航
4. **链接矩阵**: 关联所有相关平台链接

### 标签策略

1. **梯度组合**: 大流量（>100万）+ 中流量（10-100万）+ 精准（<10万）
2. **时效性标签**: 蹭热点但不偏离主题
3. **品牌标签**: 建立系列内容的统一标签
4. **定期更新**: 根据数据表现调整标签组合

### 封面优化

1. **高对比度**: 确保在手机小屏上清晰可辨
2. **文字精简**: ≤ 10 字，字号要大
3. **人脸效应**: 含人脸的封面通常点击率更高
4. **一致性**: 保持系列封面的视觉一致性
