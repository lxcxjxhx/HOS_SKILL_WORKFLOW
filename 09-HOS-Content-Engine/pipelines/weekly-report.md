# 世界AI安全周报管线

> Pillar 1 — 每周自动生成 AI 安全领域周报，输出视频脚本 + 博客文章。

---

## 1. 管线概览

| 属性 | 值 |
|------|-----|
| 触发词 | `生成AI安全周报` |
| 内容支柱 | Pillar 1 — 世界AI安全周报 |
| 执行频率 | 每周一次（或手动触发） |
| 预估总耗时 | 2–3 小时 |
| 最终产出 | 周报 + B站视频脚本 + 博客文章 |

---

## 2. 执行步骤

### Step 1: D1 全域扫描

- **调用**: `hos-discover`
- **动作**:
  1. 扫描 RSS 源（Hugging Face Blog、OpenAI Blog、Anthropic Blog、arXiv cs.CR/cs.AI）
  2. 扫描 GitHub Trending（security / AI safety 相关）
  3. 扫描 Twitter/X AI 安全领域 KOL 动态
  4. 扫描 Hacker News 安全相关热帖
  5. 扫描国内外安全资讯（FreeBuf、安全客等）
- **输出**: 原始素材包（≥ 20 条）
- **质量门**: 素材数量 ≥ 20，覆盖 ≥ 3 个来源

### Step 2: 聚合 TOP10

- **动作**:
  1. 按影响力 + 新鲜度 + 受众兴趣排序
  2. 筛选 TOP 10 条目
  3. 为每条标注：标题、一句话摘要、来源链接、重要性评分
- **输出**: TOP10 结构化列表

### Step 3: 生成趋势报告

- **动作**:
  1. 分析 TOP10 中的共性趋势
  2. 提炼 2-3 个关键洞察
  3. 撰写周报正文（1500-2500 字）
- **输出**: 周报 Markdown 文档
- **质量门**: 包含趋势分析 + 关键洞察 + 每条新闻摘要

### Step 4: D2 深度分析（可选）

- **触发条件**: TOP10 中有 1-2 条特别值得关注
- **调用**: `hos-dissect`
- **动作**: 对选中条目进行深度源码/技术分析
- **输出**: 深度分析附录（嵌入周报或独立成文）

### Step 5: D4 文档化 — B站视频脚本

- **调用**: `hos-document`
- **格式**: 5-8 分钟视频脚本
- **结构**:
  - Hook (0:00-0:30): 本周最劲爆的安全事件
  - 概览 (0:30-1:30): 本周 AI 安全全景
  - TOP10 逐条解读 (1:30-6:00): 每条 20-30 秒
  - 趋势洞察 (6:00-7:30): 2-3 个关键趋势
  - 总结与展望 (7:30-8:00)
- **输出**: 符合 B站模板的视频脚本

### Step 6: D4 文档化 — 元数据 + 封面简报

- **输出**:
  - B站元数据（标题/简介/标签/分区/封面简报）
  - 封面设计简报

### Step 7: D4 文档化 — 博客文章

- **动作**: 将周报适配为博客格式
- **平台**: CSDN / 掘金 / 知乎（三平台适配）
- **输出**: 各平台版本的博客文章

### Step 8: D3 可选 — PR 贡献

- **触发条件**: 周报过程中发现有趣的 PR 机会
- **调用**: `hos-develop`
- **动作**: 转入 PR 贡献管线（参见 `pr-contribution.md`）

## 3. 周报模板结构

```markdown

> 日期范围：YYYY-MM-DD ~ YYYY-MM-DD
> 编辑：HOS-AI-Security

## 本周概览
（3-5 句话概括本周 AI 安全领域动态）

## 关键趋势
1. 趋势一：XXX
2. 趋势二：XXX
3. 趋势三：XXX

## TOP 10 安全资讯

### 1. [标题]
- **摘要**: 一句话描述
- **影响**: 为什么重要
- **来源**: 链接

### 2. [标题]
...

## 深度聚焦（可选）
（对 1-2 个重点话题的深度分析）

## 下周展望
（预测下周可能的重要事件/发布）

## 参考资料
（所有引用链接汇总）
```
