# B站（Bilibili）平台内容规格

> AI安全实验室频道在 B 站的内容发布规格定义，涵盖标题、描述、标签、分区、封面和发布策略。

---

## 1. 标题规格

### 1.1 基本规则

| 项目 | 规格 |
|------|------|
| 字符上限 | ≤ 80 字符（含标点） |
| 推荐长度 | 20-40 字符 |
| 语言 | 中文为主，技术术语保留英文 |

### 1.2 标题公式

```
[核心关键词] + [数字/数据] + [冲突/悬念]

示例:
✅ "LangChain曝严重漏洞！5分钟搞定Prompt Injection攻击"
✅ "读完10万行源码，我发现了AI框架的致命设计缺陷"
✅ "给HuggingFace提PR被拒3次后，第4次终于合并了"
✅ "GPT-4 vs Claude vs Gemini：谁最抗攻击？实测对比"
❌ "关于LangChain的一些安全问题分析"（太平淡）
❌ "今天我们来聊聊AI安全的那些事情"（无信息量）
```

### 1.3 关键词策略

- **前置核心词**: 技术名称/项目名放最前面（搜索权重更高）
- **数字锚点**: 具体数字提升点击率（"TOP10", "5分钟", "3个漏洞"）
- **冲突制造**: "曝光", "翻车", "被拒", "挑战" 等词增加戏剧性
- **悬念钩子**: "结果出乎意料", "最后一个太离谱" 等引导完播

## 2. 描述规格

### 2.1 基本规则

| 项目 | 规格 |
|------|------|
| 字符上限 | ≤ 2000 字符 |
| 结构 | 钩子段落 + 时间戳章节 + 链接 + 关注引导 |

### 2.2 描述模板

```markdown
[钩子段落 - 1-2句话概括视频核心看点，制造好奇心]

⏱ 时间戳:
00:00 开场
00:30 [章节1标题]
02:15 [章节2标题]
05:40 [章节3标题]
08:20 [章节4标题]
10:00 总结

🔗 相关链接:
• 项目地址: https://github.com/xxx
• 原文博客: [链接]
• 上期回顾: [链接]

📢 关注 AI安全实验室，每周带你追踪全球 AI 安全前沿！
🔔 开启小铃铛，第一时间收到更新通知~

#AI安全 #开源安全 #[相关标签]
```

### 2.3 注意事项

- 第一段是搜索摘要和推荐流预览，必须是最吸引人的内容
- 时间戳章节帮助观众导航，提升完播率
- 链接使用完整 URL（B站描述支持点击）
- 关注引导语固定模板，但可微调措辞避免机械感

## 3. 标签规格

### 3.1 基本规则

| 项目 | 规格 |
|------|------|
| 数量上限 | ≤ 12 个 |
| 推荐数量 | 8-12 个 |
| 结构 | 核心标签 + 长尾标签 + 热门标签 |

### 3.2 标签组合策略

```
核心标签 (3-4个): 定义内容领域
  - AI安全, 网络安全, 开源安全, 人工智能

长尾标签 (3-4个): 精准匹配搜索意图
  - LangChain漏洞, Prompt Injection, 源码分析, PR贡献

热门标签 (2-4个): 蹭热度/扩大曝光
  - 根据当周热点调整，如: ChatGPT, 程序员, 科技, 编程
```

### 3.3 各内容支柱推荐标签

| 支柱 | 固定标签 | 动态标签 |
|------|---------|---------|
| 周报 | AI安全, 网络安全, 开源安全, AI周报 | 当周热点项目名 |
| 源码 | 源码分析, 架构设计, 代码审查, [项目名] | 相关技术栈 |
| 纪录片 | 程序员日常, 开源贡献, AI开发, 真实记录 | 项目名, 技术关键词 |
| PR | 开源贡献, GitHub, PR, [项目名] | 编程语言, 框架名 |
| 挑战 | AI对比, 安全测试, 模型评测, [模型名] | 当周热点模型 |
| Explained | 安全科普, 漏洞分析, 安全原理, [主题词] | 相关CVE编号 |

## 4. 分区选择

### 4.1 主分区

```
科技 > 软件应用      ← 偏应用/工具/产品向内容
科技 > 计算机技术    ← 偏技术/原理/底层向内容
```

### 4.2 选择规则

| 内容类型 | 推荐分区 | 理由 |
|---------|---------|------|
| 周报（偏资讯） | 科技 > 软件应用 | 受众更广，推荐流量大 |
| 源码解读（深度技术） | 科技 > 计算机技术 | 精准触达技术受众 |
| 开发纪录片 | 科技 > 软件应用 | 故事性强，泛科技受众 |
| PR 故事 | 科技 > 软件应用 | 开源故事，受众偏广 |
| 安全挑战 | 科技 > 计算机技术 | 技术对比，硬核内容 |
| Explained | 科技 > 计算机技术 | 概念解释，技术向 |

## 5. 封面（Thumbnail）规格

### 5.1 文字规格

| 项目 | 规格 |
|------|------|
| 文字上限 | ≤ 10 个字符 |
| 字体 | 粗体无衬线（思源黑体 Heavy / 阿里巴巴普惠体 Bold） |
| 颜色 | 白色文字 + 深色描边/阴影，或黄色/红色高亮 |

### 5.2 配色方案

```
主色调:
  - 科技蓝: #1E90FF / #0066CC
  - 安全绿: #00FF88 / #00CC66
  - 警告红: #FF4444 / #CC0000
  - 深色底: #1A1A2E / #16213E

文字:
  - 主标题: 白色 #FFFFFF + 深色投影
  - 强调词: 黄色 #FFD700 或红色 #FF4444
```

### 5.3 构图规则

```
布局: 左文右图 / 上文下图
  - 文字区域: 占封面 40-50%
  - 主视觉: 代码截图/架构图/对比图/人物
  - 品牌标识: 右下角固定 "AI安全实验室" logo

尺寸: 1920x1080 (16:9)
格式: PNG, ≤ 5MB
```

## 6. 发布策略

### 6.1 最佳发布时间

| 时段 | 适合内容 | 理由 |
|------|---------|------|
| 周五 18:00-20:00 | 周报 | 周末有时间看长内容 |
| 周三 12:00-13:00 | 源码/技术 | 工作日午休碎片时间 |
| 周六 10:00-12:00 | 纪录片/挑战 | 周末上午黄金时段 |
| 周日 20:00-22:00 | Explained | 周末晚间学习时段 |

### 6.2 发布频率建议

| 内容支柱 | 频率 | 固定发布日 |
|---------|------|-----------|
| 世界AI安全周报 | 每周 1 期 | 周五 |
| 源码解读 | 每月 2-4 期 | 周三 |
| 开发纪录片 | 持续系列 | 周六 |
| PR 故事 | 每月 1-2 期 | 周六 |
| 安全挑战 | 每月 1-2 期 | 周六 |
| Explained | 每月 2-4 期 | 周日 |

### 6.3 发布 Checklist

- [ ] 标题 ≤ 80 字符，含关键词+数字/冲突
- [ ] 描述 ≤ 2000 字符，含时间戳章节
- [ ] 标签 8-12 个，核心+长尾+热门
- [ ] 分区选择正确
- [ ] 封面文字 ≤ 10 字，配色符合规范
- [ ] 视频时长 8-15 分钟（推荐 10-12 分钟）
- [ ] 视频分辨率 ≥ 1080p
- [ ] 字幕已添加（中文硬字幕）
- [ ] 描述中链接可正常访问
