# 工作流 02 · 50 帧变身差分链

> 用途：从定稿锚点生成平滑渐进的身体变化链（男 → 女），核心卖点。
> 命令：`python src/gen_chain.py --config config.yaml`
> 前置：`out/still/` 三张定稿已存在且用户确认。

## 1. 原理：两段锚定链式 img2img

```
段一（t: 0 → 0.5）:  000_male ──(校准)── 帧01 ──(链)── 帧02 … ── 帧25(=500_mid)
段二（t: 0.5 → 1.0）: 500_mid ──(校准)── 帧26 ──(链)── 帧27 … ── 帧50(=1000_female)
```

- **段首校准帧**（帧 01、帧 26）：以锚点图为底图，`denoise 0.42` 生成段内第一个差异帧，把"趋势"定住。
- **链式帧**：以前一帧为底图，`denoise 0.32` 逐步推进，每帧只改一个差分槽，保证相邻帧连续性。

## 2. 差分槽渐变表（t 轴驱动）

| 槽 | 渐变区间 | 说明 |
|----|----------|------|
| gender | 0.0→0.5 | 1boy → androgynous → 1girl |
| hair_length | 0.0→1.0 | short → medium → very long |
| chest | 0.2→0.9 | flat → small → large |
| waist/hips | 0.2→0.9 | masculine → curvy → hourglass |
| height | 0.0→0.6 | 略缩 |
| skin | 0.3→0.8 | 肤质细化 |
| expression | 0.0→0.5 | stern → neutral → gentle |
| clothes | 0.3→0.9 | 男装 → 中性 → 女装 |
| LoRA 权重 | 0.10→0.90 | Gender Swap LoRA 渐变 |

> 完整 12 槽定义见 [references/tag-slots.md](../references/tag-slots.md)。

## 3. 铁律（违反必翻车）

1. **全程同 seed**——只有 denoise 和槽在变，seed 一旦漂移整条链断。
2. **一次只动一帧一个槽**——相邻帧只允许 1 个槽变化，否则画面跳变。
3. **锚点不动**——000/500/1000 三张定稿是引用物，绝不回写。
4. **中途质检**——每 10 帧抽查 1 帧，气质漂移立即回退到最近校准帧重链。

## 4. 验收标准

- [ ] 50 帧连续，无跳变帧（单帧肉眼变化 ≤ 合理梯度）
- [ ] 帧 01 ≈ 000_male，帧 25 ≈ 500_mid，帧 50 ≈ 1000_female
- [ ] 白底、侧身、构图全程稳定
- [ ] 生成 `out/chain/01.png … 50.png`

## 5. 兜底

画面崩坏无法链式修复时：回到定稿 → 调整槽表粒度（如 chest 渐变拉宽到 0.2→0.9）→ 重跑段一。
