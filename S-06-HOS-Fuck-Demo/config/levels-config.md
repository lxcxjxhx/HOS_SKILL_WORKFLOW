# Levels Config — 三层深度定义（10分钟标准版）

> 定义 L1 / L2 / L3 各层级的输出内容、token 预算和执行约束。
> **所有视频/音频统一为 10 分钟（600 秒）标准长度。**

---

## L1 — 文案 + 10分钟音频（批量模式主力）

### 适用场景
批量课程音频、知识播客、有声短文、短视频长音频、音频专栏

### 输出清单
| # | 产出 | 文件 |
|---|------|------|
| 1 | 10分钟内容包（title + 6 ideas + 3层叙事弧 + 情绪曲线） | `01_content/{id}-idea-{n}.md` |
| 2 | 10分钟音频稿（4幕 ~1800~2200字，含节奏标记） | `03_audio/{id}-script.txt` |

### Token 预算
| 阶段 | 预算 |
|------|------|
| STEP1 方向解析（3钩子） | ≤ 200 tokens |
| STEP2 观点生成（6观点+叙事弧+情绪曲线） | ≤ 800 tokens |
| STEP3 内容包填充 | ≤ 800 tokens |
| STEP5 10分钟音频稿 | ≤ 2000 tokens |
| **每方向总计** | **≤ 4000 tokens** |

### 约束
- ❌ 不生成 PPT
- ❌ 不生成视频 spec
- ❌ 不生成仓库结构
- ✔️ 音频固定 10 分钟标准
- ✔️ 可批量（推荐 batch count ≤ 5）

---

## L2 — PPT + 10分钟音频（课件主力）

### 适用场景
知识付费课件、10分钟培训视频、演讲 PPT + 音频、在线课程

### 输出清单
| # | 产出 | 文件 |
|---|------|------|
| 1 | 10分钟内容包 | `01_content/{id}-idea-{n}.md` |
| 2 | PPT 12页数据（按 ppt 模板，每页映射时间轴） | `02_ppt/{id}-slide.json` |
| 3 | 10分钟音频稿（4幕，精确对齐12页PPT） | `03_audio/{id}-script.txt` |

### Token 预算
| 阶段 | 预算 |
|------|------|
| STEP1 方向解析 | ≤ 200 tokens |
| STEP2 观点生成 | ≤ 800 tokens |
| STEP3 内容包填充 | ≤ 800 tokens |
| STEP4 PPT 12页数据 | ≤ 1000 tokens |
| STEP5 10分钟音频稿 | ≤ 2000 tokens |
| **每方向总计** | **≤ 6000 tokens** |

### 约束
- ❌ 不生成视频 spec
- ❌ 不生成仓库结构
- ✔️ 12页 PPT 固定，不增不减
- ✔️ 音频与 PPT 时间轴对齐
- ✔️ 可少量批量（batch count ≤ 3）

---

## L3 — 完整 Demo + 10分钟视频 + GitHub 发布

### 适用场景
完整项目演示、YouTube/B站 10分钟视频、GitHub 开源发布、作品集

### 输出清单
| # | 产出 | 文件 |
|---|------|------|
| 1 | 10分钟内容包 | `01_content/{id}-idea-{n}.md` |
| 2 | PPT 12页数据 | `02_ppt/{id}-slide.json` |
| 3 | 10分钟音频稿 | `03_audio/{id}-script.txt` |
| 4 | 10分钟视频合成规格（12页→600秒ffmpeg命令） | `04_video/{id}-render-spec.json` |
| 5 | 仓库结构 + commit message | `README.md` + git 指令 |

### Token 预算
| 阶段 | 预算 |
|------|------|
| STEP1 方向解析 | ≤ 200 tokens |
| STEP2 观点生成 | ≤ 1000 tokens |
| STEP3 内容包填充 | ≤ 800 tokens |
| STEP3.5 音频扩展（audio-expander） | ≤ 2000 tokens |
| STEP4 PPT 12页数据 | ≤ 1000 tokens |
| STEP5 10分钟音频稿 | ≤ 2000 tokens |
| STEP6 视频合成规格 | ≤ 1000 tokens |
| STEP7 仓库结构 + commit | ≤ 400 tokens |
| 项目管理登记 | ≤ 400 tokens |
| **每方向总计** | **≤ 12000 tokens** |

### 约束
- ✔️ 包含所有层级产出
- ❌ 不建议 batch（一次一个）
- ✔️ 必须同时生成管理登记
- ✔️ 音频+PPT+视频三者时间轴严格对齐（600秒）
- ✔️ 内容包→音频稿通过 `audio-expander.md` 扩展（自动执行）

## L3-extended — 长视频扩展模式

> 在 L3 基础上扩展音频稿字数，适应 10 分钟全长视频。
> 用于方向需要深度展开、或用户明确要求 10 分钟全长的场景。

### 与 L3 的差异

| 项目 | L3 | L3-extended |
|------|-----|-------------|
| 内容包 tokens | ≤ 800 | **≤ 1500** |
| 音频稿字数 | 1800~2200 | **2500~3000** |
| 音频扩展步骤 | 可选 | **强制** |
| PPT 页数 | 12 | 12（支持子帧轮播） |
| 视频总长 | 600s | **600s ±5%** |
| 总 token 预算 | ≤ 12000 | **≤ 18000** |

### 触发条件

```
自动触发（任一满足）:
  □ 用户深度指定为 "L3-long" 或 "L3-extended"
  □ 内容包展开后预计 < 1500 tokens
  □ direction 复杂度高，6个观点需要更详细展开

手动触发:
  □ 内容包生成后，STEP5 前自动判断是否需要扩展
```

### 扩展流程

```
STEP3(内容包, 800 tokens)
  → 判断需要扩展?
  → STEP3.5 音频扩展 (读 audio-expander.md, 按style/emotion自动扩展)
  → STEP5(音频稿填充, 2500~3000字)
  → 时长验证: 字数 / 3.5 / 0.8 = 600s ±5%
```

### 约束
- ✔️ 仅在 L3 基础上使用
- ✔️ 音频扩展后必须验证时长
- ❌ 不改变 PPT 页数（保持 12 页）
- ❌ 不跳过视频规格生成

## 10分钟标准速查

| 项目 | 原标准（V1） | 新标准（V2） |
|------|-------------|-------------|
| 视频/音频长度 | 40~60 秒 | **600 秒（10 分钟）** |
| 内容包字数 | ~250 字 | **~600~800 字** |
| 核心观点数 | 3 个 | **6 个** |
| PPT 页数 | 6 页 | **12 页** |
| 音频句子数 | ~10 句 | **~60~80 句** |
| 音频总字数 | ~300 字 | **~1800~2200 字** |
| L1 token 预算 | ≤ 800 | **≤ 4000** |
| L2 token 预算 | ≤ 1200 | **≤ 6000** |
| L3 token 预算 | ≤ 2000 | **≤ 10000** |

---

## 自动降级

当 token 预算不足或外部工具不可用时：
- L3 → L2：不生成 video spec + repo structure
- L2 → L1：不生成 PPT
- L1 → 仅内容包：不生成音频稿（输出纯文案）

## 自动执行集成

本配置被 `skill/auto-pipeline.md` 引用。AI 在自动执行时：
1. 读取本文件确定某 depth 的输出清单和 token 预算
2. 按 `auto-pipeline.md` 的自动执行规则逐个 STEP 执行
3. 每 STEP 执行后触发 `core.flow.md` 中的质量门禁
4. 全部完成后触发 `management/auto-register.md` 自动注册
