# Style Presets — 风格预设集

> 控制内容风格。每个 style 影响语言密度、结构复杂度、修辞方式。
> 当用户指定 `style` 参数时读取本文件。默认 `academic`。

---

## Style 定义

### academic — 学术/知识风格

| 维度 | 特征 |
|------|------|
| 语言 | 正式、准确、中性 |
| 结构 | 问题 → 分析 → 结论 |
| 修辞 | 数据、引用、逻辑链 |
| 标题 | 陈述式："XXX的3个原则" |
| 句长 | 中等（15~25字） |
| 适合 | 课程、培训、知识分享 |

### hype — 营销/传播风格

| 维度 | 特征 |
|------|------|
| 语言 | 短促、有力、情绪化 |
| 结构 | 钩子 → 痛点 → 方案 → 行动 |
| 修辞 | 对比、夸张、反问 |
| 标题 | 数字+悬念："99%的人不知道" |
| 句长 | 短（8~15字） |
| 适合 | 短视频、营销文案、社交媒体 |

### calm — 沉稳/深度风格

| 维度 | 特征 |
|------|------|
| 语言 | 克制、留白、有重量 |
| 结构 | 故事 → 体悟 → 启发 |
| 修辞 | 隐喻、类比、独白 |
| 标题 | 简短、有哲学感："慢下来，才能快" |
| 句长 | 短但有力（10~18字） |
| 适合 | 价值观内容、深度文章、有声书 |

### storytelling — 叙事/故事风格

| 维度 | 特征 |
|------|------|
| 语言 | 画面感、细节、对话感 |
| 结构 | 场景 → 冲突 → 解决 → 升华 |
| 修辞 | 具象描写、悬念、对话 |
| 标题 | 故事化："那个被AI替代的同事" |
| 句长 | 多变（5~30字混合） |
| 适合 | 有声书、案例、个人品牌 |

| | academic | hype | calm | storytelling |
|---|---------|------|------|-------------|
| anxiety | ⚠️ 勉强 | ✔️ 原生 | ❌ 冲突 | ✔️ 可用 |
| hope | ✔️ 可用 | ✔️ 可用 | ✔️ 原生 | ✔️ 可用 |
| identity | ✔️ 可用 | ✔️ 可用 | ✔️ 可用 | ✔️ 原生 |
| elite | ✔️ 原生 | ❌ 冲突 | ✔️ 可用 | ⚠️ 勉强 |

✔️ 推荐  ⚠️ 可用但效果一般  ❌ 风格冲突不推荐

---

## 使用规则

1. style 决定**表达方式**，emotion 决定**情感底色**，两者正交
2. 不指定 style 时默认 `academic`
3. 内容包模板结构**不随 style 变化**（只改措辞，不改槽位）
