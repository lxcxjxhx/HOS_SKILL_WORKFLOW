# Batch Plan Template — 批量生产计划模板

> `batch` 模式下，在执行前先生成此计划供用户确认。

---

## 模板

```markdown
## 📋 批量生产计划

**方向**: {{direction}} | **数量**: {{count}} | **深度**: {{depth}}
**风格**: {{style}} | **情绪**: {{emotion}}

### 内容分配

| # | 子方向/钩子 | 预计输出 |
|---|------------|---------|
| 1 | {{hook_or_subdir_1}} | 内容包 + {{附加产出}} |
| 2 | {{hook_or_subdir_2}} | 内容包 + {{附加产出}} |
| 3 | {{hook_or_subdir_3}} | 内容包 + {{附加产出}} |
| 4 | {{hook_or_subdir_4}} | 内容包 + {{附加产出}} |
| 5 | {{hook_or_subdir_5}} | 内容包 + {{附加产出}} |

### 输出结构

```
batch-{direction}-{timestamp}/
├── 01-{title_1}/
├── 02-{title_2}/
├── 03-{title_3}/
├── 04-{title_4}/
└── 05-{title_5}/
```

### Token 预估

| 项目 | 单次 | ×{count} | 总计 |
|------|------|---------|------|
| 内容包 | ~300t | ×{count} | ~{{n}}t |
| 音频稿 | ~200t | ×{count} | ~{{n}}t |
| **总计** | | | **~{{total}} tokens** |

---

> 确认执行此批量计划？(Y/N)
```
