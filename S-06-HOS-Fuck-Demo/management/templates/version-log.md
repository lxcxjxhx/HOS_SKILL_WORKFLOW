# Version Log — 版本日志模板

> 每个项目的变更历史记录。
> 存放位置：`output/{project-id}/version-log.md`

---

```markdown
# Version Log — {{project_id}}

## v{{version}} — {{date}}

### 变更类型
- [ ] 新建
- [ ] 内容更新
- [ ] 审核通过
- [ ] 审核不通过
- [ ] 发布
- [ ] 归档

### 变更说明

{{description}}

### 影响范围

- [ ] 内容包
- [ ] PPT
- [ ] 音频
- [ ] 视频
- [ ] 元信息

### 审核记录

- 审核人: {{reviewer}}
- 结果: pass / fail
- 备注: {{notes}}
```

---

## 日志示例

```markdown
# Version Log — course-001-ai-security

## v1.1.0 — 2026-06-30

### 变更类型
- [x] 内容更新

### 变更说明
更新了"AI编码助手"钩子的数据，将替代率从60%修正为70%。

### 影响范围
- [x] 内容包
- [ ] PPT
- [x] 音频
- [ ] 视频
- [ ] 元信息

---

## v1.0.0 — 2026-06-28

### 变更类型
- [x] 新建

### 变更说明
项目创建，初始内容生产。

### 影响范围
- [x] 内容包
- [x] PPT
- [x] 音频
- [ ] 视频
- [ ] 元信息
```
