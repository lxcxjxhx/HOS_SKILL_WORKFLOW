# 场景记忆索引（Scenario Memory Index）— 模板

> **提交 PR 前必须检索本索引**；每次真实 PR 交互后必须新增/更新一行。本文件是模板：实际记录存放在用户本地（见 [README.md](README.md)），此处仅作格式示例，**不要提交含逐字反馈的真实记录**。

## 索引表（示例）

| ID | 日期 | 项目 | 关键词 | 闸门命中 | 状态 | 记录文件 |
|----|------|------|--------|---------|------|---------|
| SCN-001 | 2026-08-01 | Datus-ai/Datus-agent #1236 | self-join, LAG, POP, 环比, 语义混用, 纯AI PR, 窗口函数, 指标计算, internal representation | G1, G2, G3 | 被批评 | 用户本地 `~/.claude/memory/scenario-records/` |

## 使用方法

### 提交前（consult）
1. 用项目名 + 技术术语 + 改动类型检索本表。
2. 命中 → 读取记录，把其"提炼规则"纳入本次提交的 G3/G5 依据。
3. 未命中 → 继续，但本次交互后要新增记录。

### 提交后（write）
1. 无论成功/失败/被批评，新建 `scenario-records/<日期>-<项目>-<主题>.md`（**存用户本地**）。
2. 记录维护者**逐字**反馈（verbatim，勿转述）。
3. 更新本索引表（本仓库版本仅记关键词与 PR 链接，不记逐字反馈）。
4. 把新增"提炼规则"回流到 `experience/failure-modes.md`。
