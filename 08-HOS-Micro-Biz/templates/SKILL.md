# Client Communication SOP

## Requirements Confirmation Checklist

### Basic Info
- [ ] Project type (coursework / thesis / tool / other)
- [ ] Tech stack requirements (specific language/framework?)
- [ ] Feature list (itemized)
- [ ] Reference/template/examples available?
- [ ] Deliverables (code + docs + PPT?)

### Delivery Requirements
- [ ] Deadline
- [ ] Format requirements (coding standards, comment requirements)
- [ ] Need explanation/defense coaching?
- [ ] After-sales modification count agreement

### Business Terms
- [ ] Quote confirmed
- [ ] Deposit ratio (default 50%)
- [ ] Payment method
- [ ] Delivery method (GitHub / archive / remote demo)

## Communication Scripts

### Initial Inquiry
```
Hi! Tell me about your requirements?
What needs to be done, what tech stack, when is it due?
I will check if I can do it, free of charge.
```

### When Requirements Are Vague
```
I understand the general idea, but need to confirm some details:
1. [Specific question 1]
2. [Specific question 2]
Could you send a requirements doc / screenshot / reference link?
This helps me give you a more accurate quote.
```

### Standard Quote
```
Hi, I have reviewed your requirements:
- Features: [list]
- Estimated hours: ~X hours
- Quote: XXXX CNY (includes code + docs + 7-day after-sales Q&A)
- Delivery: X days
50% deposit to start, balance upon acceptance.
```

### Negotiation Response
```
Price can be adjusted, but depends on whether we can reduce some features.
For example, removing [feature] saves XX CNY.
Or if the timeline is flexible, I can offer 10% off for next week.
```

### Delivery
```
Done! Here is what I prepared:
[Deliverables description]
Code has detailed comments, documentation is ready.
Review it and let me know if you have questions.
Once confirmed, please send the balance payment.
```

### After-Sales
```
This issue is caused by [reason].
I will fix it and send it to you by [time].
(Within after-sales scope, no charge)
```

```
This modification is beyond the original scope.
It counts as a new requirement, quoted at XX CNY. Want to proceed?
```
