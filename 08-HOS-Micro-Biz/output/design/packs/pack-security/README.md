## 文字叠加规范

所有图片均为背景图，文字需在投放平台编辑器或设计工具中叠加：

- **HOS logo**：衬线字体，白色 #F5F0FF，28px
- **主标题**：衬线字体，白色，36-48px
- **价格**：等宽字体，金色 #FFB347，32px
- **授权相关文字**：勃艮第红 #8B1A3C，加粗（强调合规）
- **红线声明**：无衬线，勃艮第红 #8B1A3C，14px
- **三色色带**：图片顶部/底部 4px 紫红绿三等分色带
