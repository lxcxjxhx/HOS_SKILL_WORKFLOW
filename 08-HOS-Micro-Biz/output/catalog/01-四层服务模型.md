# 四层服务模型

> **模块**: catalog
> **文档编号**: CAT-0001
> **版本**: 1.0.0 | **最后更新**: 2026-07-26
> **适用阶段**: 冷启动 / 稳定期 / 扩张期

---

## 模型总览

技术服务采用四层服务分层模型，每层承担不同战略角色：

| 层级 | 定位 | 客单价区间 | 核心目的 |
|------|------|-----------|---------|
| 引流品 | 免费或极低价 | 0-10 CNY | 建立信任，筛选精准客户 |
| 标品 | 标准化服务 | 30-500 CNY | 稳定现金流，可批量交付 |
| 利润品 | 定制化服务 | 500-5000 CNY | 高客单价，深度服务 |
| 形象品 | 高端咨询服务 | 5000+ CNY | 提升品牌，拉高客单价天花板 |

```
┌─────────────────────────────────────────────┐
│              形象品（品牌天花板）               │
│  企业安全顾问 / 技术架构咨询 / 长期驻场         │
│  客单价：5000+ CNY                           │
├─────────────────────────────────────────────┤
│              利润品（核心利润）                 │
│  毕设全程辅导 / AI 应用开发 / 安全审计          │
│  客单价：500-5000 CNY                        │
├─────────────────────────────────────────────┤
│              标品（稳定现金流）                 │
│  课设辅导 / 代码调试 / 文档撰写 / 环境搭建     │
│  客单价：30-500 CNY                          │
├─────────────────────────────────────────────┤
│              引流品（获客入口）                 │
│  免费 5 分钟咨询 / 9.9 元环境配置教程          │
│  客单价：0-10 CNY                            │
└─────────────────────────────────────────────┘
```

## 第一层：引流品

### 定位
获客入口，通过极低门槛吸引潜在客户接触你的服务，建立初步信任。

### 典型服务

| 服务项 | 价格 | 交付形式 | 信任建立机制 |
|--------|------|---------|-------------|
| 免费技术咨询 | 0 CNY | 5 分钟内文字回复 | 展示专业能力，快速响应 |
| 环境配置教程 | 9.9 CNY | 图文教程 / 远程协助 | 低成本解决真实问题 |
| 代码诊断 | 免费 | 指出问题方向，不修复 | 让客户感受到"这人真懂" |
| 技术选型建议 | 免费 | 文字回复 | 展示经验广度 |

### 运营策略
- **频率**：每周 2-3 次免费咨询，控制在 5 分钟内
- **边界**：免费咨询只"诊断"不"治疗"，给出方向但不动手
- **转化路径**：咨询中自然引出"这个我可以帮你做，要不要看看报价？"
- **话术要点**：先给价值，再提服务。不要上来就推销

### 注意事项
- 免费咨询设明确时间边界（"我给你看 5 分钟"）
- 避免"免费做完了客户就跑了"的情况：给方案不给完整代码
- 9.9 元教程是筛选机制——愿意付 9.9 元的人，才是潜在付费客户

---

## 第二层：标品

### 定位
标准化服务，需求明确、交付流程固定，可批量处理。这是日常收入的基本盘。

### 典型服务

| 服务项 | 起步价 | 交付周期 | 标准化程度 | 批量可行性 |
|--------|--------|---------|-----------|-----------|
| 代码调试 | 30 CNY | 1-24h | 高 | 可同时接 3-5 单 |
| 环境搭建 | 50 CNY | 1-6h | 高 | 可同时接 3-5 单 |
| 文档撰写 | 100 CNY | 1-2 天 | 中 | 可同时接 2-3 单 |
| 课设辅导 | 200 CNY | 3-7 天 | 中 | 可同时接 2-3 单 |
| 实验报告 | 80 CNY | 1-2 天 | 高 | 可同时接 3-5 单 |

### 运营策略
- **交付清单**：每类标品准备标准化交付物模板，减少定制工作量
- **定价策略**：起步价固定，复杂度加价用系数表（参考 [定价策略引擎](02-定价策略引擎.md)）
- **复购设计**：课设客户下学期大概率还有需求，主动跟进
- **转介绍激励**：标品客户转介绍意愿最高（客单价低，决策门槛低）

### 批量交付流程
1. 收到需求 → 用 [需求确认 Checklist](../templates/01-需求确认checklist.md) 快速评估
2. 匹配标品模板 → 确定是否需要定制
3. 标准品直接报价，定制品加价
4. 交付后引导评价/转介绍

## 第三层：利润品

### 定位
高客单价、深度服务，是利润的主要来源。需要投入更多时间但单价也更高。

### 典型服务

| 服务项 | 起步价 | 交付周期 | 典型工时 | 利润率 |
|--------|--------|---------|---------|--------|
| 毕设全程辅导 | 800 CNY | 2-8 周 | 20-60h | 70-80% |
| AI 应用开发 | 1000 CNY | 7-30 天 | 15-50h | 65-75% |
| 安全审计 | 500 CNY | 3-7 天 | 10-30h | 70-80% |
| RAG 系统搭建 | 500 CNY | 3-7 天 | 10-20h | 65-75% |
| 定制工具开发 | 300 CNY | 3-14 天 | 8-30h | 70-80% |

### 运营策略
- **客户分级**：利润品客户是核心资产，提供差异化服务体验
- **分阶段交付**：大额订单（>2000 CNY）分 2-3 阶段交付，降低双方风险
- **需求锁定**：开工前必须书面确认需求清单，中途变更重新报价
- **案例积累**：每个利润品交付后都整理为案例素材（供 marketing 使用）
- **长期关系**：毕设客户后续可能需要论文辅导、工作推荐等延伸服务

### 风险控制
- 必收定金（默认 50%）再开工
- 需求变更必须书面确认 + 重新报价（参考 [风险防控 Checklist](../compliance/02-风险防控checklist.md)）
- 大额订单建议分阶段付款（50% 定金 + 30% 中期 + 20% 尾款）

## 第四层：形象品

### 定位
高端咨询服务，提升个人品牌和专业形象。即使不常接，也能拉高客户对你整体定价的认知锚点。

### 典型服务

| 服务项 | 起步价 | 交付形式 | 客户类型 | 品牌价值 |
|--------|--------|---------|---------|---------|
| 企业安全顾问 | 5000 CNY/月 | 定期巡检 + 报告 | 中小企业 | 建立"专业"标签 |
| 技术架构咨询 | 300 CNY/h | 线上会议 | 创业团队 | 展示系统设计能力 |
| 技术培训 | 200 CNY/h | 直播/录播 | 团队/机构 | 建立"导师"人设 |
| 长期技术顾问 | 8000 CNY/月 | 持续支持 | 固定客户 | 稳定收入预期 |

### 运营策略
- **不主动推销**：形象品通过朋友圈案例展示和客户口碑自然引流
- **案例包装**：将形象品项目包装为"高光案例"在朋友圈/小红书展示
- **锚定效应**：即使客户最终选了标品，"我平时做企业顾问的"这句话会让他觉得你的定价合理
- **转介绍**：形象品客户社交圈质量高，转介绍价值大

### 注意事项
- 形象品需要真实项目经验支撑，不可虚构
- 初期没有案例时，可用学校/实验室项目作为"培训经历"展示
- 形象品客户期望值高，务必确保交付质量

## 服务组合设计工作表

根据个人情况填写以下工作表，生成适合你的服务组合：

```
=== 个人情况 ===
我的技术栈：[如 Python / Java / AI / 安全]
目标客户群体：[如 在校大学生 / 初创团队 / 中小企业]
每周可投入时间：[如 15 小时]
期望月收入：[如 5000 CNY]
目前最擅长的 3 个方向：
  1. [方向1]
  2. [方向2]
  3. [方向3]

=== 推荐组合（示例） ===
引流品：免费 5 分钟咨询 + 9.9 元环境配置
标品：代码调试 + 课设辅导（主力，每周 3-5 单）
利润品：毕设全程辅导 + AI 应用（每月 1-2 单）
形象品：暂不主动推广，等案例积累后启动
```

### 组合建议

| 阶段 | 引流品 | 标品 | 利润品 | 形象品 |
|------|--------|------|--------|--------|
| 冷启动（0-3 月） | 2-3 种 | 3-5 种 | 1-2 种 | 0 种 |
| 稳定期（3-12 月） | 1-2 种 | 4-6 种 | 2-4 种 | 0-1 种 |
| 扩张期（12 月+） | 1 种 | 5-8 种 | 3-5 种 | 1-2 种 |

## 层级转化路径

```
引流品客户
    │
    │ 信任建立后，自然需求出现
    ↓
标品客户（首次付费）
    │
    │ 体验满意后，升级需求
    ↓
利润品客户（高价值单）
    │
    │ 长期信任积累
    ↓
形象品客户 / 转介绍来源
```

### 转化话术

**引流品 → 标品**
```
"这个问题我帮你看了，是 [技术原因] 导致的。
完整修复的话大概需要 [X] 小时，我可以帮你做。
要不要我报个价？"
```

**标品 → 利润品**
```
"你这个课设如果只是交差的话，现在这样就够了。
但如果你想让答辩更出彩，我可以帮你加个 [亮点功能]，
答辩老师肯定会问到的。加这个的话 [报价] 就能搞定。"
```

**利润品 → 转介绍**
```
"做完了，你觉得满意的话，
如果有同学也需要的可以推荐给我，
你们俩都能减 50 块。"
```
