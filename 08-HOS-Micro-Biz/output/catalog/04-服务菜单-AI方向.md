## 一、服务总览

本菜单覆盖 HOS 微商技术服务在"人工智能方向"对外承接的五类标准化服务。AI 服务与程序设计服务在交付物、验收标准、成本结构上差异显著,接单前必须完成「算力成本核算、模型许可证确认、数据隐私评估」三项前置检查。

| 编号 | 服务项 | 服务说明 | 起步价 | 交付周期 | 典型难度区间 |
|------|--------|----------|--------|----------|--------------|
| A-01 | 模型部署 | 本地/云端 LLM 部署 | ¥200 起 | 1-3 天 | D2-D4 |
| A-02 | Prompt 工程 | 提示词优化 / Agent 设计 | ¥100 起 | 1-3 天 | D1-D3 |
| A-03 | RAG 系统 | 知识库问答系统搭建 | ¥500 起 | 3-7 天 | D3-D4 |
| A-04 | 数据分析 | 数据清洗 + 可视化 + 报告 | ¥300 起 | 2-5 天 | D2-D4 |
| A-05 | AI 应用开发 | ChatBot / 智能体 / 插件 | ¥1000 起 | 7-30 天 | D3-D5 |

> **难度系数说明**:D1=入门(调 API、单轮 Prompt);D2=基础(多轮 Prompt、本地小模型);D3=进阶(RAG、Agent、微调);D4=复杂(多模型协同、生产部署);D5=高难(自训练、分布式推理、垂直领域优化)。

## 二、模型部署服务(A-01)

### 2.1 服务说明

为客户在本地服务器、私有云或公有云上部署大语言模型(LLM)或视觉模型,使其可通过 API 或 Web 界面调用。覆盖环境配置、模型下载、推理引擎选型、接口封装、性能调优。不含模型训练,不含硬件采购。

### 2.2 交付物清单

| 交付物 | 形式 | 是否必交 |
|--------|------|----------|
| 部署脚本 | shell/ansible,幂等可重复执行 | 必交 |
| 推理服务 | OpenAI 兼容 API 或 Web UI | 必交 |
| 配置说明 | 模型路径、显存配置、并发参数 | 必交 |
| 压测报告 | QPS、首 token 延迟、显存占用 | 必交 |
| 运维手册 | 启停、日志、扩容、回滚 | 必交 |
| 模型权重 | 下载地址或本地文件 | 必交(合规前提下) |

### 2.3 工时拆解参考

| 阶段 | 工作内容 | 参考工时 |
|------|----------|----------|
| 环境评估 | 硬件盘点、CUDA/驱动、网络 | 1-2h |
| 引擎选型 | vLLM / Ollama / TGI / llama.cpp | 1-2h |
| 部署实现 | 下载、加载、接口封装 | 3-8h |
| 性能调优 | 量化、并发、KV cache | 2-6h |
| 压测与文档 | 压测脚本、报告、手册 | 2-4h |
| 合计 | — | 9-22h |

### 2.4 难度系数参考

| 难度 | 判定条件 | 系数 |
|------|----------|------|
| D2 | Ollama 一键部署 7B 模型,单机单卡 | ×1.2 |
| D3 | vLLM 多卡部署,需量化与并发配置 | ×1.8 |
| D4 | 多节点分布式、K8s 编排、私有镜像仓库 | ×2.6 |

### 2.5 报价区间推演

```
场景 A:本地部署 Qwen2-7B,Ollama,仅供个人调用
  工时 8h × 单价 50 × D2(1.2) = ¥480
  → 成交价 ¥480

场景 B:云端部署 Llama3-8B,vLLM,OpenAI 兼容 API
  工时 16h × 单价 55 × D3(1.8) = ¥1584
  含压测报告 → ¥1680

场景 C:多机部署 70B 模型,4 卡分布式,需 K8s
  工时 22h × 单价 60 × D4(2.6) = ¥3432
  算力由客户承担 → ¥3432
```

### 2.6 适用客户画像

- 企业 IT 部门,需私有化 LLM 保障数据不出域
- 研究团队,需稳定推理服务支撑实验
- 独立开发者,需低成本跑开源模型

### 2.7 交付标准与验收点

1. 推理服务在客户指定硬件上稳定启动,持续运行 2 小时无 OOM;
2. OpenAI 兼容接口可被标准 SDK 调用,返回格式正确;
3. 压测报告包含 QPS、P95 延迟、显存峰值三项指标;
4. 运维手册让客户能独立完成启停与日志查询;
5. 模型权重来源合规(见第五章许可证合规)。

### 2.8 售后边界

| 售后项 | 是否包含 | 说明 |

## 四、RAG 系统服务(A-03)

### 4.2 交付物清单

| 交付物 | 形式 | 是否必交 |
|--------|------|----------|
| 系统源码 | 前端 + 后端 + 索引服务 | 必交 |
| 文档处理脚本 | PDF/Word/Markdown 解析与分块 | 必交 |
| 向量库 | Milvus/Chroma/Qdrant 配置 | 必交 |
| 知识管理后台 | 上传、删除、重建索引 | 必交 |
| 问答前端 | Web 界面,含引用溯源 | 必交 |
| 部署文档 | docker-compose 一键启动 | 必交 |
| 评测报告 | 召回率、答案准确率 | 必交 |
| 调优参数表 | chunk size、top-k、rerank | 必交 |

### 4.3 工时拆解参考

| 生成与引用 | Prompt、引用溯源、重排 | 4-8h |
| 前后端开发 | 管理后台、问答界面 | 8-16h |
| 评测调优 | 评测集、指标、迭代 | 4-8h |

### 4.6 适用客户画像

- 企业,需内部知识库问答

| 模型训练/微调 | 不包含 | 另行专项报价 |

## 七、AI 服务交付验收标准

AI 服务的"效果"具有不确定性,验收必须以可量化的指标为准。以下为通用验收框架,具体指标在需求确认阶段写入协议。

### 7.1 效果指标约定模板

```
【任务准确率】
  定义:在客户提供的评测集(≥50 条)上,输出被人工判定为正确的比例
  达标线:A-02/A-03 ≥80%,A-05 ≥75%(复杂任务可议)
  评测方式:双方共同标注,争议条目由第三方裁决

【召回率】(RAG 专用)
  定义:Top-k 检索结果中包含正确文档的比例
  达标线:≥85%

【延迟】
  定义:首 token 延迟 / 端到端 P95 延迟
  达标线:首 token ≤2s,端到端 P95 ≤5s(取决于硬件)

【稳定性】
  定义:连续运行 24h 无崩溃,OOM 次数为 0
  达标线:满足

【成本】
  定义:单次调用平均 token 消耗 × 单价
  达标线:不超过约定上限的 120%
```

### 7.2 验收流程

1. 交付前由 HOS 提供内部评测报告;
2. 客户在 3 个工作日内组织验收,使用约定评测集;
3. 验收通过则签署验收单,进入售后期;
4. 验收不通过则进入返工,返工不超过 2 轮,每轮 5 个工作日;
5. 2 轮返工后仍未达标,按协议约定退款或协商降级交付。

## 八、AI 服务特殊性说明

### 8.1 算力成本核算

AI 服务的成本结构中,算力成本可能超过人力成本,必须在报价阶段单独核算并向客户明示。

**核算公式**:
```
算力成本 = 训练/推理时长 × 单价 + 存储成本 + 网络流量
```

**责任划分**:
- 算力费用由客户承担,HOS 仅收取服务费;
- 如由 HOS 代采算力,加收 10% 管理费;
- 报价单须列明「服务费」与「算力费」两栏,不得混算。

### 8.2 模型许可证合规

接单前必须确认所用模型的许可证允许客户的使用场景,常见模型许可证如下:

| 模型族 | 许可证 | 商用限制 |
|--------|--------|----------|
| Llama 3 | Llama 3 Community License | ≥7 亿月活需授权 |
| Qwen | Apache 2.0 / Tongyi Qianwen License | 多数可商用,需核实 |
| Mistral | Apache 2.0(部分)/ MNL | 部分模型受限 |
| GLM | 智谱开源协议 | 需登记 |
| DeepSeek | MIT | 可商用 |
| GPT-4o(闭源) | OpenAI Terms | 禁止特定场景 |

**合规要求**:
1. 交付文档须注明模型名称、版本、许可证来源链接;
2. 如客户月活超阈值,须提示其申请商用授权;
3. 闭源 API 服务须提示数据出境合规风险;
4. 不得部署明确禁止商用的模型用于客户商业场景。

### 8.3 数据隐私边界

| 数据类型 | 处理方式 | 说明 |
|----------|----------|------|
| 客户业务数据 | 不得用于训练 | 协议明确禁止 |
| 客户对话日志 | 默认不存储 | 如需存储须脱敏 |
| 个人信息(PII) | 部署前脱敏 | 涉及 GDPR/个保法 |
| 敏感行业数据(医疗/金融) | 签保密协议 | 限本地部署 |
| 训练数据集 | 需确认来源合法 | 禁用爬取的受版权数据 |

**红线**:
- 不得将客户数据用于训练 HOS 自有模型;
- 不得将客户数据共享给第三方模型服务商(除非客户书面同意);
- 涉及未成年人数据一律拒接。

## 九、算力成本估算表

以下为常见场景的算力成本估算,仅供客户预算参考,实际以云厂商计费为准。价格为 2026 年参考价,可能波动。

### 9.1 本地部署 vs 云端部署对比

| 维度 | 本地部署 | 云端部署(按量) | 云端部署(包月) |
|------|----------|------------------|------------------|
| 初始硬件投入 | 高(¥1.5 万-15 万) | 无 | 无 |
| 单次推理成本 | 极低(电费) | 中(按 token/秒) | 低(固定) |
| 适用场景 | 长期高频调用 | 短期/峰值 | 稳定中频 |
| 运维复杂度 | 高 | 低 | 中 |
| 数据隐私 | 强 | 弱(数据出域) | 弱 |
| 弹性扩展 | 差 | 好 | 一般 |

### 9.2 典型模型算力成本参考

| 模型规模 | 本地硬件要求 | 本地电费/月 | 云端按量(¥/小时) | 云端包月(¥/月) |
|----------|--------------|-------------|---------------------|------------------|
| 7B | RTX 4060 8G 起 | ¥150-300 | ¥3-8 | ¥1500-3000 |
| 13B | RTX 4090 24G | ¥300-500 | ¥8-15 | ¥3500-6000 |
| 70B | 2×A100 80G | ¥800-1500 | ¥30-60 | ¥12000-25000 |
| 闭源 API(GPT-4o) | 无 | — | 按 token,¥0.03/1K in | — |

> **注**:以上为推理成本,训练/微调成本另行核算,通常为推理的 5-20 倍。

### 9.3 成本估算示例

```
场景 A:企业内部问答,7B 本地部署,日均 1000 次调用
  硬件:RTX 4060 整机 ¥8000(客户一次性投入)
  电费:¥200/月
  vs 云端:¥2000/月
  回本周期:约 4 个月
  → 建议本地部署

场景 B:活动短期 ChatBot,7B,2 周峰值
  本地:硬件 ¥8000(不划算)
  云端按量:¥3/h × 336h = ¥1008
  → 建议云端按量

场景 C:生产级 70B 服务,7×24
  本地:2×A100 整机 ¥15 万,电费 ¥1200/月
  云端包月:¥18000/月
  回本周期:约 9 个月
  → 高频建议本地,低频建议云端
```
