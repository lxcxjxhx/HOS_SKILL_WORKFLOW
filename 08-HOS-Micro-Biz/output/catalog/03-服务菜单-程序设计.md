## 一、服务总览

本菜单覆盖 HOS 微商技术服务在"程序设计"方向对外承接的六类标准化服务。所有报价均为起步价,最终成交价由「难度系数 × 工时 × 紧急度系数」推演得出,具体推演方法见《定价策略引擎》(CAT-0002)。

| 编号 | 服务项 | 服务说明 | 起步价 | 交付周期 | 典型难度区间 |
|------|--------|----------|--------|----------|--------------|
| P-01 | 代码调试 | 定位 Bug + 修复 + 讲解 | ¥30 起 | 1-24h | D1-D3 |
| P-02 | 课设辅导 | 需求分析 + 代码实现 + 文档 | ¥200 起 | 3-7 天 | D2-D4 |
| P-03 | 毕设全程 | 选题 → 开题 → 实现 → 答辩 PPT | ¥800 起 | 2-8 周 | D3-D5 |
| P-04 | 脚本/工具 | Python/JS 自动化脚本 | ¥100 起 | 1-3 天 | D1-D3 |
| P-05 | 网站开发 | 静态页面 / 全栈应用 | ¥500 起 | 3-14 天 | D2-D5 |
| P-06 | 小程序开发 | 微信小程序 / Uni-app | ¥1000 起 | 7-30 天 | D3-D5 |

> **难度系数说明**:D1=入门(单文件、无依赖);D2=基础(多文件、标准库);D3=进阶(框架、第三方库、数据库);D4=复杂(全栈、部署、多模块);D5=高难(分布式、性能优化、原创算法)。

## 二、代码调试服务(P-01)

### 2.1 服务说明

针对客户已有代码中的缺陷进行定位、修复,并以可理解的方式向客户讲解问题成因与修复思路。不包含新功能开发,不包含大规模重构。适用于"程序能跑但有 Bug""特定场景报错""运行结果不符合预期"三类诉求。

### 2.2 交付物清单

| 交付物 | 形式 | 是否必交 |
|--------|------|----------|
| 修复后的代码 | 原工程 zip 或 git diff patch | 必交 |
| 问题定位说明 | Markdown 文档,含报错堆栈、根因、修复点 | 必交 |
| 修复讲解录音/录屏 | 5-15 分钟,口述根因与改法 | 选交(¥80 以上赠送) |
| 复现环境说明 | 依赖版本、运行命令 | 必交 |

### 2.3 工时拆解参考

| 阶段 | 工作内容 | 参考工时 |
|------|----------|----------|
| 环境复现 | 拉取代码、安装依赖、复现报错 | 0.5-2h |
| 根因定位 | 断点调试、日志分析、最小复现用例 | 0.5-3h |
| 修复实现 | 改动代码、回归测试 | 0.5-2h |
| 讲解整理 | 撰写说明、录制讲解 | 0.5-1h |
| 合计 | — | 2-8h |

### 2.4 难度系数参考

| 难度 | 判定条件 | 系数 |
|------|----------|------|
| D1 | 单文件、报错信息明确、改 1-5 行 | ×1.0 |
| D2 | 多文件、需读上下文、改 10-30 行 | ×1.5 |
| D3 | 涉及框架生命周期/异步/并发、需理解业务 | ×2.2 |

### 2.5 报价区间推演

基准单价 ¥40/h(冷启动期),以下为三个典型场景:

```
场景 A:Python 单文件 NameError,改 3 行
  工时 2h × 单价 40 × 难度 D1(1.0) = ¥80
  起步价兜底 → ¥80(不低于 ¥30 起步价)

场景 B:Spring Boot 接口 500,涉及 MyBatis 映射
  工时 5h × 单价 40 × 难度 D3(2.2) = ¥440
  紧急度 1.5(次日交付)→ ¥660

场景 C:React 父子组件状态不同步,需排查 useEffect
  工时 4h × 单价 40 × 难度 D2(1.5) = ¥240
  含讲解录屏 → ¥280
```

### 2.6 适用客户画像

- 计科/软工本科生,课设跑不通急需救场
- 自学者跟教程做项目,卡在某个报错
- 初级程序员,线上小 Bug 求二次确认

### 2.7 交付标准与验收点

1. 客户提供的复现用例在修复后运行通过;
2. 原有功能未出现新的报错(回归测试);
3. 问题定位说明能让客户复述根因(验收话术:"你能用自己的话说一下为什么错吗");
4. 代码改动范围与说明文档一致,无未声明的副作用改动。

### 2.8 售后边界

| 售后项 | 是否包含 | 说明 |
|--------|----------|------|
| 同一 Bug 复发 | 包含(7 天内) | 免费再修一次 |
| 客户自行改动后新报错 | 不包含 | 按新单计费 |
| 新功能需求 | 不包含 | 转为 P-02 或 P-05 |
| 环境配置问题 | 不包含 | 另行收费 ¥50 起 |

|--------|------|----------|
| 小程序源码 | 微信开发者工程 / Uni-app 工程 | 必交 |
| 后端源码 | Node/Java/Python | 必交(全栈) |
| 数据库脚本 | SQL/迁移文件 | 必交(全栈) |
| 接口文档 | Apifox/Markdown | 必交 |
| 部署文档 | Markdown | 必交 |
| 体验版二维码 | 微信体验版 | 必交 |
| 上架材料清单 | 类目、资质、截图说明 | 选交(+¥200) |

### 7.3 工时拆解参考

| 阶段 | 工作内容 | 参考工时 |
|------|----------|----------|
| 需求与原型 | 功能清单、页面流、原型图 | 6-12h |
| UI 设计 | 视觉稿、切图 | 6-16h |
| 前端开发 | 页面、组件、状态、接口联调 | 20-50h |
| 后端开发 | API、数据库、鉴权 | 15-40h |
| 测试 | 真机、兼容、支付、权限 | 6-14h |
| 上架协助 | 资料整理、提审跟进 | 2-6h |
| 合计 | — | 55-138h |

### 7.4 难度系数参考

| 难度 | 判定条件 | 系数 |
|------|----------|------|
| D3 | 展示型、无登录、无支付 | ×1.5 |
| D4 | 含登录、表单、后端管理 | ×2.0 |
| D5 | 含支付、订阅消息、多角色权限、直播组件 | ×2.8 |

### 7.5 报价区间推演

```
场景 A:餐饮展示小程序,5 页,无后端
  工时 60h × 单价 50 × D3(1.5) = ¥4500
  → 成交价 ¥4500

场景 B:预约小程序,含登录与后台
  工时 95h × 单价 50 × D4(2.0) = ¥9500
  含上架协助 → ¥9700

场景 C:电商小程序,含支付与订单管理
  工时 130h × 单价 55 × D5(2.8) = ¥20020
  分阶段 3:4:3 → ¥20000(取整)
```

### 7.6 适用客户画像

- 实体门店,需会员/预约/点单
- 区域服务商,需轻量线上入口
- 活动方,需报名与签到

### 7.7 交付标准与验收点

1. 体验版在 iOS/Android 微信真机正常运行;
2. 核心流程(登录、下单、支付、查询)闭环;
3. 接口文档与实际接口一致,可被二次开发;
4. 体验版二维码可被客户指定测试人员扫码;
5. 上架材料清单覆盖类目、资质、截图三项。

### 7.8 售后边界

| 售后项 | 是否包含 | 说明 |
|--------|----------|------|
| 上线后 15 天 Bug 修复 | 包含 | 限原需求 |
| 微信平台政策变更适配 | 不包含 | 重新议价 |
| 上架被拒协助 | 包含(2 次) | 第 3 次起 ¥100/次 |
| 服务器/后端维护 | 不包含 | 签维护协议 |
| 运营素材更新 | 不包含 | 按次计费 |

## 八、服务组合推荐

### 8.1 冷启动期推荐组合

冷启动期以"快速成单、积累口碑、降低交付风险"为目标,推荐以下组合:

```
组合 A:学生救场包
  P-01 代码调试 + P-04 脚本工具
  客单价区间:¥150-400
  交付周期:1-3 天
  适合:开学季、期末季引流

组合 B:课设标准包
  P-02 课设辅导 + P-01 代码调试(赠 1 次)
  客单价区间:¥600-1500
  交付周期:5-7 天
  适合:学期中段稳定接单

组合 C:作品集速成包
  P-05 网站开发(静态档) + P-04 脚本工具(部署脚本)
  客单价区间:¥1000-2000
  交付周期:5-10 天
  适合:求职季
```

### 8.2 稳定期推荐组合

稳定期以"提高客单价、拉长客户生命周期"为目标,推荐以下组合:

```
组合 D:毕设全程包
  P-03 毕设全程 + P-05 网站开发(部署档) + P-01 调试(答辩前不限次)
  客单价区间:¥5000-12000
  交付周期:4-8 周
  适合:大四上学期至答辩前

组合 E:小微企业数字化包
  P-06 小程序 + P-05 网站开发(全栈档) + P-04 脚本(数据同步)
  客单价区间:¥8000-20000
  交付周期:4-8 周
  适合:B 端客户拓展

组合 F:长期维护包
  任意开发服务 + 年度维护协议(开发费 15%/年)
  客单价区间:按主服务
  适合:复购客户转化
```

| 编号 | 场景 | 拒接理由 |
|------|------|----------|

## 十、价格声明

1. 本菜单所列「起步价」为对应服务项的最低成交价,不代表最终报价;
2. 最终成交价由《定价策略引擎》(CAT-0002)定义的「工时 × 单价 × 难度系数 × 紧急度系数」推演得出,并与客户书面确认;

4. 高客单服务(¥2000 以上)分阶段付款,比例在协议中约定,常见为 4:4:2 或 3:4:3;
5. 价格可能因市场行情、平台政策、人力成本变动而调整,调整以本版本号升版为准,旧客户在签订协议前的已确认报价 7 天内有效;
