## 一、模块定位与使用说明

本菜单覆盖 HOS 微商技术服务运营中"计算机基础"品类下的全部对外服务项,包括算法辅导、实验辅导、考研辅导三类。本菜单用于:

1. 一线接单时快速查阅服务范围、报价区间、交付物;
2. 与客户进行课时规划与排期的依据;
3. 内部派单与讲师匹配的参考基准。

计算机基础辅导类服务以"课时"为主要计费单位,强调教学过程的可量化、可追溯。所有辅导服务须遵守学术诚信原则,严禁代写、代考等违规行为。

### 1.1 服务总览

| 服务项 | 核心内容 | 起步价 | 标准工期 |
|---|---|---|---|
| 算法辅导 | 数据结构与算法 1v1 | ¥50/小时 | 即时 |
| 实验辅导 | OS/网络/数据库实验 | ¥80 起 | 1-2 天 |
| 考研辅导 | 408 全科/单科辅导 | ¥100/小时 | 预约制 |

### 1.2 难度系数说明

难度系数用于课时估算与报价推演,取值 1.0-2.5:

- 1.0:基础知识点讲解,标准教材内容;

- 2.0:高阶专题、竞赛级内容;
- 2.5:跨学科综合、深度定制。

## 七、拒接场景

以下场景一律拒接,不得以任何理由变通。一线接单人员遇此类需求应直接引用《红线清单与拒绝话术》标准话术回绝。

### 7.1 绝对拒接(学术诚信红线)

| 场景 | 拒绝理由 |
|---|---|
| 考试代考 | 违反考试管理法规,涉嫌违法 |
| 作业/实验报告代写 | 违反学术诚信,长期风险 |
| 毕业设计代做 | 违反学位管理规定 |
| 论文代写 | 违反学术规范,涉嫌学术不端 |
| 在线课程代刷/代考 | 违反平台规则,欺诈 |
| 押题/透题承诺 | 无法保证,涉嫌欺诈 |
| 简历造假辅导 | 违反诚信原则 |

### 7.2 有条件拒接(需升级审核)

| 场景 | 处理方式 |
|---|---|
| 要求"包过"承诺 | 拒绝承诺结果,仅承诺教学过程 |
| 要求代写代码(非教学目的) | 拒绝,仅提供思路与关键片段 |
| 要求代做课程设计 | 拒绝完整代做,仅提供指导 |
| 课时要求过少但期望高分 | 说明合理预期,不承诺效果 |
| 考前临时突击(不足 1 个月) | 评估可行性,不承诺覆盖全部考点 |

### 7.3 标准拒绝话术

```
话术A(代考/代写):
"您好,我们不提供代考、代写类服务,这违反学术诚信与相关规定。
我们可以提供正规的教学辅导,帮助您真正掌握知识点。
感谢理解。"

话术B(包过承诺):
"您好,考研辅导的效果取决于多种因素,我们无法承诺'包过'。
我们能承诺的是按规划完成教学、答疑与模考评估。
如果您认可这个方式,我们可以进一步沟通。"

话术C(代做课程设计):
"您好,课程设计需要您独立完成,我们可以提供思路指导、
关键代码片段和报告结构建议,但不提供完整代做服务。
感谢理解。"
```

## 八、价格声明

本菜单所列价格均为起步价或参考价,实际报价依据以下因素动态核算:
