> **版本**: 1.0.0 | **最后更新**: 2026-07-26
> **基于 Skill**: 08-HOS-Micro-Biz
> **适用阶段**: 冷启动 / 稳定期 / 扩张期

---

## 一、体系概述

本物料体系是 HOS 微商技术服务运营助手的完整落地文档集,覆盖从服务设计、获客文案、客户沟通、订单管理到合规风控的全链路运营场景。面向微信朋友圈、社群、闲鱼、小红书等微商/私域平台,为程序设计、计算机科学、AI 应用、信息安全等技术服务的线上小买卖提供可执行的标准作业流程与模板。

### 核心特征

- **可执行性**:所有文档均提供可直接复制的模板、话术、checklist,非理论阐述
- **全链路覆盖**:从接单前合规判断到售后纠纷处理,五大模块闭环
- **阶段适配**:冷启动/稳定期/扩张期三阶段差异化策略
- **专业商务风格**:结构化表格、代码块包裹可复制内容、克制使用 emoji

## 二、模块架构

```
┌─────────────────────────────────────────────────────────────┐
│                    合规风控模块 (compliance)                  │
│  红线清单 · 风险防控 · 合规决策流 · 退款纠纷                   │
│  ↑ 接单前过滤                    ↑ 售后纠纷兜底               │
├─────────────────────────────────────────────────────────────┤
│  服务目录模块         获客文案模块         沟通模板模块         │
│  (catalog)           (marketing)         (templates)        │
│  四层服务模型         朋友圈/闲鱼/         需求确认/沟通话术/    │
│  定价策略引擎         小红书/社群          报价话术/交付售后SOP  │
│  四领域服务菜单       获客文案模板         全场景话术与SOP       │
├─────────────────────────────────────────────────────────────┤
│                    订单财务模块 (orders)                      │
│  订单跟踪 · 财务管理 · 复购运营 · 转介绍机制                   │
└─────────────────────────────────────────────────────────────┘
```

### 模块间协作关系

- **合规风控**是接单前的过滤层,所有订单必须先过合规决策流
- **服务目录**提供可售服务清单与定价依据
- **获客文案**驱动公域/私域流量导入
- **沟通模板**支撑客户全生命周期沟通
- **订单财务**管理执行过程与资金流转
- 售后纠纷回流入**合规风控**模块处理

## 四、快速上手指南

### 冷启动期(0-10 单)

1. 通读 [四层服务模型](catalog/01-四层服务模型.md) 确定服务组合
2. 用 [定价策略引擎](catalog/02-定价策略引擎.md) 建立报价能力
3. 选 1-2 个擅长领域,精读对应服务菜单(如 [程序设计](catalog/03-服务菜单-程序设计.md))
4. 部署 [闲鱼商品SEO文案](marketing/02-闲鱼商品SEO文案.md) + [朋友圈文案模板集](marketing/01-朋友圈文案模板集.md) 开始获客
5. 每单必过 [需求确认checklist](templates/01-需求确认checklist.md) + [合规决策流](compliance/03-合规决策流.md)
6. 用 [订单跟踪表](orders/01-订单跟踪表.md) 管理订单

### 稳定期(月 10+ 单)

1. 复盘 [财务管理模板](orders/02-财务管理模板.md) 校准定价
2. 启动 [客户复购运营模板](orders/03-客户复购运营模板.md) 提升复购
3. 部署 [转介绍机制模板](orders/04-转介绍机制模板.md) 拓展获客
4. 标准化执行 [交付与售后SOP](templates/04-交付与售后SOP.md)
5. 每月跑 [风险防控checklist](compliance/02-风险防控checklist.md) 自检

### 扩张期(月 30+ 单)

1. 全模块标准化执行,考虑团队化
2. 时薪档位上移,缓冲率固定 15-20%
3. 建立 [转介绍机制模板](orders/04-转介绍机制模板.md) 的体系化运营
4. 季度 [财务管理模板](orders/02-财务管理模板.md) 复盘驱动调价
5. 完善 [退款策略与纠纷处理](compliance/04-退款策略与纠纷处理.md) 的流程化应对

## 五、文档使用规范

### 文档编号规则

- `CAT-XXXX`:服务目录模块
- `MKT-XXXX`:获客文案模块
- `TPL-XXXX`:沟通模板模块
- `ORD-XXXX`:订单财务模块
- `CMP-XXXX`:合规风控模块

### 文档结构约定

每份正式文档包含:
- 文档头(模块/编号/版本/日期/适用阶段)
- 中文数字分节(一、二、三...)
- ### 小标题
- 标准 markdown 表格
- 代码块包裹的可复制模板/话术/流程图
- 文末"相关文档"交叉链接

### 价格声明

*本体系中所有价格、报价区间、时薪基准均为参考值,需根据当地市场行情、个人能力档位与项目战略价值综合调整。定价公式与系数表提供的是决策框架,非固定标准。*

### 合规声明

*本体系提供的是运营流程模板与合规判断框架,不构成法律意见。涉及税务、合同、知识产权等专项问题,请咨询专业律师或会计师。红线服务坚决不碰,灰色地带优先拒绝。*
