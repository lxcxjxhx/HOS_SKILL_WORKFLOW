# 合规与风控模块总览

> 本模块是 HOS 微商技术服务运营体系的安全护栏，定义红线边界、风险防控机制与纠纷处理流程，保障业务合规运营与风险可控。

## 文档清单

| 编号 | 文档 | 说明 |
|------|------|------|
| CMP-0001 | 01-红线清单与拒绝话术.md | 五大类红线服务识别与拒绝话术 |
| CMP-0002 | 02-风险防控checklist.md | 六大风险防控场景可勾选清单 |
| CMP-0003 | 03-合规决策流.md | 三层过滤模型与典型场景决策案例 |
| CMP-0004 | 04-退款策略与纠纷处理.md | 退款决策矩阵与纠纷升级处理流程 |

## 使用建议

1. 接单前必须对照红线清单（CMP-0001）进行服务合规性判断，红线服务一律拒绝
2. 需求确认阶段同步执行风险防控checklist（CMP-0002），逐项勾选确认
3. 遇到边界模糊场景时遵循合规决策流（CMP-0003）逐层过滤，不可凭直觉判断
4. 退款策略（CMP-0004）应提前在沟通阶段告知客户，纠纷处理遵循升级流程
5. 本模块内容为业务底线，优先级高于其他所有模块，冲突时以合规为准
