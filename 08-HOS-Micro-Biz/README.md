# HOS-Micro-Biz: Micro-Business Tech Service Operations

A complete skill system for operating tech services on micro-business / private domain platforms.

## Quick Start

### 1. Choose Your Sub-Skill

| What do you want? | Sub-Skill | Documentation |
|-------------------|-----------|---------------|
| Design service catalog & pricing | catalog | [View docs](catalog/SKILL.md) |
| Write customer acquisition copy | marketing | [View docs](marketing/SKILL.md) |
| Client communication scripts | templates | [View docs](templates/SKILL.md) |
| Track orders & finances | orders | [View docs](orders/SKILL.md) |
| Check compliance & risk | compliance | [View docs](compliance/SKILL.md) |

### 2. Usage Examples

#### Design a service menu
```
Help me design a tech service menu for WeChat Moments.
I'm good at Python, AI deployment, and web security.
Target customers: college students.
```

#### Write acquisition copy
```
Write 3 WeChat Moments posts for this week.
Focus on AI-related services, include a case study format.
```

#### Get a pricing quote
```
A client wants a Python data visualization coursework.
Requirements: matplotlib charts + analysis report, due in 5 days.
Help me calculate the price.
```

#### Check compliance
```
A client asked me to help with an online exam.
Can I take this order?
```
