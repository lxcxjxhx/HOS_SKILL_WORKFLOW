# hos-weekly-update

## Description
HOS 生态周报自动生成器。从三个仓库（HOS-Forge、HOS-LS、HOS_SKILL_WORKFLOW）的 git log、issues、PRs 中提取本周活动，生成统一格式的 Weekly Update，可直接发布到 GitHub Discussions / Releases / 社交平台。

## Trigger
当用户提到以下关键词时激活：
- "周报"、"weekly update"、"本周总结"、"weekly report"
- "生成周报"、"写周报"、"本周进展"

## Context

### HOS 生态品牌
```
HOS（Hyacinth Open Security）
AI Native Open Source Security Ecosystem

├── HOS-Forge        → AI Security IDE（旗舰）
├── HOS-LS           → AI Static Analysis Engine
└── HOS_SKILL_WORKFLOW → AI Workflow & Prompt Library
```

### 仓库路径
- HOS-Forge: `c:\1AAA-PROJECT\HOS\HOS-Forge`
- HOS-LS: `c:\1AAA-PROJECT\HOS\HOS-LS`
- HOS_SKILL_WORKFLOW: `c:\1AAA-PROJECT\WORKFLOW`（或用户指定路径）

## Workflow

### Step 1: 收集数据
对每个仓库执行以下命令（PowerShell）：

```powershell
# 本周 commits（周一至今）
git -C "<repo_path>" log --oneline --since="last monday" --all

# 本周关闭的 issues
gh issue list --repo <owner/repo> --state closed --search "closed:>=<last_monday>"

# 本周合并的 PRs
gh pr list --repo <owner/repo> --state merged --search "merged:>=<last_monday>"

# 本周新增的 issues（含未关闭的）
gh issue list --repo <owner/repo> --state open --search "created:>=<last_monday>"
```

### Step 2: 分类整理
将收集到的活动按以下类别归类：

| 类别 | 说明 |
|------|------|
| **New** | 新增功能、新增规则、新增语言支持 |
| **Improved** | 性能优化、Token 减少、架构改进 |
| **Fixed** | Bug 修复、兼容性修复 |
| **Docs** | 文档更新、Wiki 补充 |
| **Upstream** | 向上游贡献的 PR、同步的上游改进 |

### Step 3: 生成周报
使用以下模板输出：

```markdown

## Highlights
> 一句话总结本周最重要的进展。

## HOS-Forge (AI Security IDE)
### New
- ...
### Improved
- ...
### Fixed
- ...

## HOS-LS (AI Analysis Engine)
### New
- ...
### Improved
- ...
### Fixed
- ...

## HOS_SKILL_WORKFLOW (AI Workflow Library)
### New
- ...
### Improved
- ...

## Upstream Contributions
- PR #XX to <upstream_repo>: <description>

## Next Week
- <planned_work_1>
- <planned_work_2>

*Generated by HOS Weekly Bot*
```

### Step 4: 输出适配
根据用户指定的目标平台调整格式：

| 平台 | 格式要求 |
|------|---------|
| GitHub Discussions | 完整 Markdown，保留所有细节 |
| GitHub Releases | 精简版，聚焦 What's New |
| X/Twitter | 提取 3-5 条亮点，每条 ≤ 280 字符 |
| 中文社交平台 | 翻译为中文，保留技术术语 |

## Rules
1. 周报语言默认英文，用户要求中文时切换
2. 每个仓库的活动不超过 10 条，超出时按重要性筛选
3. 必须包含具体数字（如 "Token 从 28000 降至 9000"）
4. 如果某个仓库本周无活动，明确标注 "No updates this week"
5. Upstream Contributions 单独列出，体现双向流动
6. 输出文件保存到 `c:\1AAA-PROJECT\BOS\BOS-OPER\hos-skills\output\weekly\` 目录
