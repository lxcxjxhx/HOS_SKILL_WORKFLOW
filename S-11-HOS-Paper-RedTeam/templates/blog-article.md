# 公开博客模板（论文鞭尸局·公开版）

> 适用：CSDN / GitHub Blog / 公众号。由 Blogger Agent 产出，辣度 1-2。

```yaml
rve_series: HOS-RVE-2026-NNNN
arxiv_id: ""
title: ""
source: paper-autopsy.md (内部版)
spiciness: 1
```

## 标题（SEO）

> 例：`【论文翻车现场】MultiVer 零样本漏洞检测：一半告警是误报？`

## 摘要（3 句话）

> 论文做了什么 → 我们发现什么问题 → 为什么值得你看。

## 正文

### 这篇论文声称什么

> 中性复述，引原文数字，标 arXiv ID。不歪曲。

### 我们审出了什么

> 逐条列出 RVE（保留编号、证据、数字），措辞收敛版：
> - "该文存在选择性指标报告问题（RVE-EVAL-XXXX）"
> - "复现门槛较高：闭源且依赖付费 API（RVE-REPRO-XXXX）"

### 这对学界意味着什么

> 每条发现的启示 + 对研究者的参考价值（从"骂"转向"教"）。

### 权威解读与佐证

> 挂权威第三方来源，增强公信力；无则写「未找到权威第三方解读，证据缺口」。
> - OpenReview 真实审稿 / Papers with Code 复现记录 / Semantic Scholar 引用 / arXiv 元数据
> - 引用格式：`[权威佐证: <来源> <url> — <一句话结论>]`

### 修复建议

> 作者能怎么改。要具体。

### 研究机会预告

> 引导到研究机会专栏。

## 结尾

- 免责声明：本文为学术批判性综述，不针对任何作者个人，引用的数字均来自论文原文。
- 引流：关注 / 预告下篇 / 研究机会专栏入口。
