# 软著申请文档自动生成 Skill

## 技能概述

本技能用于从 GitHub 代码仓库自动生成符合中国版权保护中心要求的软件著作权申请文档。通过分析代码仓库结构、README、依赖关系等信息，自动生成完整的软著申请材料。

## 触发条件

当用户提出以下需求时触发本技能：
- "帮我申请软著"
- "生成软著申请材料"
- "从 GitHub 仓库生成软著文档"
- "写软件著作权申请"
- "生成软件说明书"
- "准备软著材料"
- "软件著作权登记"
- "生成代码文档用于软著申请"

## 核心能力

### 1. 代码仓库分析
- 自动提取 GitHub 仓库信息（README、代码结构、依赖）
- 分析项目技术栈和架构
- 识别核心模块和功能
- 提取关键算法和技术亮点

### 2. 文档自动生成
- 软件基本信息表
- 软件说明书（用户手册）
- 模块设计说明
- 功能说明文档
- 关键算法描述
- 数据库设计说明
- 流程图描述
- 截图说明指南
- 创新点总结
- 申请材料清单

### 3. 格式规范
- 符合中国版权保护中心标准格式
- 必要字段完整
- 用语规范、专业
- 支持自定义调整

## 工作流程

### 阶段一：信息收集与分析

1. **获取仓库信息**
   - 读取 GitHub 仓库 URL
   - 提取 README.md 内容
   - 分析项目结构（目录树）
   - 识别技术栈（package.json / requirements.txt / pom.xml 等）
   - 提取依赖列表

2. **代码结构分析**
   - 识别主要模块和目录
   - 分析代码组织方式
   - 提取核心功能模块
   - 识别关键算法实现

3. **技术特征提取**
   - 编程语言和框架
   - 数据库类型
   - 运行环境要求
   - 开发工具和环境

### 阶段二：文档生成

1. **基础信息生成**
   - 软件名称（中英文）
   - 版本号
   - 开发完成日期
   - 软件用途和适用范围

2. **说明书生成**
   - 引言（编写目的、背景）
   - 软件概述（功能、性能）
   - 运行环境（硬件、软件）
   - 使用说明（安装、配置、操作）
   - 模块设计说明
   - 功能详细说明
   - 关键算法描述
   - 数据库设计
   - 流程图说明

3. **辅助文档生成**
   - 创新点总结
   - 截图指南
   - 材料清单

### 阶段三：输出与调整

1. **生成文档包**
   - 按模板生成所有必需文档
   - 组织文档结构
   - 生成目录和索引

2. **用户确认与调整**
   - 展示生成的文档摘要
   - 根据用户反馈调整内容
   - 补充特定信息（如截图、具体日期等）

3. **最终输出**
   - 输出完整的文档包
   - 提供申请指南
   - 给出注意事项

## 使用指南

### 基本用法

```
请帮我从 GitHub 仓库 [仓库URL] 生成软著申请材料
```

### 高级用法

```
1. 分析 GitHub 仓库并生成软著文档
   - 仓库：https://github.com/username/repo
   - 软件名称：[自定义名称]
   - 版本号：V1.0
   - 开发完成日期：2024年1月

2. 生成特定文档
   - 只生成软件说明书
   - 只生成模块设计说明
   - 只生成创新点总结

3. 调整生成参数
   - 重点突出某项技术
   - 强调某个功能模块
   - 调整文档详细程度
```

### 输入要求

必需信息：
- GitHub 仓库 URL 或本地代码路径
- 软件名称（如未提供，从仓库名生成）
- 版本号（默认 V1.0）

可选信息：
- 开发完成日期
- 首次发表日期
- 著作权人信息
- 特殊说明或强调点

### 输出内容

生成的文档包包含：
1. `software-info.md` - 软件基本信息
2. `software-description.md` - 软件说明书（主文档）
3. `module-design.md` - 模块设计说明
4. `function-description.md` - 功能说明
5. `algorithm-description.md` - 关键算法描述
6. `database-design.md` - 数据库设计说明
7. `flowchart-description.md` - 流程图描述
8. `screenshot-guide.md` - 截图说明指南
9. `innovation-points.md` - 创新点总结
10. `application-materials.md` - 申请材料清单

## 模板系统

所有文档基于预定义模板生成，模板位于 `templates/` 目录：
- 符合中国版权保护中心格式要求
- 包含所有必要字段
- 支持自定义扩展
- 提供填写指南

## 工作流系统

提供三个标准工作流，位于 `workflows/` 目录：
1. `copyright-workflow.md` - 完整软著申请流程
2. `repo-analysis-workflow.md` - 代码仓库分析流程
3. `document-generation-workflow.md` - 文档生成流程

## 注意事项

### 版权保护中心要求
1. **软件名称规范**
   - 全称格式：XXX软件 或 XXX系统
   - 简称：不能使用英文缩写
   - 版本号：VX.X 格式

2. **文档格式要求**
   - 说明书页数：一般 10-60 页
   - 代码文档：前 30 页和后 30 页（每页 50 行）
   - 字体字号：宋体小四或仿宋_GB2312 小四

3. **内容要求**
   - 必须包含原创性声明
   - 功能描述要具体、详细
   - 技术特点要突出
   - 运行环境要明确

4. **常见驳回原因**
   - 软件名称不规范
   - 功能描述过于简单
   - 缺少必要章节
   - 截图不清晰或缺失
   - 代码文档格式不符合要求

### 本技能的限制
- 无法自动生成代码文档（需手动提取）
- 无法生成实际截图（需提供截图指南）
- 无法自动提交申请（需手动操作）
- 生成的文档需要人工审核和调整
