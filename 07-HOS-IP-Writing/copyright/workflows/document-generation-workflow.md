# 文档生成工作流

## 工作流概述

本工作流用于基于代码仓库分析结果，自动生成符合中国版权保护中心要求的软著申请文档。

---

## 详细步骤说明

### 步骤 1：数据准备

#### 1.1 输入数据整理

**目标**：整理代码仓库分析结果，准备文档生成所需数据

**操作内容**：
1. 整理仓库分析数据
   - 仓库基本信息
   - 技术栈信息
   - 代码统计数据

2. 整理模块分析数据
   - 模块划分结果
   - 模块功能说明
   - 模块关系说明

3. 整理功能分析数据
   - 功能点清单
   - 功能详细说明
   - 核心功能标识

4. 整理算法分析数据
   - 核心算法清单
   - 算法详细说明
   - 算法性能数据

**输出物**：
- 数据清单
- 数据验证报告

**检查点**：
- [ ] 数据整理完整
- [ ] 数据格式统一
- [ ] 数据验证通过

---

#### 1.2 模板准备

**目标**：准备文档生成所需的模板

**操作内容**：
1. 加载文档模板

   - software-description.md（软件说明书）
   - module-design.md（模块设计说明）
   - function-description.md（功能说明）
   - algorithm-description.md（关键算法描述）
   - database-design.md（数据库设计说明）
   - flowchart-description.md（流程图描述）
   - screenshot-guide.md（截图说明指南）
   - innovation-points.md（创新点总结）
   - application-materials.md（申请材料清单）

2. 检查模板完整性
   - 模板文件存在
   - 模板格式正确
   - 模板占位符完整

3. 准备自定义模板（如需要）
   - 根据项目特点调整模板
   - 添加特定章节
   - 调整内容结构

**输出物**：
- 模板清单
- 模板检查报告

**检查点**：
- [ ] 所有模板加载完成
- [ ] 模板格式正确
- [ ] 自定义模板准备完成
