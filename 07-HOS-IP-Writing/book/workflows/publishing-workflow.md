# 出版流程指南（Publishing Workflow）

> 从书稿到出版的完整流程，涵盖传统出版和自出版两种方式。

---

## 一、出版方式选择

```
                    ┌─────────────────┐
                    │   书稿完成      │
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │  选择出版方式   │
                    └────────┬────────┘
                             │
            ┌────────────────┼────────────────┐
            │                │                │
   ┌────────▼────────┐  ┌───▼────┐  ┌───────▼───────┐
   │   传统出版      │  │ 混合   │  │   自出版      │
   │ (出版社出版)    │  │ 模式   │  │ (平台发布)    │
   └─────────────────┘  └────────┘  └───────────────┘
```

### 出版方式对比

| 维度 | 传统出版 | 自出版 | 混合模式 |
|------|----------|--------|----------|
| 权威性 | 高 | 中 | 先自出版验证，再传统出版 |
| 传播范围 | 广（书店、电商） | 依赖平台 | 两阶段覆盖 |
| 收益比例 | 低（8-15% 版税） | 高（50-70%） | 分阶段收益 |
| 出版周期 | 长（6-18 个月） | 短（1-4 周） | 先快后慢 |
| 质量控制 | 出版社把关 | 作者自负 | 自出版迭代，传统出版精修 |
| 成本 | 无（出版社承担） | 低（平台费用） | 分阶段投入 |
| 适合人群 | 追求权威性 | 追求快速迭代 | 先验证再正式出版 |

## 二、传统出版流程

### 阶段 1：出版社选择（1-2 周）

**国内技术类出版社推荐**：

| 出版社 | 擅长领域 | 投稿方式 | 联系方式 |
|--------|----------|----------|----------|
| 电子工业出版社 | 计算机、电子技术 | 官网投稿 / 编辑邮箱 | www.phei.com.cn |
| 机械工业出版社 | 工程技术、计算机 | 官网投稿 / 电话 | www.cmpbook.com |
| 人民邮电出版社 | 计算机、通信 | 官网投稿 / 编辑邮箱 | www.ptpress.com.cn |
| 清华大学出版社 | 计算机、理工 | 官网投稿 / 编辑邮箱 | www.tup.com.cn |
| 高等教育出版社 | 教材、学术 | 官网投稿 | www.hep.com.cn |
| 科学出版社 | 学术专著 | 官网投稿 | www.sciencep.com |

**选择标准**：
- 出版社是否有同类书籍出版经验
- 出版社的品牌影响力
- 版税比例和付款方式
- 出版周期
- 营销支持力度

### 阶段 2：书籍提案准备（1-2 周）

**书籍提案内容**：

1. **书籍基本信息**
   - 书名（含副标题）
   - 作者信息（简介、联系方式）
   - 预计字数
   - 预计交稿时间
   - 目标读者

2. **书籍简介**（500-800 字）
   - 书籍要解决什么问题
   - 书籍的核心特色
   - 与同类书籍的差异化

3. **市场分析**
   - 目标读者群体规模
   - 同类书籍销售情况
   - 本书的竞争优势

4. **作者简介**
   - 教育背景
   - 工作经历
   - 技术专长
   - 已出版作品（如有）
   - GitHub / 博客等技术影响力

5. **目录大纲**
   - 完整的章节目录
   - 每章主要内容概述
   - 预计篇幅分配

6. **样章**（1-2 章）
   - 展示写作风格
   - 展示技术深度
   - 展示代码示例质量

7. **营销计划**（可选）
   - 作者可提供的营销资源
   - 技术社区影响力
   - 计划的书发布活动

### 阶段 3：投稿与签约（1-3 个月）

**投稿流程**：
1. 准备书籍提案文档
2. 通过出版社官网或编辑邮箱投稿
3. 等待出版社初审（通常 2-4 周）
4. 如通过初审，参加选题会（可能需现场汇报）
5. 选题会通过后，协商合同条款
6. 签订出版合同

**合同关键条款**：
- 版税比例（通常 8-15%）
- 首印数量
- 交稿时间和质量要求
- 出版权属（纸质书、电子书、翻译权等）
- 付款方式（预付 + 版税）
- 合同期限

### 阶段 4：编辑与排版（3-6 个月）

**出版社工作流程**：
1. 责任编辑分配
2. 书稿三审三校
3. 技术审查（邀请技术专家审稿）
4. 排版设计
5. 封面设计
6. 作者校对
7. 最终确认

**作者需要配合的工作**：
- 根据编辑意见修改书稿
- 回答技术审查问题
- 校对排版样稿
- 确认封面设计
- 撰写内容简介、推荐语等营销材料

### 阶段 5：印刷与发行（1-2 个月）

- 印刷厂印刷
- 入库
- 电商平台上架
- 书店铺货
- 新书发布活动

## 三、自出版流程

### 自出版平台推荐

| 平台 | 特点 | 适合类型 | 收益比例 |
|------|------|----------|----------|
| GitBook | 在线文档、版本控制友好 | 技术文档、教程 | 免费版有限制，Pro 版收费 |
| Leanpub | 按需出版、支持预售 | 技术书籍、迭代写作 | 作者定价，平台抽成 10-40% |
| Amazon KDP | 全球最大电子书平台 | 各类书籍 | 版税 35-70% |
| 掘金小册 | 国内技术社区 | 中文技术书籍 | 与平台分成 |
| 极客时间 | 国内技术教育平台 | 专栏、课程 | 与平台分成 |
| 语雀 | 知识管理 + 出版 | 技术文档、知识库 | 免费版有限制 |

### 自出版流程

#### 阶段 1：平台选择与账号注册（1 天）
- [ ] 根据书籍类型选择平台
- [ ] 注册作者账号
- [ ] 了解平台规则和收益模式
- [ ] 配置收款信息

#### 阶段 2：内容上传与格式化（1-3 天）
- [ ] 将 Markdown 转换为平台支持的格式
- [ ] 上传章节内容
- [ ] 配置目录结构
- [ ] 设置代码高亮
- [ ] 上传插图

#### 阶段 3：定价与发布设置（1 天）
- [ ] 设置书籍定价（如收费）
- [ ] 编写书籍简介
- [ ] 上传封面图片
- [ ] 设置发布状态（公开 / 私密 / 预售）

#### 阶段 4：营销与推广（持续）
- [ ] 在技术社区宣传
- [ ] 撰写相关博客引流
- [ ] 在 GitHub 建立配套仓库
- [ ] 收集读者反馈
- [ ] 定期更新内容

## 四、混合模式

### 推荐策略

**先自出版验证，再联系传统出版**：

1. **第一阶段：自出版验证（1-3 个月）**
   - 选择 GitBook 或 Leanpub 发布初稿
   - 收集读者反馈和评价
   - 根据反馈迭代优化内容
   - 积累销量数据和读者口碑

2. **第二阶段：联系传统出版（3-6 个月）**
   - 用自出版数据作为谈判筹码
   - 向出版社展示市场验证结果
   - 协商更优的版税条件
   - 传统出版精修版

### 优势
- 降低出版社风险（有市场数据支撑）
- 作者获得更高版税（有谈判筹码）
- 读者获得更快反馈（先读后改）
- 内容质量更高（经过读者检验）

## 五、格式转换指南

### Markdown → PDF

**工具推荐**：

| 工具 | 特点 | 适合场景 |
|------|------|----------|
| Pandoc + LaTeX | 功能强大，排版精美 | 学术书籍、正式出版 |
| mdbook | Rust 编写，速度快 | 技术文档 |
| HonKit | GitBook 开源替代 | 在线文档 |
| Typora | 所见即所得 | 简单转换 |

**Pandoc 转换命令**：
```bash
# 基础转换
pandoc input.md -o output.pdf --pdf-engine=xelatex

# 带目录和代码高亮
pandoc input.md -o output.pdf \
  --pdf-engine=xelatex \
  --toc \
  --highlight-style=tango \
  -V mainfont="Noto Sans CJK SC" \
  -V monofont="JetBrains Mono"

# 使用模板
pandoc input.md -o output.pdf \
  --template=template.tex \
  --pdf-engine=xelatex \
  -V CJKmainfont="Noto Sans CJK SC"
```

### Markdown → ePub

```bash
# 基础转换
pandoc input.md -o output.epub

# 带封面和元数据
pandoc input.md -o output.epub \
  --epub-cover-image=cover.jpg \
  --epub-metadata=metadata.xml \
  --toc
```

### Markdown → HTML

```bash
# 基础转换
pandoc input.md -o output.html --standalone

# 带样式
pandoc input.md -o output.html \
  --standalone \
  --css=style.css \
  --toc
```
