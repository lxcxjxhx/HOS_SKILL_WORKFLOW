# ✅ 论文质量检查清单

> 在 Integration 和 Compression 阶段使用此清单进行全面质量检查。每个检查项必须通过才能进入下一阶段。

---

## 📊 检查状态说明

- ✅ 通过
- ⚠️ 需要改进
- ❌ 未通过（必须修改）
- N/A 不适用

---

## 1. 结构与组织（Structure & Organization）

### 1.1 整体结构
- [ ] 论文包含所有必要章节：Abstract, Introduction, Related Work, Methods, Results, Discussion, Conclusion
- [ ] 章节顺序符合逻辑（IMRAD 格式）
- [ ] 各章节篇幅分配合理（见大纲模板中的目标占比）
- [ ] 总篇幅符合投稿要求

### 1.2 章节过渡
- [ ] Introduction 末尾有明确的贡献列表
- [ ] 每个章节结尾有过渡句引出下一章
- [ ] Related Work 与 Introduction 的问题陈述呼应
- [ ] Methods 与 Related Work 的差距分析呼应
- [ ] Results 验证了 Methods 中提出的所有组件
- [ ] Discussion 解读了 Results 中的关键发现
- [ ] Conclusion 呼应了 Introduction 中提出的问题

### 1.3 段落结构
- [ ] 每个段落有明确的主题句（通常是首句）
- [ ] 每个段落只讨论一个核心观点
- [ ] 段落长度适中（5-8 句为宜）
- [ ] 段落之间有逻辑连接

---

## 2. 内容质量（Content Quality）

### 2.1 Abstract
- [ ] 包含背景、问题、方法、结果、意义五要素
- [ ] 结果部分包含具体的量化数据
- [ ] 篇幅在 150-250 词（英文）/ 200-300 字（中文）
- [ ] 没有引用、公式、图表引用
- [ ] 没有使用未定义的缩写

### 2.2 Introduction
- [ ] 第一段吸引读者兴趣，说明研究重要性
- [ ] 明确定义了研究问题
- [ ] 分析了现有方法的不足
- [ ] 贡献列表具体、可量化（3-5 点）
- [ ] 没有过度承诺（避免 "solve"、"perfect"）

### 2.3 Related Work
- [ ] 按主题分类组织（而非按时间或文献罗列）
- [ ] 每个分类有小结，指出与本文的关系
- [ ] 覆盖了该领域的主要工作
- [ ] 诚实指出相关工作的优缺点
- [ ] 没有贬低相关工作

### 2.4 Methods
- [ ] 有整体架构图（Figure 1）
- [ ] 统一定义了所有数学符号
- [ ] 描述了足够的细节以支持复现
- [ ] 每个组件说明了设计理由
- [ ] 算法流程清晰（如有）
- [ ] 复杂度分析完整（如适用）

### 2.5 Results
- [ ] 所有声明都有数据支撑
- [ ] 包含置信区间或标准差（如适用）
- [ ] 说明了统计显著性检验
- [ ] 包含消融实验验证各组件贡献
- [ ] 分析了失败案例（如适用）
- [ ] 没有只展示成功案例
- [ ] Results 部分没有解读 "为什么"（留给 Discussion）

### 2.6 Discussion
- [ ] 解释了 "为什么" 方法有效
- [ ] 与相关工作进行了深入对比
- [ ] 诚实讨论了方法的局限性
- [ ] 提出了未来改进方向
- [ ] 没有回避负面结果
- [ ] 没有过度泛化结论

### 2.7 Conclusion
- [ ] 呼应了 Introduction 中提出的问题
- [ ] 重申了核心贡献（但不是复制粘贴）
- [ ] 提出了具体的未来工作方向
- [ ] 没有引入新的信息
- [ ] 没有过度夸大贡献

---

## 3. 语言与表达（Language & Expression）

### 3.1 声音规则
- [ ] 使用主动语态（"We propose..." 而非 "It is proposed..."）
- [ ] 使用第一人称复数（"We" 而非 "I" 或 "The authors"）
- [ ] 避免了模糊量词（"very", "quite", "rather", "basically"）
- [ ] 每句话只表达一个观点
- [ ] 段落首句 = 段落主题句

### 3.2 句子质量
- [ ] 句子长度适中（目标：每句 ≤ 25 词）
- [ ] 长句已拆分为短句
- [ ] 没有语法错误
- [ ] 没有拼写错误
- [ ] 标点符号使用正确

### 3.3 段落质量
- [ ] 删除了不增加信息量的文字
- [ ] 使用具体表达而非抽象表达（"improves accuracy by 15%" 而非 "significantly improves"）
- [ ] 合并了重复表达
- [ ] 一个段落一个核心论点

### 3.4 中文论文特殊检查
- [ ] 专业术语首次出现时标注英文
- [ ] 摘要包含中英双语版本（如需要）
- [ ] 遵循中文标点符号规范
- [ ] 避免过度口语化表达
- [ ] 中英文之间有空格（排版规范）

---

## 4. 图表质量（Figures & Tables）

### 4.1 图表设计
- [ ] 每张图/表都有清晰的标题和说明
- [ ] 图表在正文中被引用和解读
- [ ] 图表设计简洁，去除不必要的装饰
- [ ] 字体大小适中，可读性好
- [ ] 颜色对比度足够（考虑黑白打印）

### 4.2 图表规范
- [ ] 图的编号连续（Figure 1, 2, 3...）
- [ ] 表的编号连续（Table 1, 2, 3...）
- [ ] 图表标题在图下方、表上方
- [ ] 坐标轴有标签和单位
- [ ] 图例清晰，位置合理

### 4.3 图表内容
- [ ] 图表传达的信息明确
- [ ] 数据准确，与正文描述一致
- [ ] 误差线标注清楚（如适用）
- [ ] 统计显著性标注（如适用）

---

## 5. 引用与参考文献（Citations & References）

### 5.1 引用规范
- [ ] 每个引用都有对应的参考文献条目
- [ ] 每个参考文献都在正文中被引用
- [ ] 引用格式统一（numbered 或 author-year）
- [ ] 引用位置合理（句末或作者后）

### 5.2 参考文献质量
- [ ] 覆盖了该领域的主要工作
- [ ] 包含近 3-5 年的最新文献
- [ ] 包含经典文献（奠基性工作）
- [ ] 参考文献数量充足（通常 30-50 篇）
- [ ] 没有虚构的参考文献

### 5.3 参考文献格式
- [ ] 格式符合投稿要求
- [ ] 作者姓名格式统一
- [ ] 期刊/会议名称完整
- [ ] 年份、卷号、页码完整

---

## 6. 数学公式与符号（Mathematics & Notation）

### 6.1 公式规范
- [ ] 所有公式都有编号
- [ ] 公式中的每个变量都有解释
- [ ] 公式编号连续
- [ ] 公式在正文中被引用

### 6.2 符号一致性
- [ ] 同一概念使用同一符号
- [ ] 符号在首次出现时定义
- [ ] 符号表完整（如需要）
- [ ] 没有符号冲突

### 6.3 数学正确性
- [ ] 公式推导正确
- [ ] 单位一致
- [ ] 边界条件处理正确
- [ ] 复杂度分析正确

---

## 7. 投稿适配（Submission Requirements）

### 7.1 格式要求
- [ ] 使用指定的 LaTeX/Word 模板
- [ ] 页边距、字体、行距符合要求
- [ ] 双栏/单栏格式正确
- [ ] 页码标注正确

### 7.2 篇幅要求
- [ ] 总页数/字数符合要求
- [ ] 参考文献页数计算正确
- [ ] 附录页数计算正确（如适用）

### 7.3 特殊要求
- [ ] 匿名评审要求已满足（如适用）
- [ ] 伦理声明已包含（如适用）
- [ ] 数据可用性声明已包含（如适用）
- [ ] 作者贡献声明已包含（如适用）
- [ ] 利益冲突声明已包含（如适用）

---

## 8. 学术诚信（Academic Integrity）

### 8.1 原创性
- [ ] 所有非原创内容都有明确引用
- [ ] 直接引用使用引号并标注页码
- [ ] 间接引用（paraphrase）充分改写
- [ ] 没有自我抄袭（reuse of own text）

### 8.2 数据真实性
- [ ] 所有实验数据都是真实的
- [ ] 没有篡改或选择性报告数据
- [ ] 实验可复现
- [ ] 代码/数据开源（如承诺）

### 8.3 作者贡献
- [ ] 所有作者都对论文有实质贡献
- [ ] 所有作者都同意投稿
- [ ] 作者排序合理
- [ ] 通讯作者明确

---

## 9. 最终检查（Final Check）

### 9.1 通读检查
- [ ] 通读全文，检查逻辑连贯性
- [ ] 检查术语一致性
- [ ] 检查时态一致性
- [ ] 检查缩写一致性

### 9.2 细节检查
- [ ] 标题、作者、单位信息正确
- [ ] 页眉页脚正确（如需要）
- [ ] 目录更新（如需要）
- [ ] 交叉引用正确

### 9.3 提交前检查
- [ ] PDF 文件可正常打开
- [ ] 图片清晰度足够
- [ ] 文件大小符合要求
- [ ] 提交系统要求已了解
