# 知乎格式指南

> 知乎使用富文本编辑器，也支持 Markdown 导入。知乎偏好深度、有见解的内容，注重可读性和讨论价值。

---

## 一、文章结构规范

### 1.1 标题层级
- **H1**（`#`）：文章标题，每篇仅一个
- **H2**（`##`）：主要章节
- **H3**（`###`）：子章节
- 知乎的目录基于标题层级自动生成

### 1.2 文章长度建议
- 知乎偏好**长文深度内容**
- 技术文章：3000-8000 字
- 观点类：1500-3000 字
- 适当使用小标题分段，提升可读性

---

## 二、内容风格

### 2.1 知乎风格特点
- **故事化开头**：用个人经历或案例引入
- **逻辑清晰**：论点-论据-结论结构
- **有深度**：不停留在表面，给出深层分析
- **有态度**：表达个人观点，引发讨论
- **可读性强**：避免纯技术堆砌，注重行文流畅

### 2.2 写作建议
- 开头 200 字决定读者是否继续阅读
- 每段不超过 5 行（移动端友好）
- 适当使用加粗强调关键信息
- 技术内容配合通俗解释

---

## 三、代码块

### 3.1 Markdown 代码块
````markdown
```python
def hello():
    print("Hello, Zhihu!")
```
````

### 3.2 注意事项
- 知乎 Markdown 导入后代码块会保留
- 支持主流编程语言高亮
- 长代码建议分段讲解

---

## 四、数学公式（LaTeX）

### 4.1 行内公式
```markdown
行内公式：$E = mc^2$
```

### 4.2 块级公式
```markdown
$$
f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$
```

### 4.3 注意事项
- 知乎完整支持 LaTeX 公式
- 行内用 `$...$`，块级用 `$$...$$`
- 公式渲染效果良好

---

## 五、图片

### 5.1 插入方式
```markdown
![图片描述](图片URL)
```

### 5.2 支持方式
- 支持上传本地图片（知乎自动托管）
- 支持外部图片链接
- 支持粘贴截图自动上传

### 5.3 最佳实践
- 图片宽度建议 800-1200px
- 添加有意义的图片说明
- 技术截图使用 PNG 格式

---

## 六、话题标签

### 6.1 格式
```markdown
#Python# #编程# #技术分享#
```

### 6.2 规则
- 使用 `#话题#` 格式（前后都有 `#`）
- 建议选择 **3-5 个**话题
- 选择知乎已有的话题标签
- 第一个话题最重要（影响推荐）

### 6.3 常用技术话题
- `Python`、`Java`、`前端开发`、`算法`、`机器学习`
- `程序员`、`技术分享`、`编程学习`、`计算机科学`

---

## 七、专栏

### 7.1 创建专栏
- 在知乎个人中心创建专栏
- 设置专栏名称和简介
- 发布文章时选择投稿到专栏

### 7.2 专栏建议
- 专栏定位清晰（如"XX 的技术笔记"）
- 定期更新保持活跃
- 专栏简介说明内容方向

---

## 八、特殊格式

### 8.1 引用块
```markdown
> 这是一段引用文字，可以用来强调重要信息
> 或引用他人的观点
```

### 8.2 分割线
```markdown
---
```

### 8.3 加粗和斜体
```markdown
**加粗文本** *斜体文本* ***加粗斜体***
```

### 8.4 链接
```markdown
[链接文字](https://example.com)
```

---

## 九、内容规范

### 9.1 知乎推荐机制
- 回答/文章的**赞同数**和**评论数**影响推荐
- 发布后 2 小时内的数据很关键
- 话题选择影响初始曝光
- 高质量内容会被编辑推荐

### 9.2 注意事项
- ✅ 原创内容
- ✅ 有深度和见解
- ✅ 结构清晰，排版整洁
- ✅ 配合图表和代码
- ❌ 避免纯转载
- ❌ 避免营销推广
- ❌ 避免敏感话题

---

## 十、发布检查清单

- [ ] 标题吸引人但不标题党
- [ ] 开头 200 字有吸引力
- [ ] 文章有深度和独到见解
- [ ] 代码块格式正确
- [ ] 图片清晰且有说明
- [ ] 话题标签已选择（3-5 个）
- [ ] 已投稿到专栏（如适用）
- [ ] 段落简短，移动端友好
- [ ] 无营销或引流内容
