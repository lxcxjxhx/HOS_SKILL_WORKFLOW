# 平台适配工作流

> 本工作流定义了将已有文章适配到不同平台的完整流程，确保文章在各平台的格式正确和最佳展示效果。

---

## 工作流概览

```
输入文章 → 分析原格式 → 选择目标平台 → 加载平台指南 → 格式转换 → 内容调整 → 生成平台版本 → 验证输出
```

---

## 阶段一：输入分析

### 1.1 接收输入

**输入类型：**

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| Markdown 文件 | `.md` 格式文章 | 直接解析 |
| 纯文本 | 无格式文本 | 识别结构后转换 |
| 已有平台版本 | 某平台已发布文章 | 提取内容后适配 |

### 1.2 分析原文章

**分析内容：**

1. **结构分析**
   - 标题层级（H1-H6）
   - 章节划分
   - 段落结构

2. **内容分析**
   - 代码块数量和语言
   - 图片数量和引用方式
   - 链接数量和类型
   - 表格和列表

3. **元数据分析**
   - 标题
   - 标签
   - 分类
   - 摘要

**分析输出：**

```markdown
## 原文章分析报告

### 基本信息
- 标题：{{标题}}
- 字数：{{字数}}
- 代码块：{{数量}} 个
- 图片：{{数量}} 张
- 链接：{{数量}} 个

### 结构分析
- H1：{{数量}} 个
- H2：{{数量}} 个
- H3：{{数量}} 个
- 段落数：{{数量}}

### 特殊元素
- 代码语言：{{语言列表}}
- 图片引用：{{外部链接/本地文件}}
- 特殊语法：{{LaTeX/Mermaid/等}}
```

## 阶段二：平台选择

### 2.1 确定目标平台

**用户指定平台：**
- 单平台适配
- 多平台批量适配

**平台特性对比：**

| 平台 | 编辑器 | 代码支持 | 图片限制 | 标签数量 | 特殊语法 |
|------|--------|----------|----------|----------|----------|
| CSDN | Markdown | 完整 | 支持外部 | 5 个 | LaTeX |
| 掘金 | Markdown | 完整 | 仅图床 | 1 个 | 高亮/折叠 |
| 知乎 | 富文本 | 完整 | 支持外部 | 3-5 个 | LaTeX |
| Medium | 专有 | 有限 | 自动托管 | 5 个 | 无 |
| Dev.to | Markdown | 完整 | 支持外部 | 4 个 | Liquid |

### 2.2 加载平台指南

根据目标平台加载对应指南：

```
templates/platform-{platform}.md
```

## 阶段三：格式转换

### 3.1 标题层级转换

**转换规则：**

| 平台 | H1 规则 | H2 规则 | 目录 |
|------|---------|---------|------|
| CSDN | 仅 1 个 | 主要章节 | 自动生成 |
| 掘金 | 仅 1 个 | 主要章节 | 自动生成 |
| 知乎 | 仅 1 个 | 主要章节 | 自动生成 |
| Medium | Title + Subtitle | 小标题 | 无 |
| Dev.to | 仅 1 个 | 主要章节 | 自动生成 |

**转换示例：**

```markdown
# 原始结构
# 主标题
## 章节1
### 子章节1.1
## 章节2

# CSDN/掘金/知乎（保持不变）
# 主标题
## 章节1
### 子章节1.1
## 章节2

# Medium（转换为 Title/Subtitle）
Title: 主标题
Subtitle: 副标题
## 章节1
### 子章节1.1
## 章节2

# Dev.to（添加 Front Matter）
---
title: "主标题"
---
# 主标题
## 章节1
### 子章节1.1
## 章节2
```

### 3.2 代码块转换

**转换规则：**

| 平台 | 代码块格式 | 文件名支持 | 行号 |
|------|-----------|-----------|------|
| CSDN | ` ```language ` | 不支持 | 自动显示 |
| 掘金 | ` ```language ` | 不支持 | 不显示 |
| 知乎 | ` ```language ` | 不支持 | 不显示 |
| Medium | 代码块或 Gist | 不支持 | 不显示 |
| Dev.to | ` ```language:file ` | 支持 | 不显示 |

**转换示例：**

```markdown
# 原始代码块
```python
def hello():
    print("Hello")
```

# CSDN/掘金/知乎（保持不变）
```python
def hello():
    print("Hello")
```

# Medium（短代码保持，长代码转 Gist）
短代码：使用 Medium 代码块
长代码：创建 Gist 并嵌入

# Dev.to（可添加文件名）
```python:app.py
def hello():
    print("Hello")
```
```

### 3.3 图片转换

**转换规则：**

| 平台 | 图片上传 | 外部链接 | 建议 |
|------|----------|----------|------|
| CSDN | 支持 | 支持 | 优先上传到 CSDN 图床 |
| 掘金 | 支持 | 不支持 | 必须上传到掘金图床 |
| 知乎 | 支持 | 支持 | 优先上传到知乎 |
| Medium | 自动托管 | 不支持 | 直接上传 |
| Dev.to | 支持 | 支持 | 直接上传或外部链接 |

**转换示例：**

```markdown
# 原始图片引用
![图片描述](https://external.com/image.png)

# CSDN/知乎/Dev.to（可保持外部链接）
![图片描述](https://external.com/image.png)
或上传后：
![图片描述](https://platform-cdn.com/image.png)

# 掘金（必须上传到掘金图床）
![图片描述](https://juejin-cdn.com/image.png)

# Medium（直接上传）
![图片描述](https://medium-cdn.com/image.png)
```

### 3.4 标签转换

**转换规则：**

| 平台 | 标签数量 | 格式 | 语言 |
|------|----------|------|------|
| CSDN | 最多 5 个 | 平台标签体系 | 中文 |
| 掘金 | 1 个分类 | 平台分类 | 中文 |
| 知乎 | 3-5 个 | `#话题#` 格式 | 中文 |
| Medium | 最多 5 个 | topics | 英文 |
| Dev.to | 最多 4 个 | 小写英文 | 英文 |

**转换示例：**

```markdown
# 原始标签
标签：Python, 异步编程, asyncio, 并发

# CSDN（最多 5 个）
标签：Python, 异步编程, asyncio, 并发编程, 性能优化

# 掘金（1 个分类）
分类：后端

# 知乎（3-5 个，#话题# 格式）
#Python# #异步编程# #并发# #性能优化#

# Medium（最多 5 个，英文）
Tags: Python, Async Programming, Asyncio, Concurrency, Performance

# Dev.to（最多 4 个，小写英文）
tags: python, async, asyncio, concurrency
```

### 3.5 特殊语法转换

**LaTeX 公式：**

| 平台 | 支持情况 | 格式 |
|------|----------|------|
| CSDN | 完整支持 | `$...$` 和 `$$...$$` |
| 掘金 | 支持 | `$...$` 和 `$$...$$` |
| 知乎 | 完整支持 | `$...$` 和 `$$...$$` |
| Medium | 不支持 | 需转为图片或 Gist |
| Dev.to | 不支持 | 需转为图片或代码块 |

**Mermaid 图表：**

| 平台 | 支持情况 | 处理方式 |
|------|----------|----------|
| CSDN | 部分支持 | 转为图片或保留代码 |
| 掘金 | 不支持 | 转为图片 |
| 知乎 | 不支持 | 转为图片 |
| Medium | 不支持 | 转为图片 |
| Dev.to | 不支持 | 转为图片 |

## 阶段四：内容调整

### 4.1 语言风格调整

**平台风格特点：**

| 平台 | 风格 | 注意事项 |
|------|------|----------|
| CSDN | 技术导向 | 注重代码和原理 |
| 掘金 | 深度原创 | 避免水文和搬运 |
| 知乎 | 故事化 | 注重可读性和见解 |
| Medium | 简洁专业 | 英文写作，面向国际 |
| Dev.to | 友好包容 | 鼓励分享和学习 |

### 4.2 长度调整

**平台推荐长度：**

| 平台 | 推荐长度 | 说明 |
|------|----------|------|
| CSDN | 2000-5000 字 | 技术博客 |
| 掘金 | 2000-6000 字 | 深度文章 |
| 知乎 | 3000-8000 字 | 长文深度 |
| Medium | 1500-4000 词 | 英文文章 |
| Dev.to | 1500-4000 词 | 技术分享 |

### 4.3 链接调整

**链接规则：**

| 平台 | 外部链接 | 注意事项 |
|------|----------|----------|
| CSDN | 限制 | 避免过多外部链接 |
| 掘金 | 限制 | 避免营销链接 |
| 知乎 | 支持 | 避免引流链接 |
| Medium | 支持 | 可添加参考链接 |
| Dev.to | 支持 | 鼓励引用权威来源 |

## 阶段五：生成平台版本

### 5.1 生成文件

**文件命名：**

```
{slug}-{platform}.md
```

**文件结构：**

```markdown
# {文章标题}

{{平台特定元数据}}

---

{{正文内容}}

---

{{平台特定附录}}
```

### 5.2 平台特定元数据

**CSDN：**
```markdown
# 文章标题

> 摘要：{{摘要}}

标签：{{标签1}}, {{标签2}}, {{标签3}}
专栏：{{专栏名称}}
原创：{{是/否}}
```

**掘金：**
```markdown
# 文章标题

> 摘要：{{摘要}}

分类：{{分类}}
标签：{{标签}}
专栏：{{专栏名称}}
```

**知乎：**
```markdown
# 文章标题

> 摘要：{{摘要}}

#话题1# #话题2# #话题3#
专栏：{{专栏名称}}
```

**Medium：**
```markdown
Title: {{English Title}}
Subtitle: {{English Subtitle}}

Tags: {{tag1}}, {{tag2}}, {{tag3}}
```

**Dev.to：**
```markdown
---
title: "{{Title}}"
published: true
cover_image: "{{cover_url}}"
description: "{{Description}}"
tags: [{{tag1}}, {{tag2}}, {{tag3}}]
series: "{{Series Name}}"
---

# {{Title}}

{{Content}}
```

## 阶段六：验证输出

### 6.1 格式验证

**验证清单：**

- [ ] 标题层级正确
- [ ] 代码块格式正确
- [ ] 图片引用正确
- [ ] 标签格式正确
- [ ] 特殊语法正确

### 6.2 内容验证

**验证清单：**

- [ ] 内容完整，无遗漏
- [ ] 代码可运行
- [ ] 链接有效
- [ ] 无错别字

### 6.3 平台规范验证

**各平台验证要点：**

| 平台 | 验证要点 |
|------|----------|
| CSDN | 标签数量 ≤ 5，无引流链接 |
| 掘金 | 图片已上传到掘金图床，分类正确 |
| 知乎 | 话题格式正确，段落简短 |
| Medium | 英文语法正确，标签 ≤ 5 |
| Dev.to | Front Matter 完整，标签 ≤ 4 |

## 批量适配流程

### 多平台批量适配

**流程：**

```
输入文章 → 分析原格式 → 选择多个目标平台 → 并行适配 → 批量生成 → 批量验证
```

**执行步骤：**

1. 分析原文章（一次）
2. 为每个目标平台加载指南
3. 并行执行格式转换
4. 生成各平台版本
5. 批量验证输出

**输出文件：**

```
{slug}-csdn.md
{slug}-juejin.md
{slug}-zhihu.md
{slug}-medium.md
{slug}-devto.md
```

## 常见问题处理

### 问题 1：图片链接失效

**解决方案：**
- 掘金：必须上传到掘金图床
- 其他平台：建议上传到平台图床

### 问题 2：代码块过长

**解决方案：**
- Medium：转为 Gist 嵌入
- 其他平台：分段展示或折叠

### 问题 3：LaTeX 公式不支持

**解决方案：**
- Medium/Dev.to：转为图片或代码块
- 其他平台：保持 LaTeX 格式

### 问题 4：标签数量超限

**解决方案：**
- 选择最相关的标签
- 删除次要标签
- 合并相似标签
