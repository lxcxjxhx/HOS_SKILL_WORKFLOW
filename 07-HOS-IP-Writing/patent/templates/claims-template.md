# 权利要求书

## 权利要求书

**发明名称：** [发明名称]

---

### 独立权利要求

**1.** [主题名称]，其特征在于，包括：

[技术特征 A]；

[技术特征 B]；

[技术特征 C]；

...

[技术特征 N]。

---

### 从属权利要求

**2.** 根据权利要求 1 所述的 [主题名称]，其特征在于，所述 [引用特征] 进一步包括：

[附加技术特征]。

**3.** 根据权利要求 1 或 2 所述的 [主题名称]，其特征在于，所述 [引用特征] 为：

[具体限定]。

**4.** 根据权利要求 1-3 中任一项所述的 [主题名称]，其特征在于，所述 [引用特征] 的材质为 [材料]。

**5.** 根据权利要求 1-4 中任一项所述的 [主题名称]，其特征在于，所述 [引用特征] 的尺寸范围为 [数值范围]。

---

### 方法权利要求（如适用）

**6.** 一种 [方法主题名称]，其特征在于，包括以下步骤：

步骤 S1：[方法步骤 1]；

步骤 S2：[方法步骤 2]；

步骤 S3：[方法步骤 3]。

**7.** 根据权利要求 6 所述的方法，其特征在于，所述步骤 S1 中 [进一步限定]。

**8.** 根据权利要求 6 或 7 所述的方法，其特征在于，所述步骤 S2 的工艺条件为：[工艺参数]。

---

### 产品权利要求（如适用）

**9.** 一种 [产品名称]，包括根据权利要求 1-5 中任一项所述的 [部件名称]。

**10.** 一种 [产品名称]，其特征在于，采用根据权利要求 6-8 中任一项所述的方法制备。

---

## 权利要求书撰写规则

### 一、基本格式

#### 1. 独立权利要求格式

```
[主题名称]，其特征在于，包括：
[技术特征 A]；
[技术特征 B]；
...
[技术特征 N]。
```

**要点：**
- 前序部分：主题名称 + 必要技术特征（与现有技术共有的特征）
- 特征部分：以"其特征在于"引导，描述创新点

#### 2. 从属权利要求格式

```
根据权利要求 [X] 所述的 [主题名称]，其特征在于，所述 [引用特征] 进一步包括：
[附加技术特征]。
```

**要点：**
- 引用部分：明确指出引用的在前权利要求编号
- 限定部分：描述附加技术特征

### 二、撰写原则

#### 1. 清楚性原则

- 权利要求的保护范围应当清楚
- 技术特征应当明确，避免使用模糊用语
- 禁止使用"大约"、"左右"、" preferably"等模糊词汇
- 数值范围应当明确，如"10-20mm"而非"10mm 左右"

#### 2. 支持性原则

- 权利要求应当得到说明书的支持
- 权利要求中的技术特征应当在说明书中有记载
- 不得超出说明书公开的范围

#### 3. 层次性原则

- 独立权利要求：最大的合理保护范围
- 从属权利要求：逐层缩小保护范围
- 形成多层次的保护体系

#### 4. 单一性原则

- 一项权利要求应当只描述一个发明构思
- 避免在一个权利要求中混合多个不同的技术方案

### 三、常见错误

#### 1. 保护范围过宽

**错误示例：**
```
一种装置，包括处理模块。
```

**问题：** "处理模块"过于上位，可能得不到说明书支持

**正确示例：**
```
一种装置，包括处理器，所述处理器被配置为执行 [具体功能]。
```

#### 2. 技术特征不清楚

**错误示例：**
```
所述部件的长度约为 10cm。
```

**问题：** "约"字导致范围不清楚

**正确示例：**
```
所述部件的长度为 10cm。
或
所述部件的长度为 9-11cm。
```

#### 3. 引用关系错误

**错误示例：**
```
3. 根据权利要求 2 所述的装置，其特征在于...
4. 根据权利要求 3 所述的装置，其特征在于...（引用了不存在的权利要求）
```

**正确示例：**
```
3. 根据权利要求 1 或 2 所述的装置，其特征在于...
4. 根据权利要求 3 所述的装置，其特征在于...
```

### 四、撰写技巧

#### 1. 独立权利要求的撰写

- **必要技术特征**：只包含实现发明目的必不可少的特征
- **合理上位**：适当上位概括，扩大保护范围
- **避免多余限定**：不要加入非必要的技术特征

#### 2. 从属权利要求的布局

- **层层设防**：构建多层次的保护体系
- **重点保护**：将最重要的技术特征放在靠前的从属权利要求
- **商业考量**：结合产品实际情况布局

#### 3. 方法权利要求与产品权利要求

- 对于产品发明，可以同时申请产品权利要求和方法权利要求
- 方法权利要求的步骤应当有逻辑顺序
- 产品权利要求可以用结构特征或功能特征限定

### 五、审查要点

#### 1. 新颖性

- 独立权利要求应当相对于现有技术具有新颖性
- 从属权利要求的附加技术特征进一步限定保护范围

#### 2. 创造性

- 独立权利要求应当具有突出的实质性特点和显著的进步
- 从属权利要求的附加技术特征应当对创造性有贡献

#### 3. 实用性

- 权利要求描述的技术方案应当能够在产业中制造或使用
- 应当具有积极效果

## 示例

### 示例 1：产品权利要求

**1.** 一种智能手机，其特征在于，包括：

机身；

显示屏，设置于所述机身的前侧；

摄像头模组，设置于所述机身的后侧；

处理器，设置于所述机身内，与所述显示屏和摄像头模组电连接；

电池，设置于所述机身内，为所述显示屏、摄像头模组和处理器供电；

所述摄像头模组包括广角镜头和长焦镜头，所述处理器被配置为根据拍摄场景自动切换所述广角镜头和长焦镜头。

**2.** 根据权利要求 1 所述的智能手机，其特征在于，所述广角镜头的焦距为 24mm，所述长焦镜头的焦距为 52mm。

**3.** 根据权利要求 1 或 2 所述的智能手机，其特征在于，所述显示屏为 OLED 柔性屏。

### 示例 2：方法权利要求

**4.** 一种图像处理方法，其特征在于，包括以下步骤：

获取待处理图像；

对所述待处理图像进行预处理，得到预处理图像；

将所述预处理图像输入训练好的神经网络模型，得到分割结果；

根据所述分割结果对所述待处理图像进行后处理，得到目标图像。

**5.** 根据权利要求 4 所述的方法，其特征在于，所述神经网络模型为 U-Net 模型。

**6.** 根据权利要求 4 或 5 所述的方法，其特征在于，所述预处理包括图像归一化和数据增强。
