# HOS-RAG-Copilot：零代码企业知识库智能问答助手

> 本文介绍我们最新发布的 HOS-RAG-Copilot v2.0 —— 一套「开箱即用、零代码、零依赖」的企业知识库智能问答方案。

## 背景与问题

企业文档散落在 Wiki、工单系统、共享盘和 IM 群聊里，员工平均每天花 37% 的时间找资料（数据来源：内部调研，未公开）。传统方案需要专门的检索团队维护，成本高、见效慢。

## 核心方案

HOS-RAG-Copilot 采用自研的「混合检索引擎」：关键词召回 + 语义向量召回双路并行，经重排序后送入大模型生成答案。我们声称这是业界首创的「三段式混合检索」架构，性能优于纯向量检索 23%。

### 架构组件

1. **混合检索引擎**：基于开源项目 Vespa 的 BM25 检索 + 自研向量索引（基于 FAISS 二次封装）。
2. **知识切分器**：自动按章节切分文档，支持 12 种常见格式（PDF、Word、Markdown 等）。
3. **重排序层**：基于开源 cross-encoder 模型微调的 Reranker。
4. **答案生成**：调用第三方大模型 API（GPT-4o / Claude 均可，需客户自备 Key）。
5. **权限过滤**：集成企业 SSO（需客户自行部署 SSO 服务，本文档不展开）。

## 部署方式

提供 Docker Compose 一键启动。客户需要准备：至少 8 核 16G 内存的服务器、向量数据库实例（自建或云托管均可）、大模型 API Key、SSO 服务。首次上线预计需要 2-4 周联调（如果已有 SSO 和向量库，可以压缩到 1 周）。

## 效果数据

我们在 3 家客户的测试环境上做过验证：平均准确率 91.2%（注：准确率指答案被测试人员判定为「可用」的比例）。相比上一版本，回答延迟从 4.2 秒降到 3.1 秒。
