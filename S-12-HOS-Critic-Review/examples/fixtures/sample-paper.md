# CAMEL-GRU：基于门控循环单元的轻量级恶意软件分类框架

> 提交至 IEEE 某会议。代码与数据集暂未公开。

## Abstract

恶意软件检测是终端安全的核心。现有深度方法参数量大、部署成本高，难以在资源受限的端点上运行。我们提出 **CAMEL-GRU**：一个融合门控循环单元（GRU）与自注意力机制的轻量级分类框架，参数量仅 2.1M。实验表明，CAMEL-GRU 在 3 个数据集上达到 99.2% 的平均准确率，**全面超越所有现有方法（SOTA）**，同时推理延迟降低 47%。

## 1. Introduction

近年基于 Transformer 的恶意软件检测模型在学术基准上表现出色，但 200M+ 参数在真实端点上不可行。本文聚焦轻量级架构设计……

## 2. Method

### 2.1 整体架构

CAMEL-GRU 由三层组成：**特征哈希层**（将原始 API 调用序列映射为固定维向量）、**GRU 编码器**、**自注意力池化层**。这种「哈希 + 循环 + 注意力」的三段式结构是我们提出的核心创新。

### 2.2 训练细节

使用 AdamW 优化器，学习率 3e-4，batch size 64。我们设计了启发式早停策略：当验证损失连续 5 个 epoch 不下降时停止训练。超参数网格搜索范围与最终取值将在正式版本中给出。
