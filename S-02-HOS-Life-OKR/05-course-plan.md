# 05 — 课程 & 考试流程规划时间推荐

## 三种规划模式

| 模式 | 适用场景 | 规划周期 | 输出 |
|------|---------|---------|------|
| 📚 **课程模式** | 系统学习一门新课（如"学透CCNA"） | 2-6个月 | 阶段化课程表 |
| 🎯 **考试模式** | 准备认证考试（如"通过Security+"） | 1-3个月 | 考试倒计时计划 |
| 🛤️ **混合模式** | 边学课程边考证 | 3-6个月 | 课程+考试双轨计划 |

## 规划算法

```
总时间 = 截止日 - 当前日

阶段拆分（按比例）:
  ├── 40% 课程/教材学习阶段
  ├── 25% 实践/实验阶段
  ├── 20% 刷题/模拟考阶段
  └── 15% 查漏补缺/总复习阶段

每周推荐投入 = 总剩余内容量 / 剩余周数 × 1.2（预留缓冲）
```

## 时间推荐规则

| 阶段 | 推荐每日时长 | 最佳学习时段 | 任务类型 |
|------|------------|------------|---------|
| 教材学习 | 60-90min | 中高能量 | 阅读 + 笔记 |
| 实验实践 | 90-120min | 高能量 | 动手 + 报告 |
| 刷题模拟 | 60-90min | 中能量 | 刷题 + 错题分析 |
| 总复习 | 120min | 高能量 | 综合复习 |

## 动态调整机制

```
阶段结束复盘 → 实际进度 vs 计划进度
  ├── 落后 >20% → 延长1周，压缩后续
  ├── 领先 >20% → 提前进入下一阶段
  └── ±20%以内 → 保持原计划
```
