# 03 — KPI 行为映射层 (从结果到行为)

## KPI 类型定义

| KPI 类型 | 说明 | 每日目标 | 周目标 |
|----------|------|---------|--------|
| 学习时长 | 纯学习时间（分钟） | 90 | 540 |
| 输出任务 | 博客/commit/笔记 | 1 | 5 |
| 实践任务 | 实验/CTF/项目 | — | 2 |
| 复盘任务 | 复盘/总结 | — | 1 |
| 知识整理 | 结构化整理 | — | 3 |
| **复习任务** | **间隔重复/错题重做** | **1轮** | **5轮** |
| **存档维护** | **SAVE + 产出归档** | — | **1次** |

## 输出结构

```json
{
  "kpi_gaps": [
    { "name": "实践任务", "remaining": 2, "priority": 0.8 },
    { "name": "输出任务", "remaining": 3, "priority": 0.7 },
    { "name": "学习时长", "remaining_minutes": 270, "priority": 0.6 },
    { "name": "复盘任务", "remaining": 1, "priority": 0.5 }
  ]
}
```

## 操作步骤

1. 检查每个 KPI 的周目标完成情况
2. 计算剩余缺口 (`周目标 - 当前累计`)
3. 根据缺口大小和 KR 关联度计算优先级
4. 按优先级排序输出 KPI 缺口列表
