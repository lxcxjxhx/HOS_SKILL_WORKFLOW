# 17 — 对话流程设计

## 初始化流程

```
用户: "我想系统学习信息安全"
系统: [收集 OKR 信息]
  → O: 目标是什么?
  → KR1: 关键结果1?
  → KR2: 关键结果2?
  → KPI: 每周可投入时间?
  → 当前进度: 已完成到什么程度?
  → 创建系统配置 → 生成今日计划
```

## 每日执行流程

```
用户: "今天有2小时，能量7" 或 "📋今日启动"
系统: [分析进度 → 生成今日任务]
  → 输出: 任务列表 + 输出物要求 + 复习队列
用户: [执行完毕后反馈]
系统: [记录 → 留档 → 知识清单 → 复盘]
```

## 课程/考试规划

```
用户: "我要考Security+，9月底"
系统: [建立考试计划]
  → 考试日期 → 四阶段拆分 → 里程碑
  → 输出: 时间线 + 每周推荐投入
```

## 学完章节/模拟考

```
用户: "📖学完第7章"
系统: [一键5步]
  → 1/5 出章节测验 + 标准答案
  → 2/5 试卷入 exam-papers/quiz/
  → 等待作答...

用户: "✅交卷"
系统: [一键6步]
  → 1/6 评分: 22/30=73%
  → 2/6 对题错题全部留档
  → 3/6 考后总结 exam-review/...
  → 4/6 复习队列更新
  → 5/6 快照保存
  → 6/6 输出报告+专项计划
```

## 间隔复习

```
用户: "🧠开始复习"
系统: [检查复习队列]
  → 今日到期: 8题 | 超期: 2题
  → 按优先级输出复习题
用户: [逐题作答]
系统: [逐题更新 mastery_level + next_review]
  → 答对 → 间隔×2 | 答错 → 间隔÷2
```

## SAVE/LOAD

```
用户: "💾SAVE"
系统: → 生成快照 → 输出可复制编码

用户: "LOAD"
系统: → 提示粘贴 → 解码 → 恢复全部状态 → 生成计划
```

## 周复盘

```
用户: "📊周复盘"
系统: [汇总 → 趋势 → 资产报告 → 调整 → 快照]
  → 本周知识资产报告 weekly/W26-2026.md
```

## 流程说明

- **初始化**：首次使用，收集目标，建立系统
- **每日执行**：核心流程，含复习块+知识清单
- **课程/考试规划**：四阶段备考计划
- **间隔复习**：自动检查复习队列
- **快捷命令**：一键完成多步操作
- **SAVE/LOAD**：存档恢复
- **周复盘**：系统级调整
